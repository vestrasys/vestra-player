# 字幕工作台（vestra.subtitles）

功能：字幕轨列表与切换、关闭字幕、加载本地 UTF-8 SRT（加载后自动选中）、移除本插件加载的外部字幕，以及对宿主宣告可样式化的轨道调整延迟、字体、字号、颜色、描边、底部边距（正延迟使字幕晚出现；“撤销本插件的样式与延迟”只移除本插件的样式层）。

入口：菜单 `字幕 → 字幕工作台… / 加载外部 SRT… / 关闭字幕 / 刷新字幕轨`，打开同一个独立窗口（`ui/workbench.slint`），不占底栏或侧栏，不控制播放。字幕操作逐个执行，进行中菜单显示忙碌；“取消操作”阻止尚未执行的步骤，已交给宿主的操作可能已生效。媒体切换会取消进行中的操作和未提交的样式拖动。

行为要点：滑块拖动合并 100 ms 后提交，且只作用于开始调整时选中的轨（期间轨道变化则提示重新调整）；窗口打开后每 1.5 秒刷新字幕状态。

限制：插件端接受 1 字节至 8 MiB、扩展名 `.srt`、严格 UTF-8 的文件；宿主上传上限为 2 MiB，超过时显示宿主的拒绝信息。字体只来自宿主固定字体清单。字幕解析与渲染由宿主负责。

开发（在 `src/` 下）：`npm run plugin -- check subtitles`、`build subtitles`（生成 `dist/`，版本取自 `manifest.json`）、`test subtitles`。SDK v2，代码只用 `import type` 引用 SDK。
