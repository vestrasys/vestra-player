# 字幕（vestra.subtitles）

功能：字幕轨切换与显示/隐藏、载入本地 UTF-8 SRT（载入后自动选中）、移除本插件载入的外部字幕；对宿主宣告可样式化的轨道调整字号、位置（底部边距）、同步（每步 0.5 秒，正值字幕滞后）、字体、颜色、描边。改动立即生效，每项有「默认」；「全部默认」撤销本插件的样式层。

入口：
- `打开 → 打开字幕…`（Alt+O）
- `字幕 → 显示字幕`（勾选，Alt+H）、`选择字幕轨 ▶`（不显示 + 各字幕轨的名称，单选）、`同步 ▶ 超前 0.5 秒 / 滞后 0.5 秒 / 复位`（`>` / `<` / `/`）、`刷新字幕轨`、`字幕微调…`、`字幕设置…`
- 菜单与按键的结果显示为屏幕提示。窗口：`ui/tune.slint`（字幕微调，301 宽：轨道 + 载入、字号 ±、位置 上/下、同步 慢/快/默认）、`ui/settings.slint`（字幕设置：字体、颜色、描边、边距）。

行为要点：字幕操作逐个执行，进行中菜单显示忙碌，载入按钮变为「取消」；样式改动合并 100 ms 后提交，只作用于开始调整时选中的轨；媒体切换取消进行中的操作；窗口打开时每 1.5 秒刷新字幕状态。

限制：「选择字幕轨」最多列出前 8 条轨（轨道变化时在子作用域里重建，旧项被删除），其余在字幕微调的下拉框里选。插件端接受 1 字节至 8 MiB、扩展名 `.srt`、严格 UTF-8 的文件；宿主上传上限 2 MiB。字体只来自宿主固定字体清单。

开发（在 `src/` 下）：`npm run plugin -- check subtitles`、`build subtitles`、`test subtitles`。
