# 字幕（vestra.subtitles）

功能：字幕轨切换与显示/隐藏、依次切换字幕轨；载入本地字幕文件（SRT、ASS/SSA、WebVTT、SAMI、MicroDVD，按内容识别格式与编码，载入后自动选中）；重载本插件载入的字幕文件（可选文件改动后自动重载）；移除本插件载入的外部字幕；按对白跳转（上一句/下一句/当前字幕起点）。对宿主宣告可样式化的轨道调整字号、位置（底部边距）、同步（步长即「同步单位」，默认 0.5 秒，正值字幕滞后；也可手动输入毫秒值，范围 ±600 000）、字体、颜色、描边、粗体、阴影、背景框，以及 ASS/SSA 原样式开关。改动立即生效，每项有「默认」；「全部默认」撤销本插件的样式层。

入口：
- `打开 → 打开字幕…`（Alt+O）
- `播放 → 跳转 ▶`：`上一句对白`（Home）、`下一句对白`（End）、`当前字幕起点`（Ctrl+Home），order 217、分组 `jump-subtitle`
- `字幕 → 显示字幕`（勾选，Alt+H）
- `字幕 → 选择字幕轨 ▶`：不显示 + 各字幕轨（单选，302–310）、`依次切换`（Alt+L，311）
- `字幕 → 字幕样式 ▶`：`粗体`（勾选，Alt+B，324）、`字号 +` / `字号 −`（Alt+PageUp / Alt+PageDown，325/326）、`上移` / `下移`（Alt+↑ / Alt+↓，330/331）、`复位位置`（Alt+Home，334）、`阴影`（勾选，335）、`字幕边框不透明`（勾选，336）
- `字幕 → 开启 ASS/SSA 原样式`（勾选，337）
- `字幕 → 同步 ▶`：`超前 0.5 秒` / `滞后 0.5 秒` / `复位`（`.` / `,` / `/`，339–341，标题随同步单位变化）、`手动调整同步…`（342）。`>` `<` `?` 留给音频同步。
- `字幕 → 重载字幕`（Ctrl+Alt+Y，370）、`刷新字幕轨`（371）、`字幕微调…`（372）、`字幕设置…`（373）
- 窗口：`ui/tune.slint`（字幕微调）、`ui/settings.slint`（字幕设置：字体、粗体、颜色、描边、阴影、背景框与不透明度、边距、ASS 样式、同步单位、默认编码、自动重载）、`ui/sync.slint`（手动调整同步）。

行为要点：
- 字幕操作逐个执行，进行中菜单显示忙碌；样式改动合并 100 ms 后提交，只作用于开始调整时选中的轨；样式与同步按键不受进行中的操作阻挡。
- 文件（`formats.ts`）：≤ 8 MiB；编码按 BOM → 严格 UTF-8 → 「默认编码」（默认 GB18030），替换字符超过 1% 时提示；SRT 原样、ASS/SSA 以 `format: "ass"` 上传（删除 `[Fonts]`、`[Graphics]` 段），VTT、SAMI（每种语言一条轨）、MicroDVD（视频帧率 → 文件声明 → 23.976）转为 SRT；转换后 > 2 MiB、图形字幕、无法识别的格式在上传前拒绝。轨标题为文件名（SAMI 加语言）。`formats.ts` 与 subtitle-online 各带一份，保持一致。
- 按对白跳转：本插件载入的轨用上传的字节解析；内嵌文本轨用 `tools.run("ffmpeg", ["-map", "0:<streamIndex>", "-f", "srt", …])` 读一次并按轨缓存（超时约每 100 MB 1 秒，至少 15 秒）。`streamIndex` 为空、网络来源、图形轨、别的插件载入的轨、时间表为空时禁用（「没有可用的文本字幕」）；不能跳转的媒体禁用（「当前媒体不能跳转」）。目标为句子开始（加同步值）前 0.05 秒；按住时一次只排队一个跳转，每次从上一次落点算起。
- 样式记忆：`style.json` 保存除同步值外的样式（含阴影上次的距离、背景框不透明度），启动后第一次有可调样式的轨被选中时恢复；「全部默认」清除。
- 重载：只重载本插件载入的轨（内存里记住路径、在文件中的序号与 SHA-256），内容未变不重新上传。自动重载监视文件所在文件夹，改动停止 500 ms 后重载。

设置：`<dataDirectory>/settings.json`（`plugin.storage.json`；`version: 1`，`syncStepMs`、`autoReload`、`fallbackEncoding`，未知字段原样保留）、`style.json`。

限制：「选择字幕轨」最多列出前 8 条轨。ASS 外部轨不能进入「含字幕」截图（宿主限制）。背景框开启时阴影不生效（宿主用 `background-box`）。插件重启后，之前载入的轨不再能重载或按句跳转（来源记录只在内存里）。不支持图形字幕文件（.sup、VobSub）。

开发（在 `src/` 下）：`npm run plugin -- check subtitles`、`build subtitles`、`test subtitles`。
