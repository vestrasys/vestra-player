# 字幕（vestra.subtitles）

功能：字幕轨切换与显示/隐藏、依次切换字幕轨、载入本地 UTF-8 SRT（载入后自动选中）、重载本插件载入的字幕文件（可选文件改动后自动重载）、移除本插件载入的外部字幕；对宿主宣告可样式化的轨道调整字号、位置（底部边距）、同步（步长即「同步单位」，默认 0.5 秒，正值字幕滞后；也可手动输入毫秒值）、字体、颜色、描边。改动立即生效，每项有「默认」；「全部默认」撤销本插件的样式层。

入口：
- `打开 → 打开字幕…`（Alt+O）
- `字幕 → 显示字幕`（勾选，Alt+H）
- `字幕 → 选择字幕轨 ▶`：不显示 + 各字幕轨（单选，302–310）、`依次切换`（Alt+L，311：轨 1 → … → 轨 N → 关闭 → 轨 1）
- `字幕 → 字幕样式 ▶`：`字号 +` / `字号 −`（Alt+PageUp / Alt+PageDown，325/326）、`上移` / `下移`（Alt+↑ / Alt+↓，330/331）、`复位位置`（Alt+Home，334）
- `字幕 → 同步 ▶`：`超前 0.5 秒` / `滞后 0.5 秒` / `复位`（`.` / `,` / `/`，339–341，标题随同步单位变化）、`手动调整同步…`（342）。`>` `<` `?` 留给音频同步。
- `字幕 → 重载字幕`（Ctrl+Alt+Y，370）、`刷新字幕轨`（371）、`字幕微调…`（372）、`字幕设置…`（373）
- 菜单与按键的结果显示为屏幕提示。窗口：`ui/tune.slint`（字幕微调，301 宽：轨道 + 载入、字号 ±、位置 上/下、同步 慢/快/默认；点同步数值打开手动调整同步）、`ui/settings.slint`（字幕设置：字体、颜色、描边、边距、同步单位、「字幕文件改动后自动重载」）、`ui/sync.slint`（手动调整同步，350×121：整数毫秒，Enter 或「应用」生效，输入框内 ↑/↓ 按同步单位增减并生效）。

行为要点：字幕操作逐个执行，进行中菜单显示忙碌，载入按钮变为「取消」；样式改动合并 100 ms 后提交，只作用于开始调整时选中的轨；样式与同步按键不受进行中的操作阻挡（按住可连续调整）。依次切换的连续按键以最后一次为准，只提示最终结果。重载：只重载本插件载入的轨（插件在内存里记住文件路径与 SHA-256），内容未变不重新上传；内容变化时上传新轨、恢复原选择、移除旧轨，样式与同步不变；文件不在时保留旧轨。自动重载监视文件所在文件夹，改动停止 500 ms 后重载。媒体切换取消进行中的操作；窗口打开时每 1.5 秒刷新字幕状态。

设置：`<dataDirectory>/settings.json`（`version: 1`，`syncStepMs`、`autoReload`）。同步值本身不保存（属于样式层）。

限制：「选择字幕轨」最多列出前 8 条轨（轨道变化时在子作用域里重建，旧项被删除），其余在字幕微调的下拉框里选。插件端接受 1 字节至 8 MiB、扩展名 `.srt`、严格 UTF-8 的文件；宿主上传上限 2 MiB。同步值范围 ±10 000 ms（宿主 `offsetMs` 范围）。字体只来自宿主固定字体清单。插件重启后，之前载入的轨不再能重载（来源记录只在内存里）。

开发（在 `src/` 下）：`npm run plugin -- check subtitles`、`build subtitles`、`test subtitles`。
