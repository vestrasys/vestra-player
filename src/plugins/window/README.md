# 主窗口（vestra.window）

依据：doc/product/feature-requirements.md「窗口（`window`）」B30、H03、H04、H05、H07，以及 doc/product/interaction-alignment.md 的 G-02、G-06、IA-WIN-01–03。窗口本身（尺寸、层级、指针）归核心，本插件只通过 `plugin.window`（能力 `window.control`）发请求；视频尺寸来自 `player.stats()`；不和其它插件通信。没有自己的窗口或面板，只有「选项 ▶ 播放 ▶ 窗口」设置页（`ui/page.slint`，能力 `ui.settings`）。

## 视频尺寸（`video-size.ts`）

`PlayerState` 没有视频尺寸，所以来源第一次 `ready` 时读 `player.stats()`：`video.displayWidth/Height`（宽高比校正与滤镜之后），没有时用 `video.width/height`（插件生成流）。mpv 还没给出时每 500 ms 再读一次，最多 10 次。每次手动调整窗口前再读一次（画面可能已被旋转）。`video` 为 `null` 或尺寸为空 = 没有视频。每个来源第一次读到尺寸时通知 G-02。

## G-02 开始播放时的窗口尺寸（`auto-size.ts`）

默认 1 倍（参考播放器 `PlayScreenSize=2`）。每个新来源（`sourceId`）第一次读到视频尺寸时调整一次，规则与手动倍数相同（`setVideoArea`，保持左上角，核心按屏幕缩小 / 按最小尺寸放大）；「适应视频比例」保持当前宽度。不提示，被缩小或被拒绝也不提示；已是目标尺寸时不发送。不调整：没有视频、全屏、迷你尺寸生效、画中画中（或正在切换）、正在调整窗口、来源就绪后尺寸拿到前用户拖动过窗口（视频区变化超过 1 点）。同一来源重播、暂停、跳转不触发。「只调整一次」：本次运行第一个有视频的来源用掉这一次。插件激活时已在播放的来源同样调整。改设置只影响下一个来源。

## IA-WIN-01 迷你尺寸与画中画（`size.ts`、`geometry.ts`、`pip.ts`）

- 迷你尺寸（所有系统，`` ` ``）：视频区缩到能放进 400×300 的最大同比例尺寸（16:9 为 400×225；竖屏视频由核心放大到最小宽度 318），保持左上角；再按一次回到进入前的视频区。不置顶（IA-WIN-02）。用户拖动窗口、进入全屏、或执行倍数 / 适应比例时迷你尺寸自动结束（不恢复旧尺寸）。不保存。不可用：全屏「全屏时不可用」；没有视频「没有视频」（已在迷你尺寸时仍可退出）；调整或画中画切换进行中命令 `busy`。画中画中执行时先退出画中画，退出失败则不进入。
- 画中画（`window.state.pictureInPicture.supported` 为真时注册，跟随 `window.onChange` 注册 / 注销；无默认按键）：`window.setPictureInPicture(!active)`，勾选跟随 `state.pictureInPicture.active`。迷你尺寸生效时先恢复进入前的视频区。成功提示「画中画: 开 / 关」，失败「无法进入画中画：<原因>」（勾选不变）；`busy` 忽略，切换进行中命令 `busy`（「正在切换画中画」）。没有视频时禁用（已在画中画时仍可退出）；全屏时可用，由核心先退出全屏。小窗「返回」、关闭按钮或核心关闭时提示一次「画中画: 关」或「画中画: 关（没有视频）」。不改窗口尺寸、不置顶；插件停用时核心关闭小窗。

## H03 倍数尺寸、H04 适应视频比例

- H03：目标视频区 = 显示尺寸 × 倍数（四舍五入到点），`setVideoArea`。提示「窗口: 1.5倍」；`clamped` 时按返回值区分「（已按屏幕缩小）」与「（已按最小尺寸放大）」。视频区与某倍数相差 ≤ 1 点时该项显示圆点。
- H04：保持当前视频区宽度，高度按视频比例；已相符（≤ 1 点）时只提示「窗口已适应视频比例」，否则「窗口: 适应视频比例」。
- 不可用：全屏、没有视频；调整进行中 `busy`（「正在调整窗口」）。核心拒绝时提示「无法调整窗口：<原因>」。

## H05 / IA-WIN-03 置顶（`on-top.ts`）

`不置顶` / `总是置顶` / `播放时置顶`（`phase === "ready" && !paused`）/ `全屏播放时置顶`（默认，全屏 且 正在播放）；Ctrl+T 按 不置顶 → 总是 → 播放时 → 全屏播放时 循环。跟随播放状态与 `window.onChange`，只在实际值变化时调用 `setAlwaysOnTop`（不覆盖别的插件的最后写入）。提示「置顶: 总是 / 播放时 / 全屏播放时 / 关闭」。插件停用时核心取消置顶。macOS 全屏是独立空间，「全屏播放时」在那里看不出效果。

## B30 / G-06 播放时隐藏鼠标指针

默认开。勾选后 `setCursorAutoHide("playing")`，取消后 `"fullscreen"`；提示「播放时隐藏鼠标: 开 / 关」。激活时只在开着时调用一次（核心默认值不发送）。隐藏条件（空闲 3 秒、视频区内、主窗口活动、菜单未打开）由核心判断。

## 设置

`settings.json`（`plugin.storage`）：`{ onTop: "never" | "always" | "playing" | "fullscreen", hideCursorWhilePlaying: boolean, autoSize: "off" | 0.5 | 1 | 1.5 | 2 | "fit", autoSizeOnce: boolean }`，默认 `"fullscreen"`、`true`、`1`、`false`（参考播放器默认值）。字段无效或缺失时逐项用默认值；不是 JSON 对象的文件由 SDK 改名为 `settings.json.bad-<时间戳>`。没有数据目录时只在本次运行内有效。窗口尺寸与位置的跨启动保存归核心。

设置页「选项 ▶ 播放 ▶ 窗口」（id `window`，order 30）：开始播放时的窗口尺寸（六选一）、只调整一次、置顶方式（四选一）、播放时隐藏鼠标指针；与菜单项共用设置，页面上的修改不弹提示。

## 开发

在 `src/` 下：`npm run plugin -- check|build|test plugins/window`。读尺寸的重试间隔在 `settings.ts` 的 `timing`，测试里缩短。
