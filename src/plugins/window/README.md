# 主窗口（vestra.window）

依据：doc/product/feature-requirements.md「窗口（`window`）」B30、H03、H04、H05，以及 H07 在 3a 的「迷你尺寸」形态。窗口本身（尺寸、层级、指针）归核心，本插件只通过 `plugin.window`（能力 `window.control`）发请求；视频尺寸来自 `player.stats()`；不和其它插件通信。没有自己的窗口或面板。

## 视频尺寸（`video-size.ts`）

`PlayerState` 没有视频尺寸，所以来源第一次 `ready` 时读 `player.stats()`：`video.displayWidth/Height`（宽高比校正与滤镜之后），没有时用 `video.width/height`（插件生成流）。mpv 还没给出时每 500 ms 再读一次，最多 10 次。每次调整窗口前再读一次（画面可能已被旋转）。`video` 为 `null` 或尺寸为空 = 没有视频。

## H03 倍数尺寸、H04 适应视频比例、迷你尺寸（`size.ts`、`geometry.ts`）

- H03：目标视频区 = 显示尺寸 × 倍数（四舍五入到点），`setVideoArea`。提示「窗口: 1.5倍」；`clamped` 时按返回值区分「（已按屏幕缩小）」与「（已按最小尺寸放大）」。视频区与某倍数相差 ≤ 1 点时该项显示圆点。
- H04：保持当前视频区宽度，高度按视频比例；已相符（≤ 1 点）时只提示「窗口已适应视频比例」，否则「窗口: 适应视频比例」。屏幕放不下时核心按比例缩小（等同以可用高度反算宽度）。
- 迷你尺寸：视频区缩到能放进 400×300 的最大同比例尺寸（16:9 为 400×225；竖屏视频由核心放大到最小宽度 318），同时置顶；再按一次回到进入前的视频区，置顶回到所选方式。用户拖动窗口、进入全屏、或执行倍数 / 适应比例时迷你尺寸自动结束（不恢复旧尺寸）。不保存。
- 不可用：全屏「全屏时不可用」；没有视频「没有视频」（已在迷你尺寸时仍可退出）；调整进行中命令 `busy`（「正在调整窗口」）。核心拒绝时提示「无法调整窗口：<原因>」。

## H05 置顶（`on-top.ts`）

`不置顶`（默认）/ `总是置顶` / `播放时置顶`（`phase === "ready" && !paused`）；Ctrl+T 按 不置顶 → 总是 → 播放时 循环。实际置顶 = 迷你尺寸 或 总是 或（播放时 且 正在播放），只在值变化时调用 `setAlwaysOnTop`（不覆盖别的插件的最后写入）。提示「置顶: 总是 / 播放时 / 关闭」。插件停用时核心取消置顶。

## B30 播放时隐藏鼠标指针

勾选后 `setCursorAutoHide("playing")`，取消后 `"fullscreen"`；提示「播放时隐藏鼠标: 开 / 关」。激活时只在开着时调用一次（默认值不发送）。隐藏条件（空闲 3 秒、视频区内、主窗口活动、菜单未打开）由核心判断。

## 设置

`settings.json`（`plugin.storage`）：`{ onTop: "never" | "always" | "playing", hideCursorWhilePlaying: boolean }`。字段无效时逐项用默认值；不是 JSON 对象的文件由 SDK 改名为 `settings.json.bad-<时间戳>`。没有数据目录时只在本次运行内有效。窗口尺寸与位置的跨启动保存归核心。

## 开发

在 `src/` 下：`npm run plugin -- check|build|test plugins/window`。读尺寸的重试间隔在 `settings.ts` 的 `timing`，测试里缩短。
