# 截图与导出（vestra.capture）

功能：保存当前画面（PNG）、连拍（2–20 张，间隔 0.1–10 秒，按媒体时间 t0 + i × 间隔采样，写入所选目录下唯一的 `Capture-*` 子目录）、导出片段（MP4，可选一条源内音轨或无）。每种都有原始 / 处理后两种模式，处理后可含字幕。保存位置选好后会显示最终确认；快照绑定用户开始时看到的来源，选择位置或确认期间来源变化则不启动。已接受的任务冻结输入：一个运行、最多四个排队；任务列表可查询、取消、打开输出、用保留输入重试（失败/取消的输入保留最多五分钟）或用当前来源重试。从不覆盖已有文件（自动建议 `name (n).ext`）。

入口：`视频 → 截图与导出 → 保存当前画面… / 连拍… / 导出片段… / 查看导出任务…`，四个入口打开同一个窗口（`capture.slint`）的对应区段。窗口打不开时显示独立的错误窗口（`capture-error.slint`）。关闭窗口不取消任务；停用插件时取消未完成任务并释放快照。

代码：`main.ts`（组装窗口、命令）、`form.ts`（准备 → 选择位置 → 确认 → 冻结）、`tasks.ts`（队列、取消、保留、打开输出）、`model.ts`（解析、校验、命名）。

限制：只支持可独立重读的本地有限时长视频；没有数值进度（只有任务阶段与已发布张数）；编码器可用性以任务实际失败呈现。

开发（在 `src/` 下）：`npm run plugin -- check capture`、`build capture`（版本 1.0.0 取自 `manifest.json`）、`test capture`。
