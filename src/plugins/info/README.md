# 播放信息（vestra.info）

右键菜单顶层「播放信息」（勾选项，`windows` 组 order 810）或 Tab 开关视频左上角的只读信息层（默认关），显示期间每秒刷新一次。内容（整改文档 §9.2）：

```
文件：movie.mp4
时间：00:05 / 01:40
视频：h264 1920×1080
帧率：24.00 fps
音频：aac 48000 Hz 2 声道
后端：libmpv · 软件渲染（会话 3）
已显示帧：120
丢帧：1
```

未打开媒体时文件名为「未打开媒体」，其它未知项为「-」。文件名取路径最后一段；网络地址取路径最后一段，没有则取主机名。

用到的接口：`plugin.osd.panel()`（能力 `ui.osd`）、`plugin.player.stats()`（`playback.read`）、命令 `bindings`。信息层的底色、字体与位置由宿主决定。
