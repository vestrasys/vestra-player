# 音频工作台（audio）

功能：六段均衡器（60 Hz–10 kHz，±6 dB，步长 0.1 dB）及其开关、四个均衡器预设（只改均衡器）、声音同步（±2000 ms，按 10 ms 取整，正值使音频更晚；菜单与按键每步 50 ms）、规格化（dynaudnorm）、晶化（3 kHz 高频搁架，开关 + 0–6 dB 强度，默认 3 dB）与全部复位，作用于本插件自有的音频处理链 `workbench`。关闭均衡器只旁路频段、保留增益；拖动频段或选预设会重新打开均衡器。关闭晶化保留强度。

设置的归属：均衡器、预设、规格化、晶化是全局设置，跨音轨、跨文件、跨重启保留。声音同步按保持方式：不保持（默认，每次换来源归 0）、本次运行内保持（换来源保留，重启归 0）、始终保持（写入设置，重启后仍生效）。切换音轨不复位任何设置。设置文件 `<dataDirectory>/settings.json`（`version: 1`；先写临时文件再改名，读坏时用默认值；不认识的字段原样保留）。

入口（右键菜单 `声音 ▶`，order 510–517）：`音频工作台…`（510）；`均衡器`（勾选，Shift+E，513）；`预设 ▶ 平直/人声/音乐/影院`（单选，514）；`声音同步 ▶ 超前 50 毫秒 / 滞后 50 毫秒 / 复位`（`>` / `<` / `?`，按住重复）· `不保持 / 本次运行内保持 / 始终保持`（单选，515）；`声音处理 ▶ 规格化 / 晶化`（勾选，Shift+N / Shift+C，516）；`复位`（517）。没有选中的音轨时编辑命令禁用（保持方式除外）。菜单操作在视频左上角显示屏幕提示（“均衡器: 开”“均衡器预设: 人声”“音频同步: -0.05秒”“晶化: 开”“规格化: 开”“音频处理已复位”）。

窗口（`ui/workbench.slint`，301×260）：顶部三个页签（记住上次的页签）——「均衡器」（开关、预设弹出菜单、复位、6 段竖滑块）、「效果」（声音同步滑块 + 数值 + 默认、规格化、晶化复选 + 强度滑块 + 默认）、「声道与输出」（同步保持方式；音轨、声道、输出设备待核心接口）。底部状态行；处理失败时显示“音频处理失败”（悬停看原因）与“重试”。

限制：不负责基础音量、静音与播放控制（属于播放栏）；“已应用”表示宿主接受，不保证已听到效果；插件停用时宿主撤销本插件的处理资源。

开发（在 `src/` 下）：`npm run plugin -- check audio`、`build audio`（生成 `dist/`，版本取自 `manifest.json`）、`test audio`。
