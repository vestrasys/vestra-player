# 音频工作台（audio）

功能：六段均衡器（60 Hz–10 kHz，±6 dB，步长 0.1 dB）及其开关、四个均衡器预设（只改均衡器）、声音同步（±10 000 ms，按 10 ms 取整，正值使音频更晚；菜单与按键每步 50 ms）、规格化（dynaudnorm）、晶化（3 kHz 高频搁架，开关 + 0–6 dB 强度，默认 3 dB）、声道（立体声 / 左 / 右 / 单声道混合 / 左右互换，多声道先混为立体声）与全部复位，作用于本插件自有的音频处理链 `workbench`（顺序：声道 → 均衡器 → 晶化 → 规格化）。另有音轨选择、按序切换与载入外部音频文件。

设置的归属：均衡器、预设、规格化、晶化、声道、“自动载入同名音频文件”是全局设置，跨音轨、跨文件、跨重启保留。声音同步按保持方式：不保持（默认，每次换来源归 0）、本次运行内保持（换来源保留，重启归 0）、始终保持（写入设置，重启后仍生效）。切换音轨不复位任何设置。单声道音轨上声道设置保留但不生效。设置文件 `<dataDirectory>/settings.json`（`plugin.storage.json`，`version: 1`；读坏的文件改名为 `settings.json.bad-<时间戳>` 并用默认值；不认识的字段原样保留）。

入口：`打开 ▶ 载入外部音频…`（114，选择文件后加入并选中；没有播放中的文件或正在载入时禁用）。右键菜单 `声音 ▶`：`音频工作台…`（510）；`音轨 ▶`（511：各音轨单选，随音轨列表重建；512：按序切换 Alt+A、五种声道单选）；`均衡器`（勾选，Shift+E，513）；`预设 ▶ 平直/人声/音乐/影院`（单选，514）；`声音同步 ▶ 超前 50 毫秒 / 滞后 50 毫秒 / 复位`（`>` / `<` / `?`，按住重复）· `不保持 / 本次运行内保持 / 始终保持`（单选，515）；`声音处理 ▶ 规格化 / 晶化`（勾选，Shift+N / Shift+C，516）；`复位`（517）。没有选中的音轨时编辑命令禁用（保持方式除外）。菜单操作在视频左上角显示屏幕提示（“音轨: 2. English [eng] (ac3)”“只有一条音轨”“声道: 左声道”“已载入音频: movie.jpn.mka”“均衡器: 开”“音频同步: -0.05秒”“晶化: 开”等）。

窗口（`ui/workbench.slint`，301×260）：顶部三个页签（记住上次的页签）——「均衡器」（开关、预设弹出菜单、复位、6 段竖滑块）、「效果」（声音同步滑块 + 数值 + 默认、规格化、晶化复选 + 强度滑块 + 默认）、「声道与输出」（音轨下拉 + 载入…、声道下拉、输出设备（置灰，需要第 3a 轮的核心接口）、“自动载入同名音频文件”、同步保持方式）。底部状态行；处理失败时显示“音频处理失败”（悬停看原因）与“重试”。

自动载入：打开本地文件后，扫描同一文件夹（不递归）中以视频主名开头、扩展名为音频格式的文件（`movie.mkv` → `movie.ac3`、`movie.jpn.mka`），最多 8 个，加入但不选中；网络来源与音频文件本身不扫描；失败不提示。

限制：不负责基础音量、静音与播放控制（属于播放栏）；“已应用”表示宿主接受，不保证已听到效果；外部音轨保留到换来源，插件停用不撤销；插件停用时宿主撤销本插件的处理资源。

开发（在 `src/` 下）：`npm run plugin -- check audio`、`build audio`（生成 `dist/`，版本取自 `manifest.json`）、`test audio`。
