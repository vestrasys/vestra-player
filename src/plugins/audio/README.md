# 音频工作台（audio）

功能：六段均衡器（60 Hz–10 kHz，±6 dB，步长 0.1 dB）及其开关、四个均衡器预设（只改均衡器）、音频延迟（±2000 ms，按 10 ms 取整，正值使音频更晚）、响度规范化（dynaudnorm）、清晰度增强（treble 0–6 dB）与全部复位，作用于本插件自有的音频处理链 `workbench`。关闭均衡器只旁路频段、保留增益；拖动频段或选预设会重新打开均衡器。设置属于“一次载入的来源 + 一条选中的音轨”，任一变化即复位为中性。

入口（右键菜单 `声音 ▶`，order 510–516）：`音频工作台…` 打开独立窗口（`ui/workbench.slint`，301 宽，参考播放器控制面板音频页样式：竖向均衡器 14×70、预设弹出菜单）；`均衡器`（勾选）Shift+E；`预设 ▶ 平直/人声/音乐/影院`（单选）；`复位`。没有选中的音轨时编辑命令禁用。菜单操作在视频左上角显示屏幕提示（“均衡器: 开”“均衡器预设: 人声”“音频处理已复位”）。处理失败时窗口显示“音频处理失败”（悬停看原因）与“重试”。

限制：不负责基础音量、静音与播放控制（属于播放栏）；“已应用”表示宿主接受，不保证已听到效果；插件停用时宿主撤销本插件的处理资源。

开发（在 `src/` 下）：`npm run plugin -- check audio`、`build audio`（生成 `dist/`，版本取自 `manifest.json`）、`test audio`。
