# 快捷键设置（vestra.hotkeys）

依据：doc/product/feature-requirements.md「快捷键设置（`hotkeys`）」J01–J03；裁决 R-K1、R-K2、R-K3。只和播放器的绑定表对话（`plugin.bindings`，能力 `bindings.manage`），不知道也不调用别的插件；新装、停用的插件的命令随 `bindings.onChange` 出现、消失。

## J01 快捷键设置（`keys-window.ts`、`ui/keys.slint`）

600×460（最小 520×380）。顶部：搜索（命令文字或按键，`Ctrl+` 找出全部 Ctrl 组合）、状态筛选（全部 / 已修改 / 有冲突 / 未绑定）、来源筛选（全部来源 / 宿主 / 各插件 id / 未加载的插件）。列表五列：命令 自适应 / 快捷键 140 / 范围 50 / 来源 120 / 状态 50，行高 18，点「命令」「快捷键」表头排序。

- 状态：`冲突`（有输入被别的命令压下，悬停与选中时写明占用者）、`已忽略`（J03 写下的空覆盖，快捷键列用括号显示默认键）、`已修改`、`默认`。快捷键列只列键盘绑定（用播放器给的 `labels`）。
- 编辑区：所选命令的全部绑定（含鼠标）为标签，`×` 删除；`添加按键…` 进入捕获，捕获框显示「请按下快捷键（Esc 取消）」，单独按修饰键不结束，Esc 取消，要绑 Esc 用旁边的 `Esc` 按钮；`恢复默认`、`全部解绑`。每条命令最多 8 个绑定。
- 捕获转换（`keys.ts` 的 `fromSlintKey`，与 `bindings.rs` 同一规则）：⌘ 与 ⌃ 都写成 `Ctrl`；⌃ 字母以控制码到达时按字母（⌃I = `Ctrl+I`），⌘ 保留命名键（⌘⌫ = `Ctrl+Backspace`）；符号不带 Shift（Shift+/ = `?`），`+` 写 `Plus`；Option 打出美式 Option 层字符时还原为键（⌥O `ø` = `Alt+O`，⌥⇧. = `Alt+>`），打出其它符号时就是该符号（德语 ⌥5 `[` = `[`，与播放器「字符优先」一致）。最终以 `bindings.set` 的校验为准，`invalid` 显示「无法使用此按键」。
- 冲突：同一范围内已被别的命令使用（macOS 上 `Ctrl+X` 与 `Cmd+X` 算同一键）时，编辑区换成确认条「Space 已用于『播放 ▶ 播放/暂停』」`替换` / `取消`；对方是「退出」时写「⌘Q 是退出 Vestra 的默认快捷键，确定改为……？」。替换 = 先从对方去掉这个键，再加到本命令；第二步失败时把第一步改回去（对方原来没有覆盖时用 `reset`）。结果等于默认值时写 `reset` 而不是覆盖。另一范围（面板）用着同一键时只提示。
- `恢复全部默认…`（`dialogs.confirm`，破坏性）清空整个覆盖层（含未加载插件的条目）；`导出列表…` 存为 `.csv`（UTF-8 BOM）或纯文本。
- 未加载的插件（`orphans`）只在来源筛选选「未加载的插件」时显示，`删除此条` = `reset(ref)`。
- 每次修改后 OSD「快捷键已更新：播放 ▶ 播放/暂停 = Space, K」。
- `hotkeys.json`：`{ version: 1, sort, descending, status, source }`（排序与筛选）。

## J02 鼠标动作（`mouse-window.ts`、`ui/mouse.slint`）

540×410。修饰键单选（无 / Ctrl / Alt / Shift / Cmd），11 行：标签 140 右对齐 + 命令选择 320×21 + `默认` 41×18，行距 26。命令选择点开后在表格位置显示可过滤的全局命令列表（一百多条，下拉框放不下），首项「（无）」。

- 选命令 X：先从当前占用者去掉该输入，再加给 X；「（无）」只做第一步。`默认`：声明该输入的命令拿回它（与默认相同时 `reset`），别的占用者去掉它。
- `Mouse:LeftClick` 可绑定；窗口底部说明单击要等过系统双击间隔。右键固定给菜单，不列出。
- OSD「鼠标动作已更新：滚轮上推 = 声音 ▶ 音量 +」。

## J03 忽略默认快捷键（`ignore.ts`，裁决 R-K2 的替代方案）

没有播放器开关。打开（先 `dialogs.confirm`）时，对每条仍按默认绑定运行（`!overridden && defaults.length`）的命令写空覆盖 `set(ref, [])`，并在 `ignore-defaults.json`（`{ version: 1, enabled, written: BindingRef[] }`）记下写过的条目；宿主的「退出」「退出全屏」不动。

- 开关打开期间：`bindings.onChange` 后再对齐一次，新加载 / 启用的插件的默认键随即失效（之前有一次 RPC 往返的窗口）；用户在 J01/J02 改过的条目从记录中移除（关闭开关时不还原），在别处改成非空的同样移除；被别处 `reset` 的条目重新写空。
- 关闭：只对记录中仍是空覆盖的条目 `reset`，清空记录。
- 启动时对齐：开关为开时补写这期间新出现的命令；开关为关但记录不空（上次关闭没做完）时补完还原。
- hotkeys 停用或卸载后写下的空覆盖留在覆盖层（默认键继续失效，菜单不再有开关），重新启用 hotkeys 后可关闭。这是裁决接受的代价。

## 已知限制

- 捕获在工具窗口里进行，拿不到物理键：小键盘按键捕获为主键盘名（`5` 而不是 `Numpad5`）；⌃P–⌃X 的控制码与 Slint 的修饰键码相同，捕获不到，用 ⌘ 代替（`Ctrl+` 绑定 ⌘ 与 ⌃ 都触发）；Option 死键在没有文字时捕获不到。
- 被系统截走的键（⌘Tab、⌘Space、⌃↑）与应用菜单的 ⌘ 组合捕获不到。
