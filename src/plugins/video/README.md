# 画面调节（vestra.video）

功能：亮度、对比度、饱和度、Gamma、高斯模糊、四个预设与复位，作用于本插件自有的视频处理链；“启用画面效果”关闭时只清空本插件的处理链，不影响其它插件。改动立即生效，每行有独立的“默认”按钮。

入口（右键菜单 `视频 ▶`，order 401–409）：`画面调节…` 打开独立窗口（`picture.slint`，301 宽，PotPlayer 控制面板视频页样式）；`复位` Q；`亮度 -1% / +1%` W / E；`对比度` R / T；`饱和度` Y / U（按住重复）；`高斯模糊`（勾选）Ctrl+B。菜单与按键操作在视频左上角显示屏幕提示，例如“亮度 +1% (+5%)”。关闭窗口保留设置和效果；插件停用时宿主撤销本插件的处理资源。

限制：没有就绪媒体时保留设置，媒体就绪后应用；处理失败时窗口底部显示“画面处理失败”（悬停看原因）与“重试”。工具窗口里不触发快捷键（宿主规则）。

开发：`npm run plugin -- check video`、`build video`（生成 `dist/`，版本取自 `manifest.json`）、`test video`。代码只用 `import type` 引用 SDK。
