# 画面调节（vestra.video）

功能：亮度、对比度、饱和度、Gamma、高斯模糊、四个预设与复位，作用于本插件自有的视频处理链；“启用画面效果”关闭时只清空本插件的处理链，不影响其它插件。

入口：`视频 → 画面调节…` 与 `视频 → 高斯模糊…` 打开同一个独立窗口（`picture.slint`），不占底栏或侧栏。隐藏窗口保留设置和效果；插件停用时宿主撤销本插件的处理资源。

限制：没有就绪媒体时保留设置，媒体就绪后应用；“已接受”表示后端接受，不保证画面已刷新（暂停时可能在继续播放后才更新）。

开发：`npm run plugin -- check video`、`build video`（生成 `dist/`，版本取自 `manifest.json`）、`test video`。SDK v2 参考迁移，代码只用 `import type` 引用 SDK。
