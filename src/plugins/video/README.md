# 画面调节（vestra.video）

功能：色彩（亮度、对比度、饱和度、色调、Gamma，四个预设与复位）、图像处理（高斯模糊、锐化、边缘锐化、3D / 渐进 / 瞬态降噪、去块、消色带）、翻转与旋转、反交错（BWDIF：自动 / 总是使用 / 不使用，按帧或按场输出）、裁剪/拉伸到 4:3…2.35:1，作用于本插件自有的视频处理链 `picture`。链的顺序固定：反交错 → 裁剪/加边 → 翻转旋转 → 降噪 → 去块 → 消色带 → eq → 色调 → 锐化 → 边缘锐化 → 高斯模糊（最长 13 个节点）。“启用画面效果”关闭时只清空本插件的处理链。

入口（右键菜单 `视频 ▶`）：`像素着色 ▶`（402，禁用：需要 GPU 渲染）；`反交错 ▶`（403，按序切换 Ctrl+I、三种模式、`输出 ▶`）；`裁剪/拉伸 ▶`（405，不使用 / 按比例拉伸 / 按比例裁剪、位置复位与上下左右移 5%）；`图像处理 ▶`（408，上下翻转 Ctrl+P、左右翻转 Ctrl+Z、高斯模糊 Ctrl+B、锐化 Ctrl+R、边缘锐化、去块 Ctrl+H、消色带、3D 降噪 Ctrl+N、渐进降噪、瞬态降噪 Ctrl+M；倍帧、运动补偿禁用）；`图像旋转 ▶`（409，按序切换 Alt+K、不旋转 / 90° / 180° / 270°）；`画面调节…`（440）、`复位` Q（441）、亮度 W/E、对比度 R/T、饱和度 Y/U、色调 I/O（442–449，按住重复）。菜单与按键操作在视频左上角显示屏幕提示，例如“色调 +1% (+5%)”“锐化: 开”“图像旋转: 90°”“反交错: 自动”“裁剪/拉伸: 按 2.35:1 裁剪”。

窗口（`picture.slint`，301×245，四个页签，记住上次的页签）：「色彩」五行滑块与预设；「效果」六行“开关 + 强度 + 默认”（降噪行带 3D / 渐进 / 瞬态下拉）与禁用的倍帧、运动补偿；「画面」翻转、旋转按钮与裁剪/拉伸下拉，宽高比、显示、缩放三行置灰（需要第 4a 轮的显示层接口）；「高级」反交错模式与输出，HDR、着色器两行置灰（需要 GPU 渲染）。底部状态行：“启用画面效果”、失败时“画面处理失败”（悬停看原因）或“当前来源没有画面”与“重试”。

生效方式：eq、色调、高斯模糊拖动时连续生效；锐化、降噪、去块、消色带的强度滑块只在松开时提交（这些滤镜改参数要重建）。

设置：色彩、效果、反交错、裁剪/拉伸与页签跨文件、跨重启保留，存在 `<dataDirectory>/settings.json`（`plugin.storage.json`，`version: 1`；读坏的文件改名为 `settings.json.bad-<时间戳>`，未知版本按默认值启动且不覆盖原文件）。翻转与旋转只属于当前来源，换来源时静默复位。

限制：没有就绪媒体时保留设置，媒体就绪后应用；按场输出时若 5 秒内丢帧超过 5%，每个来源提示一次。工具窗口里不触发快捷键（宿主规则）。未做：按宽高比自动旋转（`stats()` 的宽高未经宿主的方向处理）。

开发：`npm run plugin -- check video`、`build video`（生成 `dist/`，版本取自 `manifest.json`）、`test video`。代码只用 `import type` 引用 SDK。
