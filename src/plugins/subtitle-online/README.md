# 在线字幕（vestra.subtitle-online）

依据：doc/product/feature-requirements.md「在线字幕（`subtitle-online`）」D16。按当前视频搜索在线字幕，下载后以 `subtitles.load` 载入为本插件拥有的轨；字幕插件从字幕状态看到这些轨，两者不通信。

## 服务与密钥

- OpenSubtitles.com REST API（默认启用）：每个请求带用户自己的 `Api-Key` 与 `User-Agent: Vestra v0.1.0`；用户名、密码可选（登录得到的 token 只在内存里）。没有随插件发布的密钥。
- 射手网(伪) assrt.net（默认关闭）：用户自己的 token。
- **没有密钥时不发任何请求**：「搜索与下载字幕…」直接打开设置窗口并说明如何申请。首次搜索前在下载窗口提示「搜索会把文件名关键字与文件哈希发送给所选服务」，同意后才发送（记在设置里）。
- 密钥与密码存系统的密钥存储（`plugin.secrets`：macOS 登录钥匙串、Windows 凭据管理器，服务名 `vestra.subtitle-online`，与旧版写入的钥匙串项相同）；系统没有可用的存储（`unsupported` / `unavailable`）时存 `<dataDirectory>/secrets.json`（0600），没有数据目录时只在本次运行内记住。设置窗口写明位置。

## 行为

- 搜索：本地文件发送 moviehash（大小 + 头尾各 64 KiB）与文件名关键字（去掉分辨率、编码、片源等标记）；网络来源只用标题。「按标题搜索」只用标题框的文字。每个请求 15 秒超时；`fetch` 在插件进程内执行。
- 排序：哈希匹配 → 人工翻译先于机翻 → 首选语言顺序 → 下载次数。「仅查找与文件完全匹配」只留哈希匹配；「排除关键字」按版本名过滤。「更多」加载下一页。
- 打开字幕（双击）：下载 → 解开 zip（插件内实现，多个字幕文件时弹窗选择；rar/7z 提示不支持）→ 按 `formats.ts`（与 subtitles 同一份）识别格式与编码 → `load({ format, title: "<语言> · <版本名>", select: "primary" })`；同时保存一份到视频旁 `<视频名>.<语言>.<扩展名>`（不覆盖，加 ` (1)`），不可写或网络来源时存 `<dataDirectory>/downloads/`。「添加字幕」逐条 `select: "none"`；「直接保存」只保存；「另存为…」用保存对话框。
- 失败：配额用尽（406/429）OSD 与重置时间；401/403「API 密钥无效…」；网络错误「无法连接 <服务>」，其它服务的结果照常；无结果「没有找到字幕，可修改标题后再搜索」。关闭下载窗口或换片源会中止进行中的请求，不会载入到新片源。
- 自动搜索（默认关）：打开没有文本字幕轨的本地视频时后台搜索；首条是首选第一语言的哈希匹配时，按「搜索后」显示下载窗口或自动载入（OSD「已自动载入在线字幕：…」）。插件启动时已在播放的来源不搜索。

## 限制

- 「网页中打开」未实现：`plugin.system.openPath` 只接受存在的本地路径，打开网址需要新的通用能力（已提请求）。
- 不做上传字幕、网页字幕搜索链接。

## 文件

`settings.json`（`plugin.storage.json`）：服务顺序与开关、首选语言、自动搜索、搜索后动作、仅哈希匹配、排除关键字、保存位置、OpenSubtitles 用户名、隐私提示已确认。

开发（在 `src/` 下）：`npm run plugin -- check|build|test subtitle-online`。
