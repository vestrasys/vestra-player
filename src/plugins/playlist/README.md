# 播放列表（vestra.playlist）

功能：右侧栏播放列表（PotPlayer 样式，见 `doc/product/ui-alignment.md` §5）。31px 页签条（分离/附着、关闭按钮），单行 20px 列表项「序号. 标题」+ 右对齐时长，正在播放蓝色、播放过灰色、选中深色底，失败行尾警示图标；完整路径（及失败原因）为悬停提示，操作反馈用屏幕提示。底部 35px 按钮栏：置顶/上移/下移/置底、ADD（添加文件/添加链接）、DEL、SORT（按名称/按路径/倒序）与已知时长合计。多文件添加（`realpath` 去重，不可读的文件保留待重试）、添加 HTTP(S) 链接（只选中、不播放）；行使用稳定的 `rowId`。多选（Ctrl/Cmd、Shift 点击，Ctrl+A）、拖动排序，移除和移动作用于所选。自然播完后按当时顺序推进一次；循环（不循环/全部/单个）与随机默认关；若播完后来源被别处改动，自动推进放弃。另开的来源（即使路径相同）不接管、不提示。登记为播放序列提供者，`player.next/previous`（底栏、PgUp/PgDn）由本插件执行。

入口：右键菜单顶层「播放列表 ✓ F6」（windows 组 800）；「打开 ▶ 打开文件夹…」（110，F2）；「播放 ▶ 播放列表 ▶ 添加文件… / 添加链接… / 添加文件夹… / 循环 ▶ / 随机 / 打开列表文件… / 保存列表… / 打开文件时 ▶ / 快速推进到下一个 / 记住列表 / 移除全部前确认」（230–244）。列表右键菜单与列表焦点下的按键：Enter/P 播放、Ctrl+I 添加文件、Ctrl+O 添加文件夹、Ctrl+U 添加链接、Delete/Backspace 移除所选、Ctrl+Delete 移除未选、Ctrl+T 移除无效项、Alt+Delete 移除全部、Ctrl+F 在 Finder 中显示、Ctrl+A 全选、Ctrl+S 搜索、F3 打开列表文件、F2 保存列表、F6 关闭列表；SORT 弹出菜单：Ctrl+1/2 正序/反序，Ctrl+3…0 按标题/文件名/扩展名/大小/时长/日期/乱序/文件夹，另有按路径、倒置当前顺序；Ctrl+↑/↓/Home/End 移动；↑/↓（加 Shift 扩选）、Home/End 移动选择；双击播放。链接对话框 `ui/link.slint` 是工具窗口（UI-DLG-02「输入链接」规格，宽 464，用宿主的 `UrlInputRow`，与 playback「打开链接…」同一组件：多行输入、回车 = 添加、Shift+回车换行、Esc = 取消；每行一个链接，按顺序加入，遇到无效行停在那里并提示「第 N 行：原因」，窗口不关），侧栏是 `ui/sidebar.slint`（底栏含搜索框）。界面颜色全部取自 `Theme`（搜索框底色 `Theme.hover-bg`），没有硬编码颜色。

功能（features-r1）：打开/添加文件夹（递归 8 层、上限 5000、按文件夹自然序、`realpath` 去重，`media.ts`；「打开文件夹…」默认先清空列表）；打开文件时（A13 / IA-PL-01，`follow.ts`，只对别的插件打开的本地文件）：默认先清空列表，再按 PotPlayer 静态逆向的同类文件规则加入同文件夹的相似文件（默认）/ 同组全部文件 / 仅该文件，接管打开的文件的行继续推进；规则在 `media.ts` 的 `siblings` / `similarStep`（四步 S1–S4、视频配视频、音频配音频、跳过 `.` 开头、超过 5000 个匹配时截取），17 组用例见 `tests/similar.test.ts`；「打开或拖入时追加，不清空列表」打开时改为追加去重；移除未选/无效项；更多排序；M3U/M3U8/PLS 读写与 DPL 只读（`listfile.ts`，打开时替换列表）；搜索过滤；在 Finder 中显示（`plugin.system.reveal`，每个文件夹显示第一个仍存在的所选文件，都不在时 `openPath` 打开文件夹）；重启后恢复列表与设置（`plugin.storage.json`：`<dataDirectory>/playlists.json`，ffprobe 缓存 `probe-cache.json`，`store.ts`；读坏或版本不对时改名为 `.bad-<时间戳>` 并用默认值），列表上限 20 000 行。

快速推进到下一个（B26，features-r2，默认关，`settings.gapless`）：当前行打开后提前算出自然播完后的下一行（随机时预先抽定），并对它做 `realpath` + `stat`；列表变化（重排、移除、循环/随机切换）时重新准备。自然结束时 `onEnd` 里直接 `open` 一次，不再读盘；准备时发现文件已不存在则屏幕提示「无法打开 <标题>：文件不存在」、该行标为失败并推进到再下一行。不是无缝播放：切换仍有一次 `open`（目标「同格式切换 < 150 ms」）。准备之后才被删除的文件按普通失败处理。`VESTRA_PLAYLIST_TIMING=1` 时每次自动推进在 stderr 打印「结束→open 被接受」「结束→新来源 ready」的毫秒数。

时长：添加本地文件后经 `plugin.tools.run("ffprobe", …)` 读取（查找、不经 shell、超时与中止由 SDK 负责；参数 `-v error -show_entries format=duration -of json <路径>`，输出上限 64 KiB）。最多同时 2 个进程，每个 10 秒超时；移除该项或清空列表时中止其进程（名额立即让给下一项）；结果按 realpath + mtime 缓存。链接行从不读取。某项开始播放后以播放器报告的时长为准。ffprobe 缺失或失败时该项显示 `--:--`，合计只加已知时长并在末尾加「+」（有未播放的链接行时同样加「+」）；不弹屏幕提示、不算错误。测试用 `host.tools.handle("ffprobe", …)` 注入结果，不调用真实 ffprobe。

限制：面板右键菜单只有一层，「排序 ▶」展开为三项。链接由站点插件注册的公共来源解析器打开，本插件不解析。移除/清空和插件停用都不关闭当前媒体。拖放（A15，`drop.ts`，能力 `ui.drop`）：`drops.provide` 登记媒体扩展名、`m3u m3u8 pls dpl`、`webloc` 与 `"folder"`；拖到视频区时文件夹按 A03 扫描、列表文件按 C18 解析、`.webloc` 取其 HTTP(S) 链接（XML 或二进制 plist，插件内纯 JS 解析）、媒体直接收，按文件管理器给出的顺序拼接；有可加入的项时先清空列表（不确认，G-11），再加入并播放第一项；设置「打开或拖入时追加，不清空列表」开着时改为去重追加并播放第一个新项（全部重复时播放第一项对应的已有行）；正在打开别的来源时不清空、只加入；按住 Option 只追加、不清空、不播放。拖到侧栏（`Panel.onDrop`）只加入，默认追加到末尾（G-12）；设置「拖到列表时插入到拖放位置」开着时插到落点所在行之前（侧栏用 `list-area` 回调回传滚动距离与列表区高度，行从面板 y 31 起、每行 20），空白处、页签条、底栏仍追加到末尾；不支持的文件跳过并在提示中注明；没有插入线（核心不提供拖动中的位置）。多次拖放依次处理。真正的无缝播放（预读）被裁决拒绝（R-P5），B26 降级为快速推进。确认用系统确认框（`plugin.dialogs.confirm`，作为主窗口的表单）：打开列表文件替换非空列表时「用 <文件名> 替换当前列表？」[替换] [取消]；「移除全部」（Alt+Delete）时「移除播放列表中的全部 N 项？」[移除全部]（红字）[取消]，带「不再询问」复选框，确认时勾选则记入 `playlists.json` 的 `settings.confirmClear`（取消时勾选不记）；勾选项「播放 ▶ 播放列表 ▶ 移除全部前确认」（options 组 244，默认勾选）就是这个设置，可把「不再询问」恢复。另一个对话框还开着（`busy`）时提示「请先关闭另一个对话框」且不执行。移除所选 / 未选 / 无效项不确认。

设置页（IA-PL-02，能力 `ui.settings`）：「选项 ▶ 播放 ▶ 播放列表」（`ui/settings.slint`）：打开文件时（三选一）、打开或拖入时追加不清空列表、拖到列表时插入到拖放位置、循环、随机、快速推进到下一个、记住列表、移除全部前确认，与菜单双向同步，存在 `playlists.json` 的 `settings`（`appendOnOpen`、`dropAtPointer` 默认关）。列表获得焦点时 F5 打开该页（命令「播放列表设置…」，`focus: "panel"`）；没有焦点时 F5 仍是全局「选项…」。

自动滚动（G-08）：键盘移动光标（↑/↓、Home/End、Shift 扩选、搜索框 ↓、Ctrl+↑/↓/Home/End 移动）后光标行完整可见，按最小距离滚动（在上方时成为第一行，在下方时成为最后一行）；正在播放的行变化时，它不在视野内则滚到居中（被搜索筛掉时不滚），用户 2 秒内滚动过则不动。插件经桥接的 `scroll-to-y` / `scroll-request` 让侧栏设置 `viewport-y`。拖动排序时指针进入列表上 / 下边缘 20px 内，侧栏用 `Timer` 每 50 ms 滚 1 行（越近越快，最多 3 行），不经插件。

开发（在 `src/` 下）：`npm run plugin -- check playlist`、`build playlist`、`test playlist`。只用 `import type` 引用 SDK。
