- The vendored SDK is 1.7.1 (`npm run vendor:sdk`), the version the player now uses; 1.7.1 only refreshes the built-in command table over 1.7.0. Who must change: nobody. ## 2.2.23

- The AI reads the SDK documentation with two new tools, `docs(path)` and `docs_search(query)`, backed by the SDK's documentation tree (`@vestra-player/sdk/docs`, SDK 1.5.50): pages read by path like `go doc`, from `/` (Overview, Guides, API) down to one declaration (`/API/Media/Snapshot/export`: signature, parameters, errors, capability, player version, examples), a name alone finding its declaration (`Snapshot.export`), a search by words whose best match comes first ("add a menu item" → `/API/Commands/Commands/add`), and every answer at most 8 KB with further pages on request (`page`). The system prompt tells the AI to start at `docs /`, drill down by path, search when unsure and read the vendored `.d.ts` only for exact types. The tools load the vendored SDK's copy (`vendor/@vestra-player/sdk/dist/docs.js`, which reads `dist/docs-tree.json.gz` next to it inside the plugin folder the agent process may read), so they work the same in the packaged player. The window names them "Docs" and "Search docs".
- The vendored SDK is 1.5.50 (`npm run vendor:sdk`), the version the player now uses. Who must change: nobody. It no longer has `llms-full.txt` (the 1 MB file the AI could not read; see below), and `llms.txt` is a short entry that points to the tree; `tests/vendor-sdk.mjs` now requires `dist/docs.js` and `dist/docs-tree.json.gz`. No change to the plugin's own behaviour; `minPlayerVersion` stays 0.5.10.
- `grep` no longer pretends a file it could not search has no matches. A file over the tools' 1 MB limit was skipped silently, so a search of the SDK reference, whose `llms-full.txt` passed 1 MB with SDK 1.5.48, answered "No matches found". The result now names each skipped file ("skipped <path>: larger than 1.0 MB", a binary file it was pointed at, a walk stopped at 5000 files), and says "No matches found in the files searched" when nothing else matched. `read`'s refusal gives the limit and the file's size, and checks the size without reading the file first. The 1 MB limit stays: the AI writes every project file whole, so a larger text file is runaway output, not source. The SDK reference itself is now the documentation tree read with the docs tools (above).
- Conversations can be deleted, as in other chat apps: a delete button (×) on the hovered or open conversation in the sidebar, **Delete Chat** next to Open Folder for the open one, and Ctrl+Shift+Backspace (⌘⇧⌫ on macOS, as in ChatGPT). A confirmation names the conversation and says what goes: its messages and the plugin projects made in it (the session folder: record, `work/`, packed `.vxp` files in `dist/`); files exported elsewhere stay. Plugins this conversation installed stay installed (the player owns them) and the confirmation lists them; each install from a conversation is now recorded in its `meta.json` (`installed`), so a plugin of the same id installed from elsewhere is not counted. A run in the conversation stops first; deleting the open conversation shows a new, empty chat; a message sent or a tool that finishes while the conversation is deleted does not bring it back. A delete that fails says so in the conversation shown, and a conversation whose `meta.json` survived stays in the list. There is no undo.
- Reasoning models think again. Custom endpoints registered their model with `reasoning: false` and every session ran with thinking off, so a reasoning model such as MiniMax-M3 wrote its reasoning as ordinary replies (one session: 79 messages of 3–7k characters). Now the thinking level is **Low** by default (Settings ▸ Thinking: Off / Low / Medium, with the note that thinking tokens are billed like the answer); pi's catalog says which of its models reason, and for a custom endpoint only ids of clear reasoning models do (MiniMax M, DeepSeek R1 / reasoner, QwQ, o-series, GPT-5 but not its chat variant, gpt-oss, Claude 3.7 and 4+, Gemini 2.5+, Grok 3 mini, Magistral, ids with "thinking" or "reasoning" but not "non-reasoning" or "instruct"); hybrid families (Qwen3, DeepSeek V3.x, GLM, Kimi K2, Grok 3/4) default to no thinking. **This model can think before it answers** in the settings overrides it. An endpoint that refuses the reasoning parameters gets its own error, with Open Settings, naming both settings. A custom reasoning model gets 16384 output tokens, so the thinking budget (2048 low, 8192 medium) leaves room for the answer and its tool call. A change of thinking, model or key applies to the next message also when the agent was generating at the time (a new agent process continues the conversation). An unknown thinking level in the saved settings means Low instead of resetting the settings.
- Thinking and the notes the AI writes between tool calls are one collapsed line per turn, "Thought for 12 seconds" (or "3 progress notes" without thinking, "Thought process" for older conversations, whose thinking is shown the same way); a click, or Space / Enter once Tab reached it, shows them dimmed; screen readers see an expandable button. The answer is what the AI wrote after its last tool call; a turn that ends without one (the summary came with the last tool call, Stop, a timeout, an error) shows its last note as the answer. A collapsed line sends no text to the window, so long thinking costs the conversation list nothing. This replaces the rule that hid one short opening line.
- A `vestra.*` id the player refuses as `reserved` (at validation or at install) reads as a built-in plugin's name, as `unsupported` did.
- Tests: `docs` and `docs_search` on the real vendored tree (the root, a member, a name alone, the best search match, pagination) and through the agent's restricted process in the eval harness (docs `/`, a search, a member page); `grep` and `read` over a project file over 1 MB, thinking from a mock Anthropic and OpenAI endpoint (levels, the check box, a change during a run, which ids reason), the reasoning-parameter error, a turn without an answer, deleting conversations (a running one, a failed delete, what a conversation installed), the `reserved` refusal; and `tests/host-install.test.mjs`, which installs a scaffolded, packed plugin into a real headless player in a throwaway profile (validateArchive, then install with source `workshop`, as delivery.ts does), skipped unless `VESTRA_HOST_EXE` names a player binary.
