# 插件工坊（实验性）

让本地模型为你生成一个小插件，先校验、试载，满意了再安装。

## 怎么用

1. 右键菜单选「插件工坊…」。
2. 点「选择工作区…」，选一个专用的空文件夹。每次生成都放在里面新的子文件夹中。
3. 在需求框里填写或用「选择需求文件…」读入需求，点「生成」。日志里能看到模型写文件、类型检查报错、修复的全过程。
4. 播放器校验通过后，可以：
   - 「试载」：临时加载，测试完点「停止试载」；
   - 「安装此版本」：正式安装。生成过程不会自动安装；
   - 「回退上一版本」：回到上次安装的版本。
5. 任何时候都可以点「取消任务」中止生成、试载或安装。

如果已经从别处（例如本地文件）装过同 id 的插件，安装时会询问是否替换。替换后新插件从空数据开始，原插件的数据仍然保留；选择取消则什么都不改，候选留着以后再装。与播放器内置插件同 id 的不能安装，需要改 id 后重新生成。

## 目前能生成什么

只有一种计数器插件，id 默认是 `workshop.counter`：

- `{"kind":"native-counter","id":"workshop.counter","version":"1.0.0","step":1}`：每次加 1；
- 把版本改成 `1.1.0`、步长改成 `3`：每次加 3，可用来体验升级与回退。

## 说明

- 模型是本地模拟的，不联网，不读取任何凭据，也不产生费用。
- 生成的插件是普通插件，可以在「插件管理」里停用或卸载。
- 工坊仍是实验性功能，需求格式和流程以后可能改变。
- 第三方组件的许可证见 `licenses/`。
