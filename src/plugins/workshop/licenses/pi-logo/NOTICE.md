# pi logo

`assets/pi-logo.svg` is the official pi logo, used unchanged to credit pi
("powered by pi") in the Vestra Player AI window, with a link to the project.

- Source: https://pi.dev/logo-auto.svg, the logo shown at the top of the pi
  README (https://github.com/earendil-works/pi). Downloaded 2026-10-24,
  sha256 `abd66e7868b2d24f0f0895f9237ee8a6dcb22337583b0dc54aeb595acecb4d6b`.
- The file has fixed colours (#F09082, #4D9ABF, #F1BE58); no colour-scheme
  variants are needed.
- pi is MIT-licensed (see `licenses/@earendil-works__pi-coding-agent/LICENSE`).
  The logo identifies the pi project and its authors (Mario Zechner,
  Earendil); it is shown only as attribution, not as Vestra Player's own mark.
