# 画面调节：实验插件探针

此插件用于验证实验架构；公共 API、manifest 与代码组织可能与最终产品相差很大。

## 有限场景与预期

1. 单独安装后使用 Slint 调节亮度、对比度、饱和度、色相；TS 不接收视频帧，也不实现像素算法。
2. 明亮与影院预设一次提交一组参数；复位撤销本插件处理。亮度菜单增减与面板共享同一份状态。
3. 一个插件贡献多处菜单入口，而不是把所有功能塞入专属子菜单；不定义另一套控件编排 API。
4. 无效输入拒绝并显示错误；后端失败保留最近成功状态，不显示假成功。
5. 本插件与另一视频处理 owner 并存；复位、停用只移除自己的资源。
6. 所有其他探针不存在时仍可激活、调节、清理。

## 实验契约与实现

采用公共契约 probe-0.2 的兼容子集，在当前 probe-0.3 宿主回归，不需要迁移调用；见[基线登记](../../sdk/baselines/README.md)。TS 调用 `ctx.effects.set({key:'adjustments',kind:'video',filter})`。插件先检查 `effects.video` 能力，参数通过严格有限数字与范围检查，再构造 FFmpeg `eq` 和 `hue` 表达式。表达式经 argv 传给后端，不是 shell 命令。算法不由 TS 实现。

| 参数       | 范围        | 默认值 |
| ---------- | ----------- | ------ |
| 亮度       | -1 至 1     | 0      |
| 对比度     | 0 至 2      | 1      |
| 饱和度     | 0 至 3      | 1      |
| 色相（度） | -180 至 180 | 0      |

明亮预设：`0.12 / 1.08 / 1.05 / 0`；影院预设：`-0.04 / 1.18 / 0.85 / -3`。这是演示参数，不是画质推荐。菜单亮度以 0.05 调整，到边界停止；直接输入越界则拒绝。

菜单入口分布在 `视频 → 画面调节`、`视频 → 画面预设` 与 `工具 → 复位`；它们和 Slint 控件都调用同一 `onAction` 行为。界面状态只在宿主接受处理请求后更新；最近成功参数保留在 TS，UI 重建无需重启逻辑。预设是一次资源替换，复位移除自身 `adjustments`，不会清空整个处理链。

这是持久视频默认效果，切换文件仍保留；停用先注销动作再移除资源，宿主还应在异常退出时回收 owner。没有跨插件通信，也不要求先安装文件播放或高斯插件。

## 可复现验证

仓库根目录执行：

```sh
node --test src/tests/probes/video-adjust/*.test.ts
```

参数与行为测试 7 项通过；加上真实 Rust/Node/FFmpeg 集成共 8 项通过（root 重跑）。集成通过独立解码的 PNG 证明亮度、对比度、饱和度、色相改变，与其他 owner 的 gblur 组合及复位/卸载只清理自身。可指定 `VESTRA_HOST` 与 `VESTRA_VIDEO_EVIDENCE` 保留证据。模拟 transport 的测试不替代这些真实结果。

真实 Slint 窗口曾由协调者执行加载、菜单亮度调整与截图；最终 G1 组合和独立验收另行记录，不以这八项测试宣称完整验收。
