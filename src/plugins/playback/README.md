# 基础播放（vestra.playback）

功能：主窗口底部播放栏（`ui/bar.slint`）与菜单命令：打开/关闭来源、播放/暂停（播完后“重播”）、进度条拖动跳转、±5 秒、跳转到时间、倍速（预设与 0.25–4 倍自定义）、音量 0–200% 与静音、载入失败后“重试”、显示/隐藏播放栏。

入口：`文件 → 打开媒体… / 关闭当前来源`；`播放 → 播放/暂停（Space）/ 跳转到… / 后退5秒（←）/ 前进5秒（→）/ 速度 → …`；`音频 → 静音 / 音量…`；`视图 → 显示播放栏`。底栏按钮与菜单共用同一动作和启用条件。

结构：`main.ts` 只负责组装；`controller.ts` 播放动作与本地草稿，`commands.ts` 菜单命令表，`bar.ts` 底栏属性与回调，`editor.ts` 编辑弹出框，`format.ts` 时间格式。

限制：

- 拖动是一个手势（`player.scrub()`）：期间任何外部来源变化都会结束手势，之后的拖动点被忽略直到下一次按下；取消只丢弃未发送的点，已被宿主接受的跳转不撤销。
- 编辑框的确认只作用于打开编辑框时看到的来源，来源变化后需重新打开。
- 只有 Space/←/→ 由宿主路由；`打开媒体…` 没有快捷键（宿主尚不支持 Cmd/Ctrl+O）。
- 插件停用时当前播放、已提交的速度/音量/暂停保持不变。

开发（在 `src/` 下）：`npm run plugin -- check|build|test playback`。
