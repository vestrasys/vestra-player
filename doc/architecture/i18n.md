# 多语言（i18n）设计

状态：第 1 轮已实现（播放器 0.4.3、SDK 1.5.9）；第 2 轮的文字值（§7.1）已实现（SDK 1.5.11，分支 `i18n/r2-api`）。裁决与进度见 [2026-10 轮记录](../process/rounds/2026-10-i18n.md)；插件作者看 SDK 的《Translate a plugin》《Migrate a plugin to English source text》（`docs/how-to/i18n.md`、`i18n-migration.md`）。

## 1. 原则

- 所有界面文字以**英文为原文**，其它语言是翻译。界面语言 7 种：`en`、`zh-Hans`、`ja`、`ko`、`de`、`fr`、`es`（`i18n::LOCALES`，SDK `LOCALES`，一致性由 host-agreement 测试检查）。没有繁体中文。
- **只在启动时决定语言**，整个运行期间不变；选项里改语言，下次启动生效。所以不需要 Slint 的运行时翻译器，也不依赖 i-slint-core 内部接口。
- **插件 TS 里不写翻译代码**。用户看得到的文字只出现在三处，由播放器用该插件自己的词典翻译：
  1. 声明：命令 `title`、`path` 各段、`reason`，设置页标题，面板/页签标题（含浮动侧栏窗口标题），manifest 的 `name`、`punchline`、`description`、`tags`；
  2. Slint：`@tr("…")`；
  3. 插件交给播放器显示的句子：`osd.show(template, args?)`、`OsdPanel.set(template, args?)`、`dialogs.confirm({ …, args })`、文件对话框的 `title`。
  4. 固定文字与数据分不开时：**文字值**（§7.1）`plugin.i18n.text(source, args)`、`list(items, style)`，是数据不是译文，可以放在上面各处以及属性值、时间轴标题、字幕标题、解析器错误里，由播放器渲染。
- 未翻译的文字显示英文原文（模板照常代入参数）。

## 2. 界面语言的决定

`main()` 在建好 `Host`（读完界面状态文件）之后、注册宿主命令和加载任何插件之前，调用一次 `i18n::init(i18n::resolve(preference, system))`：

1. 环境变量 `VESTRA_LANGUAGE`（开发、测试用；值同下）；
2. 否则界面状态文件 `ui_state.appearance.language`：`"system"` 或某个 locale；读到本播放器不认识的值按 `"system"` 处理（不写回）；
3. `"system"` 或没有：`platform::preferred_languages()`（sys-locale：macOS 系统设置里的语言列表，Windows 用户显示语言，Linux `LANGUAGE`/`LC_*`/`LANG`），取第一个支持的；都不支持用 `en`。无界面模式（`--headless`）不读系统语言，除非设了 `VESTRA_LANGUAGE`，否则是 `en`，诊断输出在每台机器上相同。

标签映射（`i18n::match_tag`，SDK `matchLocale` 相同）：大小写、`_`、POSIX 后缀（`.UTF-8`、`@euro`）不计；`zh` 带 `Hans` 或不带文字、地区不是 TW/HK/MO → `zh-Hans`；带 `Hant`，或地区是 TW、HK、MO → **`en`**（用户裁决：繁体用户看英文，不取下一个语言）；其它按主语言子标签；不支持的语言跳过，看下一个。

插件进程从环境变量 `VESTRA_LOCALE` 得到当前语言，运行器交给 SDK（`Transport.locale`）→ `plugin.i18n.locale`。`window.state` 回复带 `language`（保存的选择）与 `locale`（本次语言）。

保存选择：`appearance.setLanguage({ language })`（需要 `ui.theme`，与配色同属外观）写 `ui_state.appearance.language`（`"system"` 不写字段），广播 `appearance.changed { theme, language }`，**不改变本次语言**。

## 3. 词典

格式是 gettext：

| 文件 | 谁写 | 说明 |
| --- | --- | --- |
| `locales/messages.pot` | `vestra-plugin i18n extract` | 全部原文与位置（`#:`）、给译者的注释（`#.`，来自 `TRANSLATORS:` 注释） |
| `locales/<lang>.po` | 作者 / 译者 | 每种语言一个；`extract` 合并新原文、保留译文、把消失的原文移到末尾作废（`#~`） |
| `dist/locales/<lang>.json` | `vestra-plugin build` | 打包产物，`locales/` 里每个 `<lang>.po` 一个（7 种界面语言即 `zh-Hans`、`ja`、`ko`、`de`、`fr`、`es` 六个）：`{"language":"zh-Hans","messages":{"<key>": "译文" \| ["one","other"]}}`；`.po`/`.pot` 不进包 |

- key 是 `msgid`，有 `msgctxt` 时是 `msgctxt` U+0004 `msgid`。只收录已翻译、非 fuzzy、非作废的条目。
- 复数只分 1 与非 1（与 Slint 无翻译器时相同）：`msgstr[0]` 用于 n == 1，`msgstr[1]`（没有则 `msgstr[0]`）用于其它。中日韩的 `.po` 写 `nplurals=1`，只填 `msgstr[0]`。
- 加载（`i18n::load_locale`）：先 `locales/<lang>.json`（安装的包），没有再读 `locales/<lang>.po`（`--plugin` 开发加载直接跑源码目录）；`en` 永远没有词典；坏文件写一行日志，当作没有。插件进程启动时加载（`Plugin.catalog`），并按包目录登记给 Slint 文件加载器（§4），插件停止时注销。
- 解析器 `src/host/src/i18n/po.rs` 只用标准库，`build.rs` 也引用它（§6）。SDK 的 `src/i18n.ts` 是同样规则的 TS 实现（TestHost、CLI 用）。

### 3.1 机器翻译标记与审校

第 2 轮的 `ja`、`ko`、`de`、`fr`、`es` 五种语言（播放器与全部内置插件）由翻译 agent 机翻，五位译者用的是同一个标记：

- **每个条目一个 gettext 标记 `#, x-machine`**，写在 `msgid` 之前（与 `fuzzy` 同一行时用逗号分隔：`#, fuzzy, x-machine`）：

  ```po
  #. The top-level menu, and the link input's confirm button.
  #: src/commands.rs:327 ui/vestra/widgets.slint:192
  #, x-machine
  msgid "Open"
  msgstr "Ouvrir"
  ```

  它只是给人看的记号：解析器（宿主 `i18n/po.rs`、SDK `parsePo`）只认 `fuzzy`，其它标记忽略，所以 `x-machine` 条目照常编译进词典、照常显示；`vestra-plugin i18n extract` 合并模板时连同译文保留它（`merge` 复制旧条目的 `flags`），原文消失变作废（`#~`）时也带着。`zh-Hans` 是 0.4.2 以前的人写文字，没有这个标记。
- **文件头注释**：AI 审校 agent 审完一个文件后，在文件开头（`msgid ""` 之前）加一行 `# Reviewed by an AI reviewer` 注释（可带日期、范围）。它表示「机翻已经过 AI 复核」，**不**代替人工审校，所以审校 agent 不删 `x-machine`。注意：`vestra-plugin i18n extract` 重写插件 `.po` 时目前只保留头部字段（`msgstr ""` 里的 `Language:` 等），不保留 `msgid ""` 之前的注释行，跑过 extract 后要把这行补回去（SDK 待修，见 §11）；播放器自己的 `.po` 不经 extract，不受影响。
- **人工审校**：懂该语言的人逐条看译文，改正不对的，确认后**删掉该条目的 `x-machine`**（与 `fuzzy` 同行时只删 `x-machine`）。没删的条目就是还没有人看过的。`grep -c 'x-machine' locales/<lang>.po` 看剩多少；整份审完后，文件头注释可以改成写明人工审校者与日期。

## 4. Slint：加载时改写 `@tr`

播放器没有 Slint 翻译器。`ui::compiler()` 给每个编译器设了 `set_file_loader`：每个被导入的 `.slint` 文件（插件的、`@vestra/` 库的）读入后，若有 `@tr` 且该文件所在的包有词典（`i18n::catalog_for`：已登记的包目录取最长前缀；`ui/` 目录用播放器自己的词典），就把 `@tr` 里的原文字面量换成译文，再交给 Slint；Slint 只做格式化（`{}`、`{0}`、`{n}`）和选复数形式。编译起点的源码（`build_from_source`）不经过加载器，由 `ui::translate` / `composition::build` 同样处理（插件窗口、面板、设置页、外壳、选项窗口）。

- 只替换字面量本身：`@tr("ctx" => "id" | "plural" % n, args…)` 的 `id` 与 `plural` 两个字面量；上下文、参数、`%` 表达式原样保留。词典里条目的单复数与调用不符（单数条目对复数调用，或反之）视为未翻译。
- 词法只认识必要的 Slint：`//`、可嵌套的 `/* */`、字符串与其转义（`\" \\ \n \u{…}`）、字符串插值 `"\{…}"`；注释、字符串里的 `@tr` 不动；不合法的调用原样留给 Slint 报错。
- 输出转义：`\` → `\\`，`"` → `\"`，换行 → `\n`，其它控制字符 → `\u{…}`；`{{`、`}}` 原样（Slint 格式化时就是花括号）。
- 共享用例：`src/host/tests/fixtures/slint-tr.json`。宿主 `i18n::tests::slint_tr_cases_shared_with_the_sdk` 与 `tests/sdk/host-agreement.test.ts`（用已安装 SDK 的 `scanSlint`/`rewriteSlint`）跑同一份；SDK 仓库 `test/fixtures/slint-tr.json` 是副本。
- 英文时不读、不改任何文件（没有词典，加载器返回 `None`）。

## 5. 声明与菜单

- 注册命令时（`commands.register`）：先 `commands::normalize` 把路径变成合并用的 **key**（`@video` → `Video`；播放器自己菜单的旧中文标题 → 英文 key，见下表），再 `Declaration::localize_declared` 用插件词典算出显示文字 `display { title, path }`：播放器自己的子菜单用播放器的词（`commands::host_group_label`），其余各段用插件按**声明时的原文**查词典（旧中文标题保持原样显示）。`reason` 每次更新都用插件词典翻译。
- 菜单树按 key 分组和排序；`MenuNode::Group` 带 `label`：播放器的子菜单取播放器的词，否则取组内第一个命令（菜单顺序）的显示文字。菜单行、绑定表（`bindings.list` 的 `title`、`path`）给的都是显示文字；用户的绑定覆盖层按插件 id + 命令 id 保存，与路径无关。
- 播放器自己的命令（全屏、退出、14 个核心动作）的 key 是英文，显示文字用播放器词典。

播放器的菜单 key 与旧标题别名（`MENU_ANCHORS`、`LEGACY_MENUS`，SDK `MENU_KEYS`、`menuKeys` 相同）：

| id | key | 旧中文标题（仍可用） |
| --- | --- | --- |
| `@open` | Open | 打开 |
| `@playback` | Playback | 播放 |
| `@subtitles` | Subtitles | 字幕 |
| `@video` | Video | 视频 |
| `@audio` | Audio | 声音 |
| `@screen` | Screen | 屏幕 |
| `@settings` | Settings | 设置 |
| | Playback ▸ Speed | 播放 ▸ 速度 |
| | Playback ▸ Seek | 播放 ▸ 跳转 |
| | Settings ▸ Appearance | 设置 ▸ 外观（过渡：preferences 已迁移，visualizer 第 2 轮迁移） |

别名只改有下一级的段（子菜单），叶子不改。第 2 轮全部插件迁移后，多插件共用的子菜单靠大家写同一个英文 key 合并；英文 key 由交互负责人登记在 [menus.md](../product/menus.md)「英文菜单 key」（目前：Open ▸ Recently Played、Playback ▸ Playlist、Playback ▸ Chapters and Bookmarks、Playback ▸ A-B Loop、Playback ▸ Resume Playback、Subtitles ▸ Online Subtitles、Video ▸ Snapshot、Emulator、Screen ▸ When Playback Starts、Screen ▸ Always on Top）。

其它声明：设置页标题、面板标题（含默认用的 manifest `name`）注册时翻译后保存；`packages.list` 每项新增 `display { name, punchline, description, tags }`，用各包自己的词典翻译（没在运行的包按需读词典）。

## 6. 播放器自己的文字

- 原文英文，写在代码里：Rust 用 `i18n::tr("…")`、`i18n::tr_args("Back {} s", &json!([n]))`；播放器的 `.slint`（`ui/`）和它生成的 Slint 源码（选项窗口）用 `@tr("…")`。
- 词典：`src/host/locales/messages.pot`（全部原文）与 `zh-Hans.po`（简体中文 = 0.4.2 及以前的界面文字，逐字相同）。`build.rs` 把 `locales/*.po` 编译成 `$OUT_DIR/locales/<lang>.json`（坏文件让构建失败），并生成 `$OUT_DIR/host_catalogs.rs`：`HOST_CATALOGS` 列出每一个编译出的语言及其 `include_str!`，`i18n::host()` 从中取当前语言。加一种语言只要加 `.po`（以及 `LOCALES`），代码里不用改；`every_interface_language_has_an_embedded_host_catalog` 检查 `HOST_CATALOGS` 与 `LOCALES`（除 `en`）完全相同，漏了 `.po` 或多了没有语言设置的 `.po` 都会失败；`host_strings_show_in_every_language` 每种语言查一条。
- `i18n::tests::the_host_template_lists_exactly_the_strings_the_player_uses`：扫描 `src/`（各文件 `#[cfg(test)] mod tests` 之前的部分）里的 `tr(`、`tr_args(` 字面量和 `@tr`，以及 `ui/` 的 `@tr`，必须与 `messages.pot` 完全一致；每个 `.po` 的条目与模板相同，译文的占位符与原文相同。`the_simplified_chinese_catalog_keeps_the_old_texts` 检查核心动作提示等文字与旧版逐字一致。
- 返回给插件的错误消息里，原来是中文、会被插件直接显示给用户的（「没有视频」「侧栏已被 … 使用」「全屏时不可用」…）同样翻译；英文的开发者消息不翻译。

## 7. 模板与参数

`osd.show`、`osd.panel`、`dialogs.confirm` 的 `message`/`detail` 接受 `args`：数组（`{}` 依次取，`{0}` 按序号）或对象（`{name}`），最多 16 个字符串或有限数字（`i18n::valid_args`，SDK `templateArgs` 同样检查）。播放器先查插件词典得到译文模板，再格式化（`i18n::format`，规则同 Slint：`{{`/`}}` 是花括号，没有对应参数的占位符原样保留；整数不带小数）。**没有 `args` 时不格式化**，旧插件的文字原样显示。长度限制（OSD 200 字符、确认框各字段）按显示出来的文字计。确认框的按钮与复选框文字只翻译不格式化；默认取消按钮是播放器的「Cancel」。

参数是数据，不翻译。一个参数本身是固定集合里的词时，应写成每个取值一整句模板（`theme === "x" ? "Palette: X" : "Palette: Y"`），或者用文字值（§7.1）。

### 7.1 文字值（第 2 轮，SDK 1.5.11）

第 2 轮插件作者的请求同一根源：用户看得到的文字里固定词与数据混排（菜单「音轨 2 (opus)」、下拉框「无声音 / 音轨 7 · en」、「下载失败：连接超时」、文件名列表、多个分句），而 TS 不能翻译也不能拼句子。设计与逐条答复在[轮记录](../process/rounds/2026-10-i18n.md)「第 2 轮答复」。

- **wire 形状**（`src/host/src/i18n/text.rs`）：`{"$vestraText": source, "args"?: [...] | {...}}`、`{"$vestraList": [...], "style"?: "list"|"clauses"|"semicolons"|"sentences"|"lines"}`；参数是字符串、有限数字或文字值。不允许别的字段。与 `$vestraImage`、`$vestraMarkdown` 同一约定：Slint 结构体字段不能以 `$` 开头，不会与真实数据冲突。
- **渲染**（`Texts::render`）：`source` 查插件词典（没有则英文），参数先渲染再按 §7 格式化；Text 总是格式化（与 Slint `@tr` 相同）。列表按 `text::SEPARATORS`（每种语言每种 style 一个分隔符，SDK `LIST_SEPARATORS` 相同，host-agreement 检查）连接。
- **语义**：字符串仍然整句翻译（声明）或作为模板（句子）；文字值作为句子时自带参数，外面再给 `args` 是 `invalid`。命令的 Text 段：key = 英文渲染（`Texts::english()`，菜单按它合并、绑定表 `key`），显示 = 译文（`Declaration::show_texts`）；TextList 不能作菜单段。
- **在哪里渲染**：`dispatch` 开头，`ui.open`、`ui.set`、`ui.mount`、`ui.setMount`、`settings.register`、`settings.set`、`timeline.set`、`subtitles.commit` 的参数里有文字值时整体替换成字符串（之后的值上限、长度检查都按显示文字），`sourceResolvers.respond` 的 `error` 同样（后端线程没有插件词典）；`osd.*`、`dialogs.*`、`commands.*` 在各自处理时渲染。
- **上限**：嵌套 8、一个值 1024 个节点、16 个参数、256 项、4096 字节（`TEXT_LIMITS`）。
- **截断**：`osd.panel` 的 `maxColumns`（8–1000）在翻译、格式化之后按 `unicode-width` 截断每行（宽字符 2 列）。
- **`resolve`**：插件进程里的 SDK 用同样的规则和同一份词典（`loadPackageCatalog`）同步渲染，只用于离开播放器的文字（剪贴板、文件）。播放器端不需要配合。
- **兼容**：`vestra/1` 只有新增形状；插件代码运行在播放器自带的 SDK 上，所以文字值随播放器 0.4.3 一起出现，旧播放器上没有 `plugin.i18n.text`（插件写 `minPlayerVersion`）。

## 8. 字体（中日韩字形）

每个窗口用系统界面字体，Slint 按字符回退。同一码位在中、日、韩里习惯字形不同（骨、直、角），系统回退可能取到中文字形。用户允许**仅 ja、ko** 在阶段验证中确认字形错误时，按语言指定系统自带的界面字体（例外于 10-22「不指定字体」裁决）。本轮不实现，只留接口：`i18n::ui_font_family(locale)` 目前对所有语言返回 `None`；需要时在 `theme::apply_fonts` 里按它设置窗口字体。

**阶段验证的检查方法**（协调者真机截图）：`VESTRA_LANGUAGE=ja`（再 `ko`）启动，打开有日文/韩文与汉字混排的界面（插件翻译完成后的菜单、选项窗口；或临时加载一个 `@tr` 写着「骨 直 角 刃 化 写 誤 説 갈 값」的测试窗口），放大截图，与系统设置里同一文字对照；字形与日文系统字体（Hiragino Sans / Yu Gothic）或韩文（Apple SD Gothic Neo / Malgun Gothic）一致即合格，否则记录哪几个字、哪个系统，再决定是否填 `ui_font_family`。

## 9. 菜单宽度估算

`menu::text_width` 按 Unicode East Asian Width 估算：宽字符（W/F：中日韩、假名、谚文、全角）约一个字号宽，其它（拉丁、带变音符号的拉丁、西里尔、符号）约半个，组合用符号不占宽度。德文、法文的长菜单项因此不再被当成中文宽度。

## 10. SDK（1.5.9；1.5.11 加文字值）

- 1.5.11：`plugin.i18n.text`、`list`、`error`、`resolve`（§7.1），`OsdPanel.set(…, { maxColumns })`，`BindingInfo.key`，`TEXT_LIMITS`、`LIST_SEPARATORS`；`extract` 收集文字值的原文并报告读不出的展开字段；TestHost 按播放器的方式显示文字值（`host.fileDialogs` 等）。
- `plugin.i18n.locale`（只读）；`appearance.language`、`appearance.setLanguage()`；`osd.show(text, args?)`、`OsdPanel.set(text, args?)`、`ConfirmOptions.args`；`PluginInfo.display`。没有 `t()`、`onChange` 或翻译引用。
- `vestra-plugin i18n extract`（用 TS 类型检查器找出调用点的字面量、条件两支、`as const` 表的字面量联合类型；`.slint` 的 `@tr`；manifest 显示字段；`TRANSLATORS:` 注释成为译者注释；`i18n-ignore` 注释排除不翻译的文字，如各语言的本名）与 `vestra-plugin i18n check`（覆盖率、占位符、复数、模板过期、TS 里拼接的句子、无法提取的值、非英文原文、Slint 里没包 `@tr` 的文字；只警告）；有 `locales/` 时 `vestra-plugin check` 也打印这些警告。
- TestHost：`locale`（`startPlugin({ locale })`）加载插件词典；`FakeCommand.display`、`host.osd`/`osdPanel`（显示出来的文字）、`host.confirmTexts`、`host.translate()`、`host.language`/`setLanguage()`；核心动作的声明路径是英文 key。**没设 `locale` 时**，播放器自己的文字（核心动作提示、拒绝消息）保持 1.5.8 的中文，旧测试不变；设了则是播放器的英文（`zh-Hans` 时是中文）。

## 11. 已知限制

- 换语言要重启。
- 复数只有两种形式；俄、阿、波兰等多形式语言不在支持范围。
- 模板里的数字按 JS/Rust 的写法（`1.5`），不按语言习惯（德文 `1,5`）。
- SDK 自己生成、插件会直接显示的错误消息（`player.ts`、`stream.ts`、`subtitles.ts` 里「无法打开此媒体」等）仍是中文，没有词典；第 2 轮要决定：改英文并随 SDK 带一份按 `locale` 选的小词典，或改为错误码由插件自己的模板表达。
- 插件的 README / CHANGELOG（商城详情页）没有按语言的版本。
- `vestra-plugin i18n extract` 重写 `.po` 时丢掉 `msgid ""` 之前的文件头注释（§3.1 的 `# Reviewed by an AI reviewer`）；SDK 的 `parsePo`/`writePo` 需要保留头部注释。
