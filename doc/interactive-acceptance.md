# 九插件完整交互验收

日期：2026-10-17。范围是当前 `src/plugins` 的全部九个已有插件，不只六个新探针。本轮为新增的真实交互验收，**当前尚未通过**。独立验收者盘点源码、定义场景并复核证据；root 负责先执行原生 UI；API maintainer 修共享宿主，不以改小验收范围来消除闪退。

## 1. 为什么必须另做本轮

上一轮证明了后端处理、进程协议、Slint 实际窗口、回调驱动的六插件组合及资源清理；当时明确没有验证物理鼠标键盘与系统文件对话框。67 步自动场景使用对话框路径注入和回调，不能证明点击“打开 MP4”、系统 Open/Save 面板、真实右键菜单或实际按键没有问题。

本轮已有真实故障：点击打开文件时闪退。初步崩溃栈指向 Slint timer 的 `Recursion triggered` 与同步 `rfd::pick_file` 的原生嵌套事件循环。此项记为 **INT-001 / 宿主 bug**，等待维护者修复及原生场景反复验证，不把它描述成插件用户误用或已被旧测试覆盖。

## 2. 证据等级与完成规则

每个场景必须记录输入、操作入口、结果、证据路径、实际构建修订、操作者、错误分类和状态。所有状态初始为待执行。不能把“窗口还在”当成功：打开后须实际播画面，保存后须解码文件，菜单触发后须检查状态与真实处理。

| 标记 | 证据含义 | 可以证明 / 不能证明 |
|---|---|---|
| N | CUA 实际鼠标/键盘触发原生控件、右键菜单、操作系统 Open/Save 面板 | 证明用户可达路径及系统交互；需要相邻截图/操作记录与真实结果。 |
| G | Slint 回调/场景驱动，真实原生窗口 | 证明布局、回调和状态；不能替代鼠标命中、焦点、菜单或系统 dialog。 |
| F | `host.dialogs` 等测试 fixture | 证明插件收到路径/取消后的逻辑；不能证明系统 dialog、filter、嵌套事件循环。 |
| B | 真实后端/worker/编译器/独立媒体解码 | 证明像素/PCM/文件/进程等实际结果；不能替代 UI 可用性。 |
| S | 源码及静态契约审查 | 证明分层和入口盘点；不能声称已执行。 |

所有当前可见按钮、滑块、复选框、右键菜单命令都要有 N 证据，不能只调用同名 action。一个动作同时有按钮和菜单入口时，两条入口都要实际走通。对滑块需实际拖动而不是修改 global。对话框每种实际调用方都覆盖确认、取消及可达错误；至少在播放和暂停时各开关一次，并在多次连续打开后验证不崩溃。不同场景复用的媒体/文件须记明确路径，不依赖系统默认最近文件。

内部故障注入/无 UI 的 action 单列为 B/G，不假造按钮；如产品本应具备的能力无入口，记为“不可达/需决定或实现”，不能宣称原生覆盖完成。出现新 UI 或菜单后需增补此表。

## 4. 全部插件、操作入口和场景

源码盘点基准：每个插件的 `manifest.json`、`ui.slint`、`index.ts`；工坊另读 `engine.ts/model.ts`，NES 另读 `engine.ts`。当前注册 action 共 **68**，manifest 菜单命令共 **30**。以下列表完整列出；动态循环注册的名字已展开。

机器可读清单：[coverage-inventory.json](../src/tests/interactive/coverage-inventory.json)。逐 action 记录当前控件参数、贡献菜单与所需N/B/G证据层；所有状态初始pending，`observations`空数组。它只是待验证计划，不是覆盖通过报告；例如 `preset` 和 `generate` 的两个不同按钮参数必须分别实际操作。

### 文件播放 file-playback（3 actions；无贡献命令）

- `open`：按钮“打开 MP4”。真实 Open 面板 MP4 过滤、选合法文件实际播放、取消保持原播放、损坏 MP4 可诊断并能重新打开合法文件；播放中及暂停中打开都执行。
- `toggle-pause`：按钮“播放/暂停”。无媒体时可恢复错误；加载后实际停止/恢复画面和进度，按钮文案一致。
- `seek`：实际拖动进度条到前/中/后；播放和暂停两种状态都验证，暂停时预览更新且不擅自恢复；媒体切换时进度与 duration 更新。

### 高斯 gaussian-blur（3 actions；无贡献命令）

- `enabled`：实际点击“高斯模糊”复选框，开/关均验证画面变化和复选框权威状态。
- `sigma`：拖动 σ 滑块至小/中/大，界面草稿值不被定时 playback 消息回退；此 action 只记草稿，不能把“拖动后立刻模糊变化”当既定语义。
- `apply`：点击“应用”，后端采用草稿 σ；与画面调节共存。无媒体、切换媒体、暂停预览及停用后的状态需明确，失败不伪报成功。

### 播放列表 playlist（7 actions；侧栏宿主菜单另列）

- `add`：“添加文件”实际 Open 面板；取消、加入、重复去重。至少添加4个不同有效视频，从而真实出现第二页。
- `play-index`：点击各页“播放第 N 项”，实际切换文件及 ▶ 当前标记；不能只变列表文字。文件被移除/损坏时应有错误并可恢复。
- `previous-page` / `next-page`：实际翻页；第一/末页禁用状态及三个 slot 映射正确，条目总数不被3限制。
- `hide`：点击“隐藏”，侧栏消失且视频区重新布局。
- `toggle`：右键宿主的显示/隐藏播放列表菜单，隐藏后仍能重新显示，条目/当前页/选中项保持。
- `show`：当前无单独可见按钮/贡献命令，仅注册 action；记为 B/G 覆盖。用户重显路径实际使用上述宿主 toggle 菜单，不能说点过 show。

### 画面 video-adjust（10 actions；5贡献命令）

- `brightness` / `contrast` / `saturation` / `hue`：四个实际滑块，分别检查明暗、对比、去色/增色、色相真实变化，再复位。数值边界/非法参数在 B 层补充，UI范围不能输入的值不假造原生操作。
- `preset-bright` / `preset-cinema`：实际按钮“明亮/影院”以及对应菜单两条路径分别执行；所有滑块与实际效果一致，预设后可继续编辑。
- `brightness-up` / `brightness-down`：实际菜单“增加亮度/降低亮度”，与滑块共享同一状态。
- `reset`：实际“复位”按钮和“工具/复位/复位画面参数”菜单，恢复中性且保留高斯/其他owner效果。
- `preset-neutral`：无当前 UI/贡献菜单，内部等价能力记 B/G；不替代 reset 用户路径。

### 音频 audio-workbench（11 actions；4贡献命令）

- `bass` / `mid` / `treble`：实际拖动100Hz/1kHz/6kHz三滑块；界面数值、真实处理链和独立 PCM 测量一致。
- `delay-ms`：实际拖到正值、0、负值，播放暂停恢复、换媒体后参数策略正确；音频偏移以真实样本 B 证据补充，不把肉眼或请求 ack 当测量。
- `normalize` / `voice`：两个复选框开关均操作，保留其他参数。
- `preset`：两个按钮分别传1/2，对白/音乐状态和实际处理正确。
- `preset-dialogue` / `preset-music`：对应贡献菜单实际点击，不因按钮通过省略菜单。
- `toggle-normalize`：响度规范化贡献菜单实际点击，复选框同步。
- `reset`：按钮和“工具/音频工作台”菜单分别复位，其他插件效果保留。

### 字幕 subtitle-workbench（11 actions；7贡献命令）

- `open`：“加载 SRT”按钮及“字幕/来源”菜单分别实际选择真实多条 SRT；文件过滤、取消、损坏 SRT、无媒体错误及随后成功恢复。
- `toggle`：显示/隐藏按钮及菜单，实际字幕出现/消失。
- `delay` / `font-size` / `yellow`：两个滑块、切换颜色按钮均操作；对照当前 cue 实际时间/位置/大小/颜色，不只看状态文字。
- `next-cue`：按钮和“播放/字幕导航”菜单；至少两条 cue，实际 seek 到下一条，边界循环可用。
- `translate` / `cancel`：按钮和“工具/字幕翻译”菜单，生成可见译文、原/译轨道切换、在途取消；翻译时切媒体旧结果不覆盖新文件。
- `original` / `translated`：按钮与“字幕/轨道”菜单分别操作；尚无译文时错误可恢复。
- `mock-fail-next`：无可见入口的故障注入 action；B/G 检查真实 provider 失败后重试，不冒充点击。

### 截图与导出 capture-export（9 actions；5贡献命令）

- `capture-raw` / `capture-processed`：按钮及“视频/截图”菜单均实际打开系统 Save 面板，确认/取消；保存 PNG 独立解码，处理前后像素可区分。
- `include-subtitles`：复选框两态实际操作，有字幕时保存图片确认包含/排除，原始截图不应混入处理链。
- `burst-count` / `burst-interval`：两个实际滑块，确认数量取整和间隔读数；用有限小组真实生成多个可解码图像。
- `capture-burst`：按钮及“工具/导出”菜单实际启动保存；中途取消保留已完成文件、不继续产出。
- `clip-duration`：实际拖动片段长度，再用 ffprobe 证实输出时长。
- `export-clip`：按钮及菜单实际 Save，生成含视频/音轨的 MP4；换媒体/改效果后任务仍保留旧源与参数/资源快照。
- `cancel`：按钮与菜单实际中止一个足够长的导出，进度出现后取消，无半成品/临时文件。额外执行无媒体、输出已存在、错误扩展名/不可写目录等用户可达错误；系统 overwrite 确认和插件拒覆盖语义须一致且不破坏原文件。

### NES nes（5 actions；5贡献命令）

- `open-rom`：按钮与“文件/模拟器”菜单分别真实 Open，`.nes` 过滤、取消、非法/损坏 ROM 后可重新打开合法 ROM。使用自制/明确授权 ROM，不用商业ROM。
- `toggle-pause`：按钮与菜单暂停/恢复，实际执行帧/声音消费停止和恢复，权威 paused 一致。
- `save-state`：按钮与“模拟器/存档”菜单实际 Save，磁盘 JSON 有效且与当前 ROM 绑定；取消不改变游戏，重复路径不得静默覆盖。
- `load-state`：按钮与菜单实际 Open，保存后改变运行状态再恢复，画面/后续执行与存档一致；取消、损坏/异 ROM存档不破坏当前会话。
- `close-rom`：按钮与菜单均执行，来源/计时/音频释放，关闭后控制禁用且可以再次打开。
- **物理输入额外项**：点击视频取得焦点，真实按下/释放 Z、X、Enter、Shift、四方向；至少使用能独立观察这些按键结果的合法样本。前轮自制 ROM 只对 A 键改变画面，不能用它证明其余7键都生效；需要日志中宿主收到真实事件/模拟器输入状态证据或扩充自制测试ROM。系统 dialog、面板切换、鼠标聚焦后重新按键，检查无粘键。

本轮已补充 `src/tests/interactive/input-rom.ts`，运行 `node --test src/tests/interactive/input-rom.test.ts` 生成 `.cache/interactive/fixtures/input-8keys.nes` 与对应 `input-8keys-oracle.json`。这是CC0自制6502程序，真实串行读八个按钮并改变PPU颜色；JSNES自检1/1通过，**尚不证明物理输入**。为适应CUA只有瞬时tap而无法长按，本轮ROM在真实6502程序内于松键后保色240帧（约4秒），按住则每帧刷新TTL、不会自动黑；自检已证明持续按住超过240帧不黑、释放才超时变黑。这样可在tap后截取颜色，再观察自然回黑验证release，不修改插件或伪造输入。原生选择该ROM后逐键按下/释放，用以下独立预期核对视频区：释放黑 `[0,0,0]`；Z `[188,25,0]`；X `[60,171,255]`；Shift `[43,244,3]`；Enter `[34,14,220]`；上 `[247,180,0]`；下 `[255,255,255]`；左 `[3,140,0]`；右 `[255,73,223]`。

### 工坊 plugin-workshop（9 actions；4贡献命令）

- `request-file`：按钮与菜单实际 Open JSON；有效需求（例如增量3）、取消、非法JSON/字段/超长内容后可恢复；记录最终需求。
- `generate`：按钮 +1、按钮 +2、贡献菜单按需求生成三个用户入口分别走通；真实 Pi mock 工具循环、真实 TS/Slint 校验、真实修复后安装新包，新增面板与菜单可发现。
- `cancel`：按钮和菜单在正常生成尚未提交时实际取消；已有生成插件继续可用。进入事务提交后显示明确状态，不假装强制取消成功。
- `rollback`：按钮和菜单，先安装两个不同增量版本，再回退并实际点击生成计数器验证旧增量；无历史时错误可恢复。
- `invalid` / `activation-failure` / `slow` / `slint-failure`：当前仅有内部故障注入 actions，无可见按钮或菜单，B/G独立验证类型/Slint/activate失败保旧和在途取消；与上述原生正常路径分列。
- `remove-generated`：当前没有UI/贡献菜单的管理 action，B/G 验证移除；若用户要求原生可管理移除，则记为当前产品入口缺口，不能谎称已通过鼠标卸载。
- 生成插件额外执行：实际点计数按钮及贡献菜单；两个版本替换和回退后 increment 正确；工坊面板隐藏后生成包继续使用，真正停用工坊的独立性由对应生命周期证据补充。

## 6. 操作与取证建议

先固定 binary 与代码指纹，准备两段内容明显不同且足够长的视频、损坏MP4、4个不同播放列表视频、多cue字幕与损坏字幕、自制ROM、坏ROM、好/坏需求JSON，以及隔离输出目录。可先创建合法样本文件；选择必须通过实际系统面板完成，不能用 fixture 偷换。
