# 2026-10 轮：多语言

开始于 2026-10-24。**本文是这一轮的唯一进度来源。**

## 用户裁决（2026-10-24）

- 所有界面文字以**英文为原文**，中文改为翻译。
- 界面语言：英文原文 + 6 种翻译——简体中文、日本語、한국어、Deutsch、Français、Español，共 7 种。**繁体中文取消**（用户：港台用户不多，可以看英文；新加坡用户用简体）。
- 选项里可以选择界面语言，默认「跟随系统」；系统语言不在支持范围内时用英文。
- 不为每种语言各写一份 Slint；用 Slint 的 `@tr` 和 gettext 词典，TS 文字走 SDK 提供的同一套词典。插件作者自己决定提供哪几种语言。

- 2026-10-24 维护者方案的三个问题：
  - 繁体取消，回退问题不复存在；
  - 中日韩字形如果在阶段 0 核实确实用错，**允许**按语言指定系统自带的界面字体，只限 ja、ko；这是对 10-22「不指定字体」裁决的破例；

## 修订（2026-10-24，用户裁决，取代下文方案中冲突的部分）

- **切换语言只在下次启动时生效**，取消实时切换。选项里改了语言，提示「重启后生效」。
  - 宿主在加载插件时，用 Slint 公开的 file loader 把 `@tr("原文")` 里的原文替换成当前语言的译文，Slint 只负责格式化。
  - 因此**不再依赖 i-slint-core 内部 API**（上一条「用内部库」的裁决作废）。复数只区分 1 与非 1。
- **插件做多语言时 TS 里不写任何翻译代码**：
  1. 声明类文字（菜单标题和路径、设置页标题、面板/页签名、窗口标题、manifest 的 name/description）填英文原文，由宿主用该插件的词典翻译；
  2. 窗口里的文字都写在 Slint 里，用 `@tr`，TS 只传数据；
  3. OSD、对话框等 TS 直接发出的文字，API 用「模板 + 参数」，例如 `osd.show("Speed {}×", [rate])`，宿主按模板查词典。
  - 规则：用户看得到的句子不在 TS 里拼接，`vestra-plugin check` 尽量检查出来。
- **SDK**：只有只读的 `plugin.i18n.locale`；没有 `t()`、`onChange` 或翻译引用。
- **流程**：按 §5 自上而下，分两轮派活，本轮并发上限放宽到 8：
  - 第 1 轮：维护者完成宿主、SDK、迁移指南，并亲自迁移 preferences 作为参考 → 协调者审查、真机验证、合并、发版；
  - 第 2 轮：所有插件作者一次完成迁移，包括顺手写 `zh-Hans.po`；5 个翻译 agent（ja、ko、de、fr、es）在拿到 `.pot` 后同时开工；独立验收者负责审查，协调者负责真机截图。

## 维护者方案要点（上一版）（2026-10-24，全文待阶段 0 写入 doc/architecture/i18n.md）

- **Slint**：当前构建里 `@tr` 只做格式化。gettext 只支持 unix，bundled 翻译解释器不支持，所以采用 i-slint-core 的 `tr` feature 加自定义 Translator，用 `update_all_translations()` 实时切换。通过 file loader 给每个插件的 `@tr` 加上 `<manifest-id>\u{4}` 前缀作为上下文，从而按插件区分词典。
- **SDK**：`plugin.i18n.locale/preference/onChange/t/t.n/mark/set`；每个插件的 `locales/messages.pot`、`<lang>.po` 在构建时编译成 JSON；新增 `vestra-plugin i18n extract|check`，check 只警告；manifest 的 name、description 也可翻译。

- **译文**：每种语言一个翻译 agent，另一个 agent 审校；机翻条目标 `x-machine`；简体中文由用户抽查。
- **规模**：约 1,590 条中文字面量要改写成英文原文。
- **分阶段**：

### 分类（§4.2）

全部请求同一根源：用户看得到的文字里固定词与数据混排，或者由翻译过的片段组成，而 TS 不能翻译、不能拼句子（用户裁决）。按 §4.2 第 5 条合并成一个设计议题，不逐条加字段（例如不给 `commands.add` 加只作用于最后一段的 `args`，不给 OSD 单独加 `{text,args}` 参数、给 ComboBox 单独加控件）。属于核心的理由：词典只在宿主，渲染必须在宿主（§4.3 第 1 条），且十几个插件都要用（第 4 条）。

| --- | --- |
| R2-audio-1（+video、playback、subtitles、store、history、marks） | 改写后接受：路径段 / 标题 / 原因可以是文字值 |
| capture 请求 1、R2-subtitles-1、R2-workshop-1 | 改写后接受：属性值里 `string` 的位置可以是文字值（含 `[string]`） |
| R2-subtitles-2、R2-playlist-1、R2-store-1、capture 观察、hotkeys 鼠标 OSD | 接受：参数可以是文字值，可嵌套 |

### 设计

一个**文字值**是纯数据，不是译文：

```ts
const { text, list, error, resolve } = plugin.i18n;
text("Track {} · {}", [7, "en"])   // → { $vestraText: "Track {} · {}", args: [7, "en"] }
list(["a.glsl", "b.glsl"])         // → { $vestraList: ["a.glsl", "b.glsl"] }
```

- 参数是数据（字符串、有限数字），或者又是文字值（同样翻译）；嵌套至多 8 层。列表按界面语言连接：`list` `, ` / `、`，`clauses` `, ` / `，`，`semicolons` `; ` / `；`，`sentences` `. ` / `。`，`lines` 换行（日文 `、 、 ； 。`，法文 `;` 前是窄空格；表在宿主 `i18n::text::SEPARATORS` 与 SDK `LIST_SEPARATORS`，host-agreement 检查一致）。
- **宿主渲染**：显示时用该插件的词典查 `source`，再代入渲染过的参数（规则同 `@tr`）；没有译文显示英文。TS 里没有任何翻译调用，`text()` 只是构造数据（`Object.freeze` 的 `{ $vestraText, args }`，构造时检查上限）。
- **一处机制，所有显示面**：命令 `title` / `path` 各段 / `reason`；`osd.show`、`OsdPanel.set` 的文字和参数；确认框各字段；文件对话框 `title`、`saveFile` 的 `fileName`；窗口 / 面板 / 设置页属性里 Slint 类型为 `string` 的任意位置；`TimelineLayer.set` 标题；`subtitles.load` 标题；解析器抛出的 `plugin.i18n.error(…)`。
- **Slint 侧**：Slint 不知道文字值。宿主在 `dispatch` 开头把 `ui.open`、`ui.set`、`ui.mount`、`ui.setMount`、`settings.register`、`settings.set`（以及 `timeline.set`、`subtitles.commit`、`sourceResolvers.respond` 的 `error`）参数里的文字值换成字符串，然后才走原来的路径；`set_property` 收到的只是字符串，`[string]` 的 ComboBox 不用改。`$vestra…` 键不会与真实结构体字段冲突（Slint 标识符不能以 `$` 开头，与 `$vestraImage`、`$vestraMarkdown` 同一约定）。
- **D1 上限**：替换在上限检查之前，所以 `UI_VALUE_LIMITS` 按显示出来的字符串计。文字值自己的上限 `TEXT_LIMITS`：嵌套 8、一个值 1024 个节点、16 个参数、256 项、4096 字节（模板字符串参数从 1024 放宽到 4096 字节）。
- **菜单 key**：Text 段的 key 是它的英文渲染（`Track 2 (opus)`），菜单按 key 合并、绑定表 `key` 给出；显示文字是译文。列表值不能作菜单段。
- **协议**：`vestra/1` 只有新增形状，只在插件用了新 API 时出现；旧插件的字符串与 `args` 语义不变。插件代码运行在播放器自带的 SDK 上，文字值随播放器 0.4.3 出现；用它的插件写 `minPlayerVersion: "0.4.3"`。
- **提取**：`vestra-plugin i18n extract` 收集每个 `plugin.i18n.text(…)` / `error(…)` / `resolve("…")` 的 `source`（字面量、条件两支、`as const` 表；`plugin.i18n.text` 或解构的 `text` 都认，靠类型检查器解析到 `I18n` 接口），以及 `{ $vestraText: "…" }` 字面量；`"{} · {}"` 这类只有占位符和标点的不收录。类型是文字值的字段不再报「不是字面量」。展开进调用选项的字段（`commands.add({ ...extra })`）按类型读取，读不出时报 `… spread into Commands.add is not a literal`。
- **TestHost**：与宿主同样渲染：`FakeCommand.display`（新增不可枚举的 `display.reason`，`deepEqual(display, { title, path })` 的旧测试不变）、`host.osd`、`host.osdPanel`（按 `maxColumns` 截断）、`host.confirmTexts`、新 `host.fileDialogs`、窗口/面板/设置页 `props`（已换成字符串；原样在 `host.sent(…)`）、时间轴与字幕标题、解析器的 `TextError`、`BindingInfo.key`；不合法的文字值同样以 `invalid` 拒绝。
- **`resolve`**（唯一的出口）：同步返回字符串，SDK 在插件进程里读同一份词典（`locales/<lang>.json`，开发时 `.po`）。只用于剪贴板、文件；界面上一律传文字值。
- **截断**：`OsdPanel.set(value, args, { maxColumns })`，宿主在翻译、格式化后按 `unicode-width` 截断每行（宽字符 2 列），末尾 `…`。

### 每条请求的写法

```ts
const { text, list, error, resolve } = plugin.i18n;
// R2-audio-1、video、playback、store、history、subtitles 的菜单
path: ["@audio", "Audio Track", text("Track {} ({})", [n, codec])]
title: text("Custom ({})", [ratio])                       // video
path: ["@playback", "Seek", text("Back {} s", [seconds])]  // playback（播放器的 "Back {} s" 是播放器自己的词，插件词典里要有这一条）
title: text("Plugin Store ({} updates)…", [count])         // store
reason: text("Needs {} more", [n])
// capture #1、R2-subtitles-1、R2-workshop-1：[string] 模型
win.set({ audioLabels: [text("No Audio"), text("Current Track"), ...tracks.map((t) => text("Track {} · {}", [t.id, t.title]))] });
tune.bind(() => ({ trackLabels: [text("Subtitles Off"), ...names] }));
settings.set({ providers: [...names, text("Custom · OpenAI format"), text("{} (no longer offered)", [name])] });
// R2-subtitles-2：结果 + 0–2 条附注
osd.show(list([text("Opened subtitle: {}", [name]), ...notes.map((n) => text(NOTES[n]))], "sentences"));
// R2-playlist-1：任意几个分句，最后一段用「；」
osd.show(list([list([text("Added: {}", [a]), text("duplicates skipped: {}", [d]), …], "clauses"), text("opening")], "semicolons"));
// R2-store-1：权限列表、来源、原因
osd.show("Download failed: {}", [text(REASONS[code])]);
dialogs.confirm({ message: "Install “{}” {}?", args: [name, version], confirm: "Install",
  detail: text("From {}, author {}.\n\n{}", [text(SOURCES[kind]), author,
    text("It will be able to:\n{}", [list(perms.map((p) => text("· {}", [text(PERMISSIONS[p])])), "lines")])]) });
// R2-video-1、workshop 能力列表
osd.show("Removed missing shaders: {}", [list(missing)]);
// R2-playlist-2、hotkeys
dialogs.saveFile({ fileName: text("Playlist.m3u8") });     // TRANSLATORS: 只译扩展名前的部分
// P-2
(await plugin.bindings.list()).commands.find((c) => c.key?.join("/") === "Playlist");
// R2-nes-1
throw error("The ROM file was not found.");                // player.state.error 与失败提示是译文
// info、R2-hotkeys-1：只用于导出
await plugin.clipboard.writeText(resolve(list(lines, "lines")));
writeFileSync(path, [HEADER.map((h) => resolve(h)).join(","), …].join("\n"));
// info 简要信息
panel.set(list(lines, "lines"), null, { maxColumns: columns });
// marks、subtitle-online
layer.set(chapters.map((c, i) => ({ time: c.start, kind: "chapter", title: c.title ?? text("Chapter {}", [i + 1]) })));
plugin.subtitles.load(bytes, { title: text("{} · {}", [text(LANGUAGES[lang]), release]) });
```
