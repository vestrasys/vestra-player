# 2026-10 轮：多语言

开始于 2026-10-24。**本文是这一轮的唯一进度来源。**

## 用户裁决（2026-10-24）

- 所有界面文字以**英文为原文**，中文改为翻译。
- 界面语言：英文原文 + 6 种翻译——简体中文、日本語、한국어、Deutsch、Français、Español，共 7 种。**繁体中文取消**（用户：港台用户不多，可以看英文；新加坡用户用简体）。
- 选项里可以选择界面语言，默认「跟随系统」；系统语言不在支持范围内时用英文。
- 不为每种语言各写一份 Slint；用 Slint 的 `@tr` 和 gettext 词典，TS 文字走 SDK 提供的同一套词典。插件作者自己决定提供哪几种语言。

- 2026-10-24 维护者方案的三个问题：
  - 繁体取消，回退问题不复存在；
  - 中日韩字形如果在阶段 0 核实确实用错，**允许**按语言指定系统自带的界面字体，只限 ja、ko；这是对 10-22「不指定字体」裁决的破例；
  - 实时切换采用方案 B：用 Slint 内部库 i-slint-core 的外部 Translator，封装在 `src/host/src/i18n/slint_bridge.rs` 一个文件里，升级清单加一项，同时向 Slint 上游请求公开 API；失效时退回方案 A，即换语言时重建窗口。

## 维护者方案要点（2026-10-24，全文待阶段 0 写入 doc/architecture/i18n.md）

- **Slint**：当前构建里 `@tr` 只做格式化。gettext 只支持 unix，bundled 翻译解释器不支持，所以采用 i-slint-core 的 `tr` feature 加自定义 Translator，用 `update_all_translations()` 实时切换。通过 file loader 给每个插件的 `@tr` 加上 `<manifest-id>\u{4}` 前缀作为上下文，从而按插件区分词典。
- **SDK**：`plugin.i18n.locale/preference/onChange/t/t.n/mark/set`；每个插件的 `locales/messages.pot`、`<lang>.po` 在构建时编译成 JSON；新增 `vestra-plugin i18n extract|check`，check 只警告；manifest 的 name、description 也可翻译。
- **菜单**：宿主用插件自己的词典翻译 title、path、页面标题；合并菜单用英文 key；共用子菜单的英文 key 登记在 menus.md；旧中文锚点作为别名继续可用。
- **设置**：`ui_state.appearance.language`；系统语言用 sys-locale 检测；语言变化时广播 `i18n.changed`；preferences 插件提供语言入口，语言名一律用各自的本名显示。
- **译文**：每种语言一个翻译 agent，另一个 agent 审校；机翻条目标 `x-machine`；简体中文由用户抽查。
- **规模**：约 1,590 条中文字面量要改写成英文原文。
- **分阶段**：
  - 阶段 0：基础设施，加试点插件 preferences 和 playlist；
  - 阶段 1：其余插件、宿主字符串、译文；
  - 阶段 2：文档与商店。
