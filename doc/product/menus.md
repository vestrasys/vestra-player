# 菜单与界面归属

> 目标结构见[界面整改](ui-alignment.md) §6；本表记录当前实现。

当前产品的右键菜单树，由 10 个插件各自注册的命令合并而成（2026-10-20 从插件代码实际注册结果整理）。菜单按用户领域组织，不按插件组织。新增或移动入口前对照本表，确认没有重复入口、没有散放到错误领域（[交互要求 §1](interaction-requirements.md#1-菜单按用户领域组织)）。

## 界面形式

| 插件 | 界面 |
| --- | --- |
| playback | 底栏（常驻）：来源、进度条、时间、打开/暂停/倍速/静音、音量；内嵌编辑框（跳转、倍速、音量） |
| playlist | 侧栏（可隐藏）：列表与操作按钮；「添加链接」工具窗口 |
| video | 工具窗口：画面调节（含高斯模糊） |
| audio | 工具窗口：音频工作台 |
| subtitles | 工具窗口：字幕工作台 |
| capture | 工具窗口：截图与导出 |
| nes | 工具窗口：NES |
| youtube、bilibili | 工具窗口：输入链接、播放（YouTube 另有下载） |
| workshop | 工具窗口：插件工坊；它生成并安装的插件各有自己的窗口 |

工具窗口的显示、隐藏、关闭不影响该插件已经生效的效果；关闭工具不等于撤销处理，也不替换底栏。
