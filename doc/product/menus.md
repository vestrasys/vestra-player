# 菜单与界面归属

> 本表记录当前实现，对应[界面整改](ui-alignment.md) §6.2 的目标结构。

当前产品的右键菜单树，由 13 个插件各自注册的命令、宿主的 14 条核心动作和宿主自己的「全屏」「退出」合并而成（2026-10-21 从 rebuild/features-r2 的插件代码实际注册结果整理）。菜单按用户领域组织，不按插件组织。新增或移动入口前对照本表，确认没有重复入口、没有散放到错误领域（[交互要求 §1](interaction-requirements.md#1-菜单按用户领域组织)）。

## 菜单树

2026-10-21，基线 rebuild/features-r2。由 `OUT=<file> node --test doc/process/rounds/menus-snapshot.test.ts` 导出的快照整理（[分配表](../process/rounds/2026-10-plugin-ui.md) §3）；宿主的「全屏」「退出」在 `src/host/src/main.rs`，不在快照里。

- 顺序按声明的 `order` 升序；同一 `order` 再按插件 id、注册先后。子菜单取其中最小的 `order`。
- 「插件」列：「核心」是宿主的核心动作（`host/<id>`），「宿主」是宿主自己的命令。
- 顶层分隔线画成「——」行。子菜单内相邻两项的 `group` 不同时也画分隔线，表中不逐一画出。
- 快捷键在全局作用域生效（视频画面、底栏、侧栏获得焦点时；工具窗口内不生效）。写 `Ctrl` 的在 macOS 上 ⌃ 和 ⌘ 都能触发。
- 「动态」项按当前媒体或记录在运行时生成；「当前版本不可用」项常驻但置灰。

| 插件 | 界面 |

| playback | 底栏（常驻）：来源、进度条、时间、打开/暂停/倍速/静音、音量；内嵌编辑框（跳转、倍速、音量） |
| playlist | 侧栏（可隐藏）：列表与操作按钮；「添加链接」工具窗口 |

工具窗口的显示、隐藏、关闭不影响该插件已经生效的效果；关闭工具不等于撤销处理，也不替换底栏。

## 冲突检查

2026-10-21 对上表全部绑定（13 个插件、14 条核心动作、宿主的全屏/退出全屏/退出）按作用域逐键检查，macOS 上把 `Cmd+X` 与 `Ctrl+X` 视为同一键。

- 全局作用域：无冲突。宿主唯一的 ⌘ 绑定是 Cmd+Q（退出），没有命令声明 Ctrl+Q。
- 面板焦点作用域（播放列表）：无冲突。
- 跨作用域遮蔽（按设计，不算冲突）：列表获得焦点时 Enter、Ctrl+I、Ctrl+O、Ctrl+U、Backspace、Ctrl+Home、F3、F2、F6 用列表自己的含义，见上节备注。
- `>` `<` `?` 是按出的字符，与 `.` `,` `/` 是不同的键名（美式键盘上前者需要 Shift），互不冲突。
