# 界面与交互整改：对齐参考播放器

日期：2026-10-20。依据：参考播放器 260819 x64 静态逆向（证据在 [research/classic-260819/ui/](research/classic-260819/ui/README.md)，下文用 `A§`、`B§`、`C§` 引用其中三份报告的章节），对照 Vestra 当前实现（`rebuild/sdk-v2` 3618fba）。

本文是发给 API 维护者和插件作者的整改依据。每一项都写明：参考播放器的值、我们的现状、目标、负责方、验收方法。实施按[社区工作流](../process/community-workflow.md)进行；需要用户拍板的取舍集中在 §1。

## 0. 怎么读

- **编号**：`UI-<区域>-<序号>`，例如 `UI-BAR-03`。负责方写成 `宿主`（Rust 宿主与 `host.slint`）、`SDK`（插件 API，要走 API 请求）、或插件名。
- **可信度**：沿用逆向报告的标记。**确认** = 皮肤文件或资源直接给出；**推断** = 多处证据推出；**未知** = 静态无法确定，目标值是我们自己的选择，附在 §12，等有 Windows 实机时校准。
- **单位**：参考播放器皮肤坐标是 96 DPI 下的 1x 像素；对话框单位（DLU）已按 Arial 9pt 换算（1 DLU = 1.75 px）。我们的 Slint 逻辑像素在 macOS 上也是 1x，两者按 1:1 对照。
- **样式代码**：用 CSS 写，便于和 Slint 属性逐项对照（`height` ↔ `height`，`background` ↔ `background`，`gap` ↔ `spacing`，`padding` ↔ `padding`）。
- **macOS 适配原则**：参考播放器是 Windows 程序，自绘了 31px 标题栏（含主菜单按钮和系统按钮）。我们保留 macOS 原生标题栏和红黄绿按钮，不仿制自绘标题栏；其余（控制栏、播放列表、菜单、工具窗口、快捷键）按参考播放器对齐。快捷键的 Ctrl 在 macOS 上同时接受 Cmd。

## 3. 主窗口外壳（宿主）

## 5. 播放列表（播放列表插件 playlist + 宿主）

### 5.1 开关与停靠（C§3.1–3.2、B§4.1，确认）

参考播放器：`列表... F6`（CmdID 10011）是**带勾选的开关**，出现在右键菜单顶层「全屏」下面的窗口入口组；底栏有开关按钮（按下态表示开启）；列表自己的标题栏有关闭按钮；列表获得焦点时 F6 也是关闭。默认**显示并附着在主窗口右侧**；可以分离成浮动窗口（最小 300×250，默认 260×408）；可见性、停靠状态、宽度都会被记住。

我们：插件挂载即显示；只有侧栏右上角 × 可以关闭，重新打开要找到「视图 → 显示播放列表」，用户反映找不到。
