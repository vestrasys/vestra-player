# 界面与交互整改：对齐 PotPlayer

日期：2026-10-20。依据：PotPlayer 260819 x64 静态逆向（证据在 [research/potplayer-260819/ui/](research/potplayer-260819/ui/README.md)，下文用 `A§`、`B§`、`C§` 引用其中三份报告的章节），对照 Vestra 当前实现（`rebuild/sdk-v2` 3618fba）。

本文是发给 API 维护者和插件作者的整改依据。每一项都写明：PotPlayer 的值、我们的现状、目标、负责方、验收方法。实施按[社区工作流](../process/community-workflow.md)进行；需要用户拍板的取舍集中在 §1。

## 0. 怎么读

- **编号**：`UI-<区域>-<序号>`，例如 `UI-BAR-03`。负责方写成 `宿主`（Rust 宿主与 `host.slint`）、`SDK`（插件 API；核心改动汇总在 §10）、或插件名。
- **可信度**：沿用逆向报告的标记。**确认** = 皮肤文件或资源直接给出；**推断** = 多处证据推出；**未知** = 静态无法确定，目标值是我们自己的选择，附在 §12，等有 Windows 实机时校准。
- **单位**：PotPlayer 皮肤坐标是 96 DPI 下的 1x 像素；对话框单位（DLU）已按 Arial 9pt 换算（1 DLU = 1.75 px）。我们的 Slint 逻辑像素在 macOS 上也是 1x，两者按 1:1 对照。
- **样式代码**：用 CSS 写，便于和 Slint 属性逐项对照（`height` ↔ `height`，`background` ↔ `background`，`gap` ↔ `spacing`，`padding` ↔ `padding`）。
- **macOS 适配原则**：PotPlayer 是 Windows 程序，自绘了 31px 标题栏（含主菜单按钮和系统按钮）。我们保留 macOS 原生标题栏和红黄绿按钮，不仿制自绘标题栏；其余（控制栏、播放列表、菜单、工具窗口、快捷键）按 PotPlayer 对齐。快捷键的 Ctrl 在 macOS 上同时接受 Cmd。

## 3. 主窗口外壳（宿主）

PotPlayer 常规模式（A§2.1、C§2.1–2.2，确认）：外框 3px 黑边 → 31px 标题栏 → 右侧附着面板（3px 可拖分隔条）→ 底部 22px 进度条行 + 40px 按钮行 → 剩余为视频。**控制栏在视频下方，不覆盖画面**，且**只在视频下方，不延伸到播放列表下方**；播放列表从标题栏下沿一直到底边。

## 5. 播放列表（播放列表插件 playlist + 宿主）

### 5.1 开关与停靠（C§3.1–3.2、B§4.1，确认）

PotPlayer：`列表... F6`（CmdID 10011）是**带勾选的开关**，出现在右键菜单顶层「全屏」下面的窗口入口组；底栏有开关按钮（按下态表示开启）；列表自己的标题栏有关闭按钮；列表获得焦点时 F6 也是关闭。默认**显示并附着在主窗口右侧**；可以分离成浮动窗口（最小 300×250，默认 260×408）；可见性、停靠状态、宽度都会被记住。

我们：插件挂载即显示；只有侧栏右上角 × 可以关闭，重新打开要找到「视图 → 显示播放列表」，用户反映找不到。

| 编号 | 整改 | 负责方 | 验收 |
| --- | --- | --- | --- |
| UI-PL-01 | 开关命令「播放列表」带勾选，快捷键 F6，放在右键菜单的窗口入口组（§6），不再藏在「视图」子菜单里 | playlist（菜单位置）+ 宿主（F6，C3） | 右键菜单顶层能看到「播放列表 ✓ F6」；按 F6 开关 |
| UI-PL-02 | 底栏开关按钮（UI-BAR-09）与菜单勾选、侧栏关闭按钮三者状态一致 | playlist + playback（C7） | 三个入口任意操作后状态同步 |

### 6.1 结构（B§3.2，确认）

## 10. 核心改动（API 维护者，一轮做完）

本节是核心层（宿主 + SDK）的**完整**改动清单，在一轮里全部完成，按[社区工作流](../process/community-workflow.md) §5 自上而下进行：维护者设计并实现，同时迁移参考插件；其余插件由迁移者同步改到新写法；本轮结束时删除全部被取代的旧接口，**不保留兼容层**。插件的视觉改版不在本轮（见 §11）。

原则：核心只提供多个插件共用、或插件做不到的能力；每项只做最小接口；被新机制取代的特殊处理一律删除。
