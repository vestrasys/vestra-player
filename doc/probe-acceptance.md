# 六插件探针验收矩阵

本轮场景在实现前确定，不能为了现有代码方便而删减。记录日期：2026-10-17。所有代码在 src/；本表不是成品功能承诺。公共规范见 [ENGINEERING.md](../src/ENGINEERING.md)。

| ID | 探针/层 | 必须由真实结果证明的条件 |
| --- | --- | --- |
| V1 | 画面 | 亮度、对比度、饱和度和色相可配置；至少两个不同菜单入口调用同一插件命令体系；Slint 面板状态一致。 |
| V2 | 画面 | 预设、复位、无效输入处理；实际像素改变而不是只断言请求发出。 |
| V3 | 画面 | 与另一个独立 owner 的画面效果共存；撤销自己不撤销另一个，处理顺序明确。 |
| A1 | 音频 | 至少三段 EQ、响度规范化、人声增强、延迟、预设及复位；实际 PCM/时间偏移可测。 |
| A2 | 音频 | 更新参数无需卸载插件；切换媒体和暂停恢复的参数策略明确，停用回收自己的处理资源。 |
| S1 | 字幕 | 加载真实字幕文件并解析多条时间轴；选择/显示隐藏、样式和同步控制；实际宿主呈现/合成可验证。 |
| S2 | 字幕 | 可替换翻译提供者；本轮确定性 mock 服务；翻译期间切换媒体后旧结果不污染新会话；取消和错误可恢复。 |
| E1 | 截图 | 原始画面与处理后画面可区分，字幕包含/排除可检验；输出有效图像。 |
| E2 | 导出 | 片段导出生成可探测的媒体；报告任务进度/取消；开始后切换视频仍绑定原来源及参数快照。 |
| N1 | NES | 使用成熟模拟器核心执行自制/授权 ROM，输出真实帧和非零音频；按键改变执行结果。 |
| N2 | NES | 来源选择对话框有 ROM 过滤，独立来源/会话允许 duration:null；暂停恢复、存档恢复和停用清理可验证。 |
| W1 | 工坊 | 工坊本身是普通独立插件，真实 Pi agent 循环配 mock 模型调用，不要求 BYOK 或付费请求。 |
| W2 | 工坊 | 生成的 TS/Slint/manifest 经真实类型/包/Slint 校验，试载并执行预定行为；先错误再根据诊断修复。 |
| W3 | 工坊 | 取消生成、候选包校验失败、替换失败及回退保留旧版；工坊不 import 生成插件或其他探针。 |
| I1 | 独立性 | 六个插件分别在其他五个缺席时可运行；无跨插件 import/目录读取/直接或定制中转消息。 |
| I2 | 组合 | 改变加载顺序；停用一个后其他继续工作；旧媒体结果、资源、任务和订阅不会泄漏。 |
| C1 | 契约 | strict TS、Rust build/clippy、Slint 编译、manifest/RPC 输入验证、共享 API 版本与实现一致。 |
| C2 | 架构 | 无探针名称硬编码业务分支、无专属内部 API、无第一方 unsafe；状态和任务所有权清晰。 |
| C3 | 社区演进 | 公共基线及各消费者目标版本明确；请求分类和决策可追踪；破坏性变更有影响清单、迁移及回归证据，兼容层有退出条件；无未解决必要迁移或待用户裁决事项。 |
| G1 | GUI | 真实 Slint 窗口加载各探针 UI，菜单贡献可发现；界面隐藏/重建后的业务状态按策略保留。 |
| R1 | 证据 | 独立验收者执行命令、检查产物和源码；最终报告与当前代码一致，未验证平台行为明确披露。 |

自动测试可通过公开 API/真实 Slint 回调驱动场景，不必让 agent 手工逐个点击。不能把 headless 后端通过等同于 GUI 全部通过。声音实听和完整平台设备行为属于单独记录的覆盖范围；音频处理正确性必须有实际样本证据。

每个探针开发者在自身 README 指明命令、契约版本、产物及对应 ID。验收者可以新增针对真实缺陷的用例，但不能将必要条件改为更容易通过的条件。
