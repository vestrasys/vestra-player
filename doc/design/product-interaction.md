# 本轮产品交互草案 B1

日期：2026-10-17。状态：阶段 B 全局草案，供插件作者写方案和 maintainer 评估；未发布共同实现基线，不表示下列能力已经实现。依据仅为本轮产品要求、scope、工作流及阶段 A 工作契约 `vestra.experimental/0.1`。范围是两个默认插件与六探针的有限场景，不承诺完整 PotPlayer。

菜单与全部功能归属见 [menu-map.md](menu-map.md)。插件作者必须逐项覆盖其条目，新增或移动入口先提交设计变更。宿主只执行公开的挂载、资源所有权和命令路由，不识别插件名称。这里的插件名称是产品分工，不是 core 分支条件。

## 1. 窗口与常驻操作

主窗口初始 1100×720 逻辑像素，最小 720×480（侧栏展开至少960×520）。系统屏幕可用区不足时按可用区显示，允许主窗内容按最小布局压缩；不能让窗口按钮落在屏幕外。正常布局如下，尺寸为产品目标而非对特定显示器的保证：

```text
┌ 文件 播放 视频 音频 字幕 视图 模拟器 插件 ┐
│                                │播放列表│
│       主画布：视频 / NES        │添加/关闭│
│   contain，留黑边，不拉伸裁切   │队列行  │
│                                │上移下移│
├─────────────────────────────────────────┤
│ 进度条                 当前时间 / 总时长 │
│ 打开 播放/暂停 时间跳转 速度 静音 音量   │
└─────────────────────────────────────────┘
 常驻栏由基础播放插件提供，普通窗口目标高96

画面/音频/字幕窗口（独立）
┌ 参数、状态、领域复位 ┐
│ 原生Slint布局       │
│ 不占主画布或播放栏  │
└────────────────────┘
```

- 基础播放插件默认启用并挂载唯一的常驻播放栏；主视频画布由宿主管理。栏内无“工具内容”槽，工具不能取得或替换此位置。挂载资格与冲突通过通用声明及公开错误处理，不通过插件 ID 特判。侧栏与播放栏是不同通用挂载位置，互不替换。独立插件测试可不安装此默认插件，宿主公开播放设施仍可用。
- 本轮播放列表采用主窗口右侧可隐藏侧栏，默认显示，目标宽280、最小240逻辑像素。侧栏有关闭按钮，视图菜单可重新显示。显示侧栏时主画布区域至少宽640、高360；主窗口空间不足时自动收起侧栏并在视图菜单显示“空间不足，放大窗口后可显示”，保留队列、选择和用户偏好，放大后不自动抢回焦点。用户在空间不足时点击显示，先把普通主窗放大到可容纳尺寸；屏幕不足则保持收起并明确原因。不存在自动转成独立窗口的第二套形态；不预建可停靠编辑器。侧栏只横向占用画布上部空间，底部播放栏横跨整个主窗。
- 画面、音频、字幕工作台独立非模态；连续调参要同时观察主画面，窗口不挤占视频。截图/导出需要查看任务与来源快照，NES控制需要存档和输入信息，工坊需要需求/诊断/产物空间，均采用独立窗口。它们只在用户打开时显示，不随插件激活抢焦点。
- 建议初始/最小逻辑尺寸：列表宽280 / 240；音频、字幕 560×520 / 440×360；画面480×560 / 400×420（较窄纵排、可滚动）；截图导出 680×560 / 520×400；NES控制 440×400 / 360×300；工坊 820×640 / 640×460；插件管理 640×500 / 500×360。可用区不足时控件区滚动；底部状态与取消操作保持可达，禁止把最小宽度靠裁切控件实现。
- 工具窗口使用 Slint 的原生组件和布局；复杂列表/图像按明确场景申请桥接。禁止 Web 面板或另一套通用 JSON UI 描述语言。

## 2. 显示、关闭、焦点和全屏

- 主菜单“打开工作台…”显示唯一实例并置前；已显示时只聚焦，不重建组件、不复位参数。视图菜单的播放栏/播放列表勾选表示用户显隐偏好（preferred visibility）；实际呈现（effective visibility）和暂隐原因分别公开。全屏自动隐藏、全屏进入时暂隐列表、空间不足自动收起均不改变偏好，不让勾选随鼠标活动闪烁。用户关闭侧栏或主动取消菜单勾选才把偏好设为false。独立工具不在视图菜单再放第二入口。
- 工具右上关闭和 Escape（未编辑/未打开弹层时）隐藏界面，保留参数、效果和运行任务；再次打开恢复状态。关闭事件不等于停用插件，不发播放暂停/seek。宿主销毁窗口实例的 API 也必须与卸载插件分开。
- 收起播放列表保留队列与当前项；队列继续按既定顺序播放。关闭导出/工坊窗口时任务继续，状态可从同一菜单重新打开；任务运行时入口显示运行标记/数量，完成或失败用非抢焦点通知。用户点击“取消任务”才请求取消。
- 菜单/按钮/快捷键打开工具后焦点进入该工具的首个适用控件；关闭后回到来源窗口中仍存在的控件。后台事件、进度和错误不抢焦点。工具窗口不置顶、不模态，不自动移动主窗口。
- 文本/数值编辑器获得焦点时，Space、方向键、字母属于编辑器；全局退出全屏和显式菜单快捷键仍可用。主画布有焦点时 Space切换播放、左右键±5秒；NES来源时主画布输入转入NES映射，须先点画布获得输入焦点，并显示输入已捕获提示。失焦、开菜单或开对话框释放已按下的NES键，禁止卡键；不擅自暂停游戏。
- F11/视图→全屏为全局命令。全屏只改变主窗布局，保持媒体、任务与工具状态；主画布占可用区，播放列表先隐藏（保留普通窗口显隐偏好，可用视图菜单手动展开且仍须满足画布最小面积），栏作为底部覆盖层，在鼠标移动/键盘操作后显示，3秒无操作后隐藏；拖动、菜单展开和焦点在栏内时不隐藏。Escape先关闭菜单/弹层，其后退出全屏。工具不自动全屏或被销毁；工具打开时用户仍可操作主播放栏。
- “显示播放栏”默认勾选，普通窗口允许手动隐藏；全屏的自动隐藏不改该用户偏好。栏隐藏后菜单与快捷键仍能播放/暂停/跳转。默认插件停用会移除其入口与栏，媒体保持；插件管理始终有公共恢复入口，不能因基础播放插件缺席失去插件管理。
- 主窗口系统关闭退出本轮应用：若仍有导出/生成/安装事务，提供“继续后台任务并保留窗口 / 取消任务并退出”的明确选择；不悄悄丢弃任务。这里“继续”取消此次退出并恢复任务窗口，不承诺后台托盘模式。最小化主窗口不暂停播放。

## 3. 状态与连续操作

- 播放事实以宿主公开会话状态为准：source、session generation、loading/ready/ended/error、pause、position、duration、source capabilities。插件不得互相发消息或读取对方对象；队列通过公开会话事件观察当前项，播放栏通过同一状态显示。NES也公开自身来源的控制能力，普通seek/速度/轨道等不支持项禁用并解释。
- 初版 `open` 只表示接受请求。产品要显示“正在打开”，成功后才显示已就绪；失败保留路径和原因并提供重试。来源切换时旧进度不能短暂显示为新媒体进度。不能解析 mpv debug 字符串判定媒体完成或任务归属。
- 基础播放：无媒体时打开可用，暂停/跳转禁用；时长未知可播放但禁用绝对进度拖动。拖动进度时显示预览目标时间、合并连续请求，释放后最终提交；不会为seek自动改变暂停状态。跳转目标约束在已知范围内。速度0.25–4倍（无媒体时禁用，不增加下次来源默认值平台）、音量0–200%、静音恢复规则见下项；不扩张初版底层范围。
- 音量/静音是公共输出设施的当前共享状态；无媒体且公共输出设施存在时可操作，否则禁用，不维护下一来源pending默认值。静音使用真实confirmed muted，保持原volume不写0；解除静音恢复同一volume。volume=0不自动等于muted，解除静音后为0也不擅自跳到100%。用户主动设音量时直接设置目标值并解除静音，不能先恢复旧大音量再降低。无需额外多消费者恢复历史平台；其他消费者同样观察公共mute/volume事实。具体原子或有序提交方式由maintainer确定。
- ended来源的播放按钮语义是“从头再播放”，仅对公开支持restart的来源可用，不假定所有来源能seek。用户明确重播与队列自动下一项竞态时，较新的用户重播意图使迟到自动推进过期；公共来源身份/意图条件负责协调，基础播放与列表不直接通信。具体restart签名与generation变化尚未冻结。
- 实时画面/音频拖动采用最新值合并、最多约30次/秒提交，释放必须提交最终值；UI立即显示待提交值，宿主确认值负责最终勾选/数值。失败恢复最近确认值并显示局部错误，不能偷偷重载媒体、暂停或复位其他参数。成功设置不等于该帧已经可见，验收必须看实际播放结果。
- 日常菜单停留至少10秒、连续拖动至少5秒、已接入工具的显示/隐藏、选择文件期间，音频和视频持续；不接受声音继续而画面冻结。未知Slint组件在安装/首次激活时可能需要整体import组合、编译和shell重建；此准备阶段允许已说明的短暂UI闪动，但必须先显示“准备界面”，保存/恢复窗口布局、焦点目标及控件状态，不重启backend、媒体session或插件实例，不自动暂停/seek。记录实际耗时、呈现中断边界和状态恢复证据；准备完成后再次show/hide不重编译。不能把返回Promise或async函数本身称为离UI线程编译，也不承诺零成本任意动态嵌入；若真实Slint限制无法满足日常连续性，按工作流上报具体路线障碍。
- 画面/音频处理以插件拥有的处理资源为单位；预设与领域复位仅改本插件在该领域的资源，不清空其他插件链。关闭窗口保留效果，停用/崩溃撤销自身效果、事件和资源。多个处理者的顺序必须可诊断且稳定；本轮不承诺任意节点拖拽混音器或滤镜图编辑器。
- 字幕选择/样式/同步为公开会话资源；媒体切换后重新核对来源。翻译任务绑定不可变session/字幕revision/输入快照。旧任务允许完成到历史结果，但不能覆盖新会话字幕；取消后不可再把迟到结果应用为当前字幕。
- 截图、连拍、片段导出绑定创建时的媒体来源、时间/范围、原始或处理后、字幕选项及视频/音频效果快照。切媒体或调参不改变进行中任务的输入；UI持续显示来源文件名与创建时间。无法保证快照时禁用启动并说明原因，不能静默改成当前会话取样。
- NES打开ROM进入主画布的独立来源/时钟，取代当前普通来源，打开前说明当前播放将切换。合法测试ROM来源在作者方案中登记；读档/复位是NES控制，不复位普通视频设置。退出NES释放其音视频/输入/存档句柄后回到无媒体状态，不声称自动恢复此前解码位置。普通暂停按钮对NES走其公开暂停能力。
- 工坊Pi编排在插件中：需求→模型mock→真实生成与校验→失败诊断修复→试载→用户点击安装→安装结果。mock仅替代模型调用，禁用付费调用；生成包和手写插件一样通过公共校验。安装前可取消；安装失败恢复此前可运行版本，不能用安装返回“已接受”显示成功。

## 4. 有限场景与反馈边界

- 列表：添加多个文件、移除、上移/下移、双击/播放选中项、上一项/下一项、顺序播完停止。添加不自动打断当前媒体；无媒体时也须显式播放选中项。媒体自然结束才推进，手动打开其他来源不错误推进旧队列；删除当前项不立即停止，保留当前来源说明。坏文件标记失败并停在该项，用户下一项继续，避免无限跳过。持久化/随机/网络列表不在本轮承诺中。
- 画面：明暗/对比/饱和/伽马、两个明确的本地预设、自有资源复位、高斯开关/强度；所有入口操作同一状态。高斯与基本参数同时作用。
- 音频：有限频段均衡器、延迟、规范化与增强的明确算法/开关、两个预设、自有资源复位。作者必须写范围与算法，不以“增强”文字代替可观察效果。
- 字幕：外部字幕选择、当前轨道选择/关闭、字体/字号/颜色等有限样式、同步偏移、一个确定性翻译场景、取消与过期结果隔离；不承诺通用在线翻译服务。
- 截图/导出：原始和处理后PNG，字幕包含选项；有限次数连拍；选择起止范围导出一种明确可播放格式；任务进度/取消/来源快照。原始帧不含效果与字幕，原始模式禁用字幕勾选并解释；处理后可选择字幕。MP4原始模式输出所选源音轨；处理后模式包含已确认且应用的音频工作台链与用户同步偏移，两种模式均不烘焙设备volume/mute。动态规范化按P1从原源0至导出起点完整重算，再裁取目标范围并重置PTS；详情记录起点/算法/边界，提示准备可能较长且支持取消。不复制实时内部历史，不保证与实时逐样本相同；若未来缩短预热范围须另行记录误差和审查。导出不改变实时播放位置。
- NES：一个实际支持的合法ROM场景、主画布输入、真实音视频、暂停/继续、一份存档保存/读取、切回普通文件资源释放。映射按键及ROM格式由作者方案明确，不承诺全ROM兼容。
- 工坊：一个可实际运行的有限新插件需求、一次错误后自动修复、试载、安装、取消、失败回退。试载关闭不等于安装，试载资源必须可清理。插件管理：可见运行状态、从包目录安装、启用/停用、版本/错误诊断、工坊安装事务的回退状态；不是应用商店。
- 任务统一显示 queued/running/cancelling/completed/failed/cancelled，未知进度用活动指示而非虚构百分比。启动失败显示原因；请求取消时保留“取消中”，收到终态才显示已取消。超时显示结果未知并可查询，不冒充取消成功。写输出使用临时文件，完成后原子发布；取消清理临时文件，已完成输出保留。

## 5. 对阶段 A 的能力请求（待评估，不是接口定义）

| 请求 | 具体产品操作 / 最小验收 | 所有权与失败语义 | 初版缺口与讨论边界 |
| --- | --- | --- | --- |
| B-01 原生嵌入 | 默认插件的Slint栏及列表侧栏分别挂主窗，开工具仍可暂停/拖进度 | 实例拥有组件；冲突明确报错；停用移除且媒体不停止 | 现有仅Window；需有限播放栏/侧栏主窗挂载，不造通用UI平台 |
| B-02 命令与可见性 | 所有菜单/快捷键/按钮共享enabled、checked、执行状态；工具关闭后勾选更新 | 插件拥有命令；通用路由拒绝重复ID；公共管理入口可恢复默认插件 | 缺菜单、快捷键、关闭/焦点/全屏公开事件；领域结构由设计表约束 |
| B-03 文件与集合 | 多选添加列表、选字幕/ROM/输出目录，取消选择不改会话 | 请求方拥有选择结果；取消单独结果；窗口播放持续 | 缺非阻塞文件选择与Slint列表model；不造文件管理器 |
| B-04 来源状态 | 两次快速open后只更新真实新session结果；列表只响应对应ended | 宿主持有来源generation和结构化结果；失败可重试 | 当前快照/诊断关联不可靠；不冻结具体状态字段 |
| B-05 处理资源 | 明暗+高斯、EQ+规范化共存；停用一方保留另一方效果 | 各实例拥有处理句柄；稳定顺序；设置失败不丢最近有效资源 | 当前裸set不能撤销链；需和作者算法/原生扩展一起审查 |
| B-06 字幕资源 | 轨道/样式读取与写入、翻译旧结果不能覆盖新媒体 | 宿主确认session/revision；过期提交明确拒绝 | 无轨道、外部字幕、样式、CAS式应用；翻译策略留插件 |
| B-07 快照与任务 | 实时播放不跳转地取原始/后处理帧和导出；切媒体输入不变 | 任务源快照/取消/进度归公共设施或明确原生提供者；插件业务自持 | 没有frame sampling/export/task；大帧不用JSONL传输 |
| B-08 外部AV来源 | ROM真实帧/音频/时钟/暂停输入，失焦释放键；切文件资源释放 | NES实例拥有producer资源；core按能力路由，不识别NES名 | 只有普通libmpv来源；需有限媒体producer契约，与NES作者评估 |
| B-09 包事务 | 工坊真实校验/试载/安装失败回退；停用不影响兄弟包 | 插件管理拥有安装事务；运行实例generation与安装版本分离 | load/disable不是持久安装；Pi与模型mock留插件侧 |
| B-10 呈现与首次准备 | 菜单驻留/已接入工具show-hide/文件选择实际音画持续；未知组件首次准备状态明确 | 普通操作不阻塞UI；首次组合编译保存/恢复状态，backend/session/实例不重启 | stable Slint可能需import组合重建shell；允许首次短暂UI闪动，实测耗时/边界，不宣称async即off-UI |

这些请求可合并为必要的少量公共能力，不要求十套子系统。插件作者须补具体usage、算法和失败例子；maintainer判断公共设施与插件原生模块边界。B-07任务状态可由各任务提供者通过公开契约呈现，不要求提前构建全局后台任务中心。SDK、Rust路由、生命周期和示例须在共同基线发布时一致。

## 6. 交互验收门槛与下一步

1. 对照menu-map逐项执行；唯一主菜单、按钮/快捷键状态一致；无插件名顶级菜单、无工具内重复复位。
2. 基础播放栏与所有工作台同时存在；主画布维持contain、主窗最小尺寸可操作；工具打开/关闭/最小化不改媒体暂停和位置。
3. 实际屏幕和音频验证菜单驻留10秒、拖动5秒、已接入工具show/hide和文件选择，画面与时钟持续；另测未知组件首次安装/激活的准备反馈、实际耗时、短暂闪动边界和布局状态恢复，两类场景均不重开backend/session/插件实例。headless帧计数只作辅助，不能替代原生证据。
4. 每个插件在其他七个产品插件不存在时通过统一测试宿主运行；关闭窗口与停用资源撤销分开测试。
5. 来源快切、旧字幕翻译回包、导出期间切媒体/调参、取消后迟到结果、插件崩溃/重启分别验证隔离；结果未知不能标完成。
6. NES与普通来源切换、输入失焦释放、音频资源释放；工坊真实工具循环与错误修复、安装回退有可复现产物。

各作者接下来只提交 `doc/design/plugins/<id>.md`，须含窗口草图、每条菜单操作、状态/范围、usage与缺口、独立运行、失败取消及可观察验收。全局交互负责人审菜单与共存，maintainer审能力和生命周期，独立验收者提出反例。汇总通过并与可运行公共基线对齐后，root才统一下发实现任务。
