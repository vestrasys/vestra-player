# 本轮验收矩阵：设计阶段草稿 R0

本表依据本轮 scope 和 B1 规范，不来自旧测试。所有产品场景均为待实现/待验证；阶段 A 的基础证据不能代替本表。各插件作者补齐具体控件、命令、输入及可观察结果后，由独立验收者审查，再随共同基线发布。

## 证据要求

- 实际交互：真实鼠标/键盘操作当前程序，记录入口、输入、前后状态和必要截图。系统文件面板须实际确认/取消，不注入路径结果代替。
- 处理结果：独立检查像素、音频样本、有效媒体文件、ROM执行和生成包行为；成功提示不代替结果。
- 自动检查：类型、构建、边界、契约、headless和回调各按实际范围报告，不升级为屏幕操作证据。
- 每项标明代码/构建修订、操作者、独立或组合条件、结果与证据路径。当前全为待验证，不以表存在作为通过。

## 公共与组合门槛

| ID | 必须成立的行为 | 必要证据 |
| --- | --- | --- |
| G01 | 全部八个产品插件实际加载，每个设计入口可发现，完整菜单树遵守领域归属 | 运行列表、真实菜单及逐入口清单 |
| G02 | 播放栏不被工具替换，侧栏可隐藏/恢复；尺寸不足、全屏、关闭工具和焦点规则一致 | 实际窗口操作及布局截图 |
| G03 | 菜单停留至少10秒、连续调参至少5秒时音画持续，最终值生效且session不重开 | 实际画面/声音观察及会话记录；参数效果另测 |
| G04 | 已接入组件显示/隐藏不重新编译；未知组件首次准备有反馈和可核验的状态恢复 | 实际操作、编译/会话记录、准备耗时和边界 |
| G05 | 原生文件面板确认/取消/失败后恢复，驻留不丢请求、不打断普通播放 | 各调用方的实际系统面板证据 |
| G06 | 各插件在其他产品插件缺席时可独立运行；组合时停用一个只释放自身资源 | 独立与组合运行、清理证据 |
| G07 | 来源快切、迟到事件、任务输入快照、取消与旧实例回包不会污染当前状态 | 复现步骤、实际结果及必要协议诊断 |
| G08 | 正常关闭、故障插件和取消任务后，进程/句柄/临时文件正确回收；已完成输出保留 | 退出状态、资源核对；持久文件与临时资源分开 |

## 组件场景

| ID | 组件 | 完整必要场景 |
| --- | --- | --- |
| P01 | 基础播放 | 打开有效/无效媒体、取消；实际播放/暂停/恢复、暂停seek、连续进度拖动、相对跳转、速度、音量/静音、关闭来源；未知时长与不支持能力反馈 |
| P02 | 播放列表 | 多选添加/去重、选择/双击播放、上一下一、移除/排序/清空、侧栏显隐；自然结束推进末项停止，坏项恢复、手动切源不错误推进 |
| P03 | 画面调节 | 所有参数、两个预设、复位、高斯开关/强度同时工作；关闭窗口保效果，停用只撤销自身资源；连续拖动不打断播放 |
| P04 | 音频工作台 | 明确频段EQ、延迟正负与零、规范化/增强及其参数、两个预设和复位；真实样本证明处理，连续拖动时画面/声音及状态符合设计 |
| P05 | 字幕工作台 | 文件/轨道/关闭、样式和同步；可见字幕与时间匹配；确定性翻译、取消、失败恢复及切源后旧结果隔离 |
| P06 | 截图/片段导出 | 原始/处理后PNG、字幕选项、有限连拍、片段范围、真实进度/取消；有效输出、拒覆盖或明确覆盖规则，切源/调参后快照不变，不跳实时播放位置 |
| P07 | NES | 合法ROM和坏ROM恢复、真实主画布/音频、全部映射输入与释放、暂停/继续、存档读写/取消/坏档；来源切换和关闭清理 |
| P08 | Pi插件工坊 | 需求输入、真实Pi工具循环和mock模型、错误诊断修复、校验、试载、安装、取消及失败回退；生成包实际可用，停用工坊不让已安装包失效 |
| H01 | 通用管理与宿主 | 包加载/启停/诊断、默认插件缺席仍可管理、资源所有权、唯一ID与能力错误、安装事务与实例生命周期区分；safe Rust及跨插件依赖审查 |

按钮、菜单和快捷键是不同可达路径；共享逻辑不意味着只测试其中一个。作者方案须展开每个已实现入口和参数，避免用“工作台正常”概括整套功能。必要缺陷必须修复复验；环境确实无法验证的项标为未验证，不将全局 goal 标完成。
