## 2. 完整功能 → 唯一主菜单 → 插件 → 界面形式

同一行内斜线分隔的不同命令各有上方完整路径。按钮、快捷键是同一命令的别名，不能注册第二份状态。`…`表示打开选择器/窗口或聚焦其中一节；无省略号的菜单立即执行或切换。

| 功能 / 命令 | 唯一主菜单 | 负责插件/设施 | 界面与其他必要入口 |
| --- | --- | --- | --- |
| 打开普通媒体 | 文件→打开媒体… | 基础播放 | 非阻塞文件选择；播放栏打开按钮；Cmd/Ctrl+O |
| 关闭来源 | 文件→关闭当前来源 | 基础播放 | 立即释放当前来源；无来源禁用 |
| 应用退出 | 文件→退出 | 通用宿主生命周期 | 系统关闭；有任务按全局规则处理 |
| 播放/暂停 | 播放→播放/暂停 | 基础播放 | 常驻栏；主画布Space；能力不足禁用 |
| 时间跳转 | 播放→跳转到… | 基础播放 | 轻量时间输入；栏内时间按钮/进度拖动 |
| 相对跳转 | 播放→后退5秒 / 前进5秒 | 基础播放 | 主画布左右键；不改pause |
| 倍速 | 播放→速度→各项 / 自定义… | 基础播放 | 常驻栏倍速选择；自定义0.25–4倍 |
| 音量与静音 | 音频→音量… / 静音 | 基础播放 | 常驻栏音量滑条/静音；音量浮层 |

字幕/导出/NES/工坊窗口内上下文按钮不都提升为全局菜单项：例如“取消这个任务”依赖具体任务选中状态，“保存存档”依赖NES会话；它们的唯一主入口如表所示。插件作者须在方案列出具体按钮行为，不能借此隐藏必需场景。

## 3. 菜单状态与冲突规则

- 顶级顺序、路径、命名由本表统一；插件贡献命令与状态到公开路由。core可校验路径和冲突，不按插件名称构建业务菜单。未安装的可选插件不留下空菜单；源能力不足的现有命令保留但禁用，并显示简短原因。
- 右键主画布投影同一完整菜单树（文件、播放、视频、音频、字幕、视图、模拟器、插件），沿用同一命令的enabled/disabled和checked状态，不登记另一套主菜单/逻辑。全屏或菜单栏隐藏时，文件打开、插件管理和工坊仍可发现。本轮不支持右键菜单自定义。
- 播放栏/列表可见性勾选表示公开确认的用户显隐偏好，effective visibility及暂隐原因另列；其他勾选显示真实确认状态；预设命中与自定义参数一致，修改一个参数后预设显示自定义。相互排斥项用单选；执行中状态禁用重复启动，但取消可用。
- 所有副入口均调用同一公开命令，或在同插件内调用同一action；插件不能为调用兄弟插件而直接依赖其command私有协议。共享播放操作使用公共播放设施，共享可见性使用通用挂载/窗口设施。
- 无媒体仍允许打开工作台、编辑下次使用参数和查看既有任务；即时取样、轨道及来源相关动作禁用。NES来源的unsupported参数/字幕/取样禁用且说明，不把普通视频设置误写到NES实例。
- 菜单展开不暂停、seek、重新加载或阻塞画面，工具关闭不改勾选效果。缺能力要显式说明，不能展示看似可用却静默无效的项。

## 4. 待插件方案细化，不扩大主菜单

作者需确定EQ频点/算法、规范化与增强参数、字幕样式集合、翻译mock的有限内容、导出格式/连拍上限、NES核心和按键、工坊生成样例。这些是已登记场景的细化，不得删掉scope内容或假定工作API已经支持。预设的具体数值可调整，但菜单名/归属变化交统一审查。B1没有产品取舍待用户裁决；必要API与Slint能力仍待maintainer和独立审查反馈。
