# 基础播放插件方案 C2

日期：2026-10-17。依据 `product-interaction.md` / `menu-map.md` B1 与阶段 A `vestra.experimental/0.1`。这是有限设计提案，不是实现任务；拟议 API 均未批准。仅阅读本轮授权需求、设计、SDK 和 `src/examples/capability-demo`，未读取旧实现。提交后须集中审查并收到共同开发基线才开始产品代码。

## 1. 职责与场景

默认启用的 TS 插件负责普通文件打开策略、播放/暂停、绝对与相对跳转、速度、音量/静音及主窗口常驻播放栏。Rust 宿主拥有播放设施、来源会话、主画布、原生窗口、通用挂载、命令路由与生命周期；Slint 负责原生控件与布局。宿主不按本插件 ID 特判。

本插件直接通过公开播放设施控制当前来源，不 import、消息通知或读取播放列表/NES 等兄弟插件。来源可能是普通视频、音频或公开能力的其他生产者；不根据文件扩展名、插件名猜测能力。队列推进、ROM读取、画面处理、音频工作台、字幕、导出、插件管理及完整 PotPlayer 功能不在本插件范围。

独立运行只需统一宿主、实际播放后端、公开SDK、原生Slint接入和本插件包，其他七个产品插件可全部不存在。无 GUI 的宿主只能用于契约辅助检查，不作为常驻播放栏验收。缺嵌入能力时登记阻塞，不用外部播放窗或独立控制窗替代主窗播放栏。

## 2. 入口与命令表

命令 ID 为本插件拟议本地标识，最终注册形式待 maintainer；下表路径严格沿用 B1。右键主画布由宿主投影同一菜单树，菜单、栏、快捷键共享同一 action 与状态，不重复注册状态。所有来源相关禁用项显示明确原因。

| 功能/拟议命令 | 唯一主菜单路径 | 其他入口 | 执行/界面 | 启用条件 | 权威状态 |
| --- | --- | --- | --- | --- | --- |
| `open` | 文件→打开媒体… | 栏“打开”、Cmd/Ctrl+O | 单文件非阻塞系统选择器；确认后请求切源 | 选择器未打开；打开中允许再次选新文件 | 选择器结果、结构化来源状态 |
| `close-source` | 文件→关闭当前来源 | 无新增按钮 | 释放当前来源，回无媒体 | 有来源或正在加载；来源支持关闭 | 当前session/来源能力 |
| `toggle-pause` | 播放→播放/暂停 | 栏按钮；主画布Space | ready切换pause；ended请求从头重播 | ready且支持pause，或ended且支持restart；加载中禁用 | 确认pause、pending |
| `jump` | 播放→跳转到… | 栏时间按钮；进度拖动 | 时间输入弹层；进度直接seek | ready且支持绝对seek且时长已知 | session、position、duration |
| `backward-5` / `forward-5` | 播放→后退5秒 / 前进5秒 | 主画布左/右键 | 从最新确认位置±5秒 | ready、可定位且公开支持相对seek；位置已知 | 来源能力、position |
| `rate-05/10/15/20` / `rate-custom` | 播放→速度→0.5倍 / 正常速度 / 1.5倍 / 2倍 / 自定义… | 栏速度选择器 | 预设直接设置；自定义数值弹层0.25–4倍 | ready且支持rate；无媒体禁用 | 确认rate；预设单选/自定义 |
| `mute` | 音频→静音 | 栏静音按钮 | 切换真实mute，保持volume | 公共输出设施存在且支持该操作；无媒体仍可编辑其当前共享状态 | 公共确认mute、volume |
| `volume` | 音频→音量… | 栏滑条 | 同一音量浮层0–200% | 同上 | 公共确认volume、mute |
| `bar-visible` | 视图→显示播放栏 | 无额外隐藏按钮 | 切换手动显隐偏好 | 本插件已挂载 | 公开挂载用户显隐偏好 |

视图→全屏/F11是通用宿主命令，本插件只观察公开窗口状态并参与栏显示策略，不注册第二个全屏命令。退出同样由宿主提供。NES控制窗可调用公共pause设施，不需要引用本插件的命令ID。

## 3. 界面与生命周期

唯一主窗底部常驻栏，默认显示，普通窗口目标高96逻辑像素。底栏横跨全窗，列表侧栏仅占上部；工具窗口打开、关闭、最小化都不能占用此挂载或改变pause/seek。有限通用挂载声明负责冲突拒绝，不允许最后打开的工具覆盖播放栏。

```text
主画布（宿主管理，contain）        可选列表侧栏
────────────────────────────────────────────
 [──────────●──────────]  01:23 / 04:56 [状态]
 [打开] [播放/暂停] [跳转…] [1.0倍▾] [静音] [──●─] 80%
```

使用原生 Slint Grid/HorizontalBox/VerticalBox、Slider、Button、ComboBox；不增加布局DSL。720×480主窗下保持两行，将进度区域弹性缩短、状态文本省略（完整原因可提示），核心按钮与音量仍可点。可用屏幕小于最小布局时容许栏增加行数、主画布缩小，控件不能被裁掉；时间/速度/音量弹层的确认和取消始终可达。首轮不提供可定制按钮排列。

时间输入弹层包含 `HH:MM:SS.mmm` 输入、合法范围提示、跳转/取消；Enter确认，Escape取消。速度浮层包含数值/确认/取消；音量浮层与栏同一状态，无独立设置副本。失焦隐藏浮层但不回滚已成功音量操作；未确认的时间/速度草稿丢弃。焦点进入首个适用控件，关闭后回发起控件；无效输入留在原处显示原因。

显示播放栏普通窗口切换不改媒体；隐藏后菜单与有效快捷键可继续控制。全屏栏为底部覆盖层，手动显示偏好为true时鼠标移动/键盘操作显示，3秒无操作隐藏；拖动、菜单展开、栏内焦点/浮层存在时保持显示。手动偏好false时不因自动活动重新显示，仍可从视图菜单恢复。全屏自动隐藏不修改普通窗口偏好；root已明确菜单勾选表示用户显隐偏好；实际可见状态另由公开挂载状态反映，插件不读host内部。Escape先交给菜单/浮层，随后退出全屏。

键盘仅在公开主画布焦点域且来源未捕获输入时处理Space/左右；文本或数值编辑器拥有输入时不得触发。NES等来源捕获画布输入时映射优先，普通视频快捷键不抢按键。菜单/选择器/工具激活的焦点与已按键释放交公开input设施；本插件不直接合成NES按键或改变其pause。

激活只声明命令和挂载，不自动打开文件、不抢焦点。隐藏栏保持实例和订阅；停用/崩溃由宿主释放本实例的挂载、菜单/快捷键、选择器与订阅，媒体和已提交速度/音量/pause保持。丢弃插件草稿和排队操作，不为“清理”发全局复位。重新启用读取当前事实恢复栏。首次组件组合若需shell准备，遵循B1“准备界面”、布局/焦点保存与状态恢复规则；不能声称现有窗口API已满足嵌入。

## 4. 状态、连续交互与失败

所有事实来自公开来源状态；本地仅保存偏好、编辑草稿、最新待提交值与请求令牌。宿主状态需至少包含session/generation、source、loading/ready/ended/error、pause、position、duration、mute/volume/rate及来源能力。确认“接受load”不能显示“打开成功”；不能解析 `playback.backend` Debug 文本推断完成。

| 状态 | 栏及操作 |
| --- | --- |
| 无媒体 | 显示“未打开媒体”、时间 `--:-- / --:--`；打开可用，pause/seek禁用；无媒体速度禁用；音量/静音仅在公共输出设施存在时可编辑，不新增下次来源默认值API |
| 加载 | 显示新来源名和“正在打开”；立即清除旧进度，禁用该session的pause/seek/rate；允许重新打开或关闭取消本次来源 |
| ready且播放 | 时钟跟随事实；pause按钮显示“暂停”；菜单展开与所有非seek操作不中断画面 |
| ready且暂停 | 按钮显示“播放”；seek保持暂停，新位置画面应实际更新 |
| 未知时长 | 总时长 `--:--`，进度不显示虚假百分比；绝对拖动/跳转禁用；若公开支持相对seek且position已知，±5秒仍可用，下界0、不假设上界 |
| ended | 显示“已结束”；播放按钮请求公开restart从头播放（不支持则禁用并说明）；这是新来源控制意图，使旧natural-end的迟到自动推进过期；不自行推进队列 |
| error | 保留失败路径/结构化原因，显示局部“重试”按钮复用open action；不把旧来源状态投给失败新来源，不自动反复重试 |
| 来源能力不足 | 显示真实pause/时钟；不支持的seek/rate/volume禁用并解释；不能将普通mpv设置写到NES生产者 |

**选择与快速切源。** 同时最多一个本插件文件选择器；重复打开聚焦已有选择器。取消无会话副作用，播放持续。确认路径才发open；从NES切到普通媒体时选择器确认文案说明当前来源将替换。A已发出后再选B，允许B成为最新意图；宿主分配单调session并保证过期A完成/失败不覆盖B。所有未发seek、旧草稿及旧弹层目标在session变化时废弃；迟到确认只能记录为旧请求结果，不能改B栏。关闭来源也以当前session为条件，宿主负责释放来源音视频/输入资源；本插件不能替来源提供者清理私有句柄。

**进度拖动。** pointer-down绑定当前session和已知duration；拖动立即显示目标时间草稿，期间真实时钟仍可获取但不把滑块拉离指针。目标限定0..duration。单在途请求，采样最多约30次/秒，队列只留最新值；在途完成后仅提交最新草稿，绝不积压每个mousemove。pointer-up无条件标记最终值，等待在途完成后最后提交；得到最后操作的确认和对应session状态后退出“跳转中”。中间确认不得覆盖更晚草稿。失败停止本轮待发值，回最近公开确认position（时钟可能继续前进），显示局部错误；不能回滚到过期的拖动起点。timeout显示“结果未知，正在核对”，先读公开状态再解除pending，不假称取消成功；迟到结果按请求序列隔离。Escape/pointer-cancel仅丢弃未发草稿，已接受的seek不承诺撤销。整个流程从不写pause；暂停seek后仍暂停，播放seek后仍播放。拖动中切源立即作废旧轮，宿主必须拒绝旧session未执行请求。

相对seek/时间确认同样绑定session，已知时长时限幅。快速±5秒按本插件最后待提交目标累加并合并，不反复取同一个旧position；失败回最新确认值。重复pause点击在单次确认期间禁用所有别名，确认后恢复，避免读旧值连续反转。超时核对真实pause，不盲目重试toggle。

速度0.25–4倍，预设匹配确认值才勾选；编辑中显示草稿/待确认，失败还原最近确认rate。音量0–200%，连续拖动沿用latest-only、最多30Hz、释放最终值与错误规则，不暂停。音量/静音只操作公共输出设施的当前共享事实；无媒体且该设施存在时可改，否则禁用，不保存下一来源默认值。静音使用独立confirmed muted事实，保持volume不写0；解除静音保持同一volume。volume=0不自动勾选静音，解除后仍为0也不擅自跳到100%。用户主动设音量时直接设置目标并解除静音，不先恢复旧大值；具体原子或有序提交由maintainer确定，不增加恢复历史平台。错误回到公共确认事实，不用本插件私有布尔值伪装共享静音，不修改他方处理资源。

**结束后重播竞态。** ended的播放按钮只有公开restart能力存在时可用，不把seek(0)+unpause当作所有来源实现。用户显式restart是新的来源控制意图；公共来源版本/条件校验（例如CAS）使旧natural-end触发的迟到auto-next过期，不能在重播开始后再次跳走。基础播放不发送播放列表专属消息，也不负责选择下一项；具体身份、版本与restart签名由maintainer在现有来源控制能力中收敛，不预建新事务平台。

## 5. 公共 API usage 与缺口

**初版已有（仅说明调用形状，不宣称产品可完成）：**

```ts
const caps = await host.capabilities();
const initial = await host.playback.state();
const off = await host.events.subscribe("playback.state", updateFromPublicState);
const accepted = await host.playback.open(path); // 仅接受；实际成功目前无可靠结构化关联
await host.playback.set("pause", false);
await host.playback.seek(12); // 非负绝对秒；没有session guard
await host.playback.set("speed", 1.5);
await host.playback.set("volume", 80);
```

`updateFromPublicState`仅为插件自有action示意。初版 `ui.open/set/show/close` 是独立Window与primitive属性，不能冒充嵌入。当前没有菜单、键盘域、选择器、close-source、mute或最终来源状态；`volume/rate`快照可选且没有确认mute。现有set回包不表示画面已经实际呈现。无条件旧session写入不能满足来源快切，故这些例子不是最终产品开发基线。

**以下全部为请求扩展的拟议 usage，不是 SDK 声明，具体签名由 maintainer 评估：**

```ts
const bar = await host.ui.mount({ // PB-01；有限通用slot，无插件名特判
  slot: "main-bottom", component: "PlaybackBar", file: "bar.slint",
  preferredVisible: true,
});
const command = host.commands.register({ // PB-02；所有入口引用同一状态/action
  id: "toggle-pause", menu: ["播放", "播放/暂停"],
  state: derivePauseCommandState, execute: toggleCurrentSession,
});
host.input.bind({ context: "main-canvas-unclaimed", key: "Space", command });
host.window.observeMain(updatePublicFullscreenAndFocusContext);
const choice = await host.dialogs.openFile({ kind: "media", multiple: false }); // PB-03
if (choice.status === "selected") await host.playback.open(choice.path);
const state = await host.playback.state(); // PB-04：结构化phase/caps/确认字段
await host.playback.seek({ session: state.session, seconds: finalDraft });
await host.playback.control({ session: state.session, pause: !state.paused });
await host.playback.close({ session: state.session });
await host.playback.output({ volume: 80, muted: false }); // 一次有序输出提交
```

| 请求/关联 | 当前不能完成的操作与最小结果 | 所有权/输入输出 | 失败、取消、清理与影响 |
| --- | --- | --- | --- |
| PB-01 / B-01,B-10 | 本插件栏嵌主窗，工具打开仍可暂停/拖动；全屏覆盖层 | 宿主持有原生组件与slot，实例持有挂载句柄；输入Slint组件与有限位置/显隐偏好，公开返回实际可见状态、布局及准备状态 | slot冲突报错、不覆盖他方；隐藏不释放；停用清本实例挂载；首次准备保存布局/焦点，不重启session。与列表侧栏共存，影响通用UI消费者 |
| PB-02 / B-02 | 菜单/按钮/快捷键同enabled/checked/pending；全屏3秒自动隐藏受焦点/菜单/拖动约束 | 实例拥有命令/绑定；宿主拥有window/input焦点域、全屏、菜单捕获与挂载状态；公开事件即可，无须插件访问私有对象 | 重名/无效路径明确拒绝；失焦释放输入，来源捕获优先；停用移除自有注册；root已明确勾选为用户偏好，自动隐藏另反映实际状态 |
| PB-03 / B-03 | 播放时选单文件，取消仍在原位置播放 | 本实例拥有选择请求；输入媒体筛选、返回selected/cancelled；不要把取消当错误 | 窗口关闭/停用取消选择请求，迟到结果不得open；选择器失败局部原因；同实例重复打开聚焦；音画连续需原生验收 |
| PB-04 / B-04,B-08 | 快开A/B只显示B，暂停seek不恢复播放，关闭来源释放当前资源，NES能力不足禁用 | 宿主持有结构化phase/session、能力、确认控制状态及来源资源；所有来源控制含session guard，输出mute/volume/rate可被所有消费者观察 | 过期session拒绝且不碰新来源；load失败保留原因；accepted/ready分离；关闭取消正在加载的当前来源；瞬时操作无撤销承诺，timeout查询；适用于播放列表与任意公开来源，不命名NES |

PB-04按R1补充公开restart及来源意图条件、真实mute保持volume的有限语义；具体签名仍待maintainer，不用“先seek(0)再pause(false)”假设所有来源均可seek。以上均已发送 maintainer 评估，属于阶段C能力设计，不批准破坏性签名切换。

## 6. 可观察验收

样本使用本轮新建的有时钟画面/音轨合成短片与长片，未知时长由本轮公共测试来源提供；NES组合使用其合法本轮ROM，不读取旧测试媒体。测试辅助事件不能替代实际屏幕和音频。

| 场景 | 实际操作 | 可观察结果/证据 | 条件 |
| --- | --- | --- | --- |
| 独立空载 | 仅本插件启动，逐一打开所有菜单、右键菜单与栏 | 唯一路径一致；打开可用；pause/seek禁用有原因；栏位正确；实际屏幕 | 独立 |
| 打开成功/取消/错误 | 栏、菜单、Cmd/Ctrl+O分别选本轮文件；播放中取消；选择坏文件并重试 | 选择期间音画持续；取消不切源；加载/失败路径清晰；成功后才ready | 独立，系统面板+屏幕/音频 |
