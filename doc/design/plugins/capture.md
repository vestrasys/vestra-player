# 截图与片段导出方案 C2

日期：2026-10-17。实验设计稿；依据 [B1 产品交互](../product-interaction.md)、[菜单表](../menu-map.md)、[scope](../../rebuild/scope.md)、插件方案模板及本轮初版 API 文档。仅设计，不是实现或验收通过声明。

## 1. 职责与有限范围

本插件负责保存当前画面、有限连拍、片段导出及自身任务管理。TS 管选项、校验、任务策略和 Slint 交互；Rust 公共设施持有来源与资源生命周期，成熟解码/滤镜/编码组件处理像素。普通视频逐帧像素不经 TS/JSONL 往返。
初版支持本地、可独立重读的普通视频，PNG 与 MP4 两种输出；不承诺网络直播、受保护媒体、NES 帧源、HDR 保真、GPU 零拷贝、批量队列或后台托盘。
只有本插件与公共宿主也能运行；不要求画面、字幕、音频插件存在。无处理资源即恒等处理，无选中字幕即无字幕；已发布资源只从公共快照设施读取，不 import、消息调用或读取兄弟插件文件。

## 2. 入口、命令与权威状态

| 功能/命令 | 唯一主菜单路径 | 行为与其他入口 | 启用及事实来源 |
| --- | --- | --- | --- |
| `capture.still` | 视频→截图与导出→保存当前画面… | 显示统一窗口，聚焦截图区；保存按钮执行同一 action | 菜单始终可打开；启动依公共来源能力 |
| `capture.burst` | 视频→截图与导出→连拍… | 同窗聚焦连拍区；开始/取消按钮 | 同上 |
| `capture.clip` | 视频→截图与导出→导出片段… | 同窗聚焦片段区；开始/取消按钮 | 同上；必须已知有限时长 |
| `capture.tasks` | 视频→截图与导出→查看导出任务… | 同窗聚焦任务区；查询/取消/重试/打开产物按钮 | 无媒体也可查看已有任务 |

不在文件、工具或视图另设重复菜单，无默认快捷键。主画布右键仅投影同一菜单命令。任务运行时入口显示运行数量，状态由公共任务句柄确认；表单值由插件保存，不能把最近轮询的播放状态当作任务输入快照。

## 3. 单窗布局及控件

默认隐藏，唯一非模态 Slint Window，初始 680×560、最小 520×400 逻辑像素；空间不足时内容滚动，底部状态/取消可达。

```text
┌ 截图与导出                 当前来源/可用性 ┐
│ [保存当前画面] [连拍] [导出片段] [任务(N)] │
│ 截图：原始/处理后   □包含字幕              │
│        输出路径…             [保存…]      │
│ 连拍：次数 5  间隔 1.0秒  起点=启动时位置 │
│        输出目录…             [开始]       │
│ 片段：起点/终点 原始/处理后 □包含字幕      │
│        音轨：无/明确轨道      [导出…]      │
│ 任务：来源·创建时间·范围·选项·状态·进度    │
│       [取消] [查询] [重试…] [打开产物]     │
├ 状态/局部错误                  [取消任务] ┤
└───────────────────────────────────────────┘
```

四区为同窗标签/区段，入口只定位相应区，不创建四个窗口。截图/连拍/片段均有原始/处理后选择；原始模式禁用“包含字幕”并显示“不含效果和字幕”。切回处理后才恢复用户勾选偏好。处理后默认不含字幕。
截图输出为源视频呈现方向、像素宽高比校正后的完整 PNG，不截取 Slint 窗口或主画布留黑；原始指未应用播放效果及字幕，不声称保留压缩码流或 HDR 元数据。处理后应用快照中的画面链，字幕在其后合成。尺寸/色彩转换写入任务详情；本轮限定 SDR 8-bit RGB。
连拍次数 2–20、默认 5；媒体时间间隔 0.1–10 秒、默认 1 秒；启动预览显示预计时间序列。按 `t0+i×间隔` 独立采样，不是每隔墙钟时间截当前播放窗口。超出已知时长则拒绝启动并提示减少次数，不静默缩短。
片段起止以秒编辑，默认当前时间至其后 10 秒（不超过总时长），要求 `0≤起点<终点≤时长`；支持 0.1 秒输入，端点按解码时间戳取帧。输出 MP4，H.264 视频、AAC 音频；界面显示实际编码器可用性。音轨明确选择快照中一条或“无”，默认当前选中轨，无轨则无音频；不混多轨。
片段原始/处理后与字幕规则同截图；原始模式输出所选源音轨，不含音频工作台处理或用户同步偏移。处理后模式冻结公共设施中 confirmed-applied 的音频工作台链、顺序、算法版本及用户同步偏移，包含 EQ/增强/动态规范化等已确认处理；待应用或失败配置不冒充已生效输入。两种模式均不烘焙设备输出 volume/mute，音轨字段旁明示该规则。无音频时输出合法无声 MP4。
动态规范化按 P1 从原源时间0解码、处理至导出 start 全段重算，再裁取所选片段并重置输出 PTS；详情记录 preroll 范围、算法版本与同步边界。长来源可能准备较久，准备阶段显示忙碌/已处理媒体时间并允许取消，不虚构百分比。不复制实时 DSP 内部状态，不承诺与实时逐样本相同；未来缩短 preroll 必须有锁版算法实证并同步公共基线。用户偏移与处理延迟补偿遵循公共锁版语义，编码保持所选视频范围与同步关系。
打开后焦点进入该区首个可用控件；已显示时置前，不重建/重置表单。编辑器内按键只编辑，进度事件不抢焦点。关闭或无弹层时 Escape 隐藏，回到来源窗口原控件；再次打开恢复表单与任务。
窗口不置顶、不挤占主画布/常驻播放栏。关闭后任务继续，完成/失败非抢焦点通知；停用才取消自有未终态任务，宿主退出遵循 B1 的任务选择。

## 4. 启动、快照、输出与恢复

无媒体/加载中/不支持独立取样时允许编辑与查看任务，启动禁用并说明具体原因。播放中或暂停中启动均不调用 pause/seek/open，不改变现有暂停状态或位置；片段/连拍使用独立离线解码。
点击保存/开始先记录 expected source generation、校验表单，再显示非阻塞系统 Save（单 PNG/MP4）或目录选择（连拍）。选择取消不启动任务、不固定输入、不改变来源。面板返回后必须显示最终确认区：来源文件名、截图/连拍“启动时固定当前时间”、片段明确范围、处理/字幕/音轨与路径，并由用户点击“确认启动”。若面板期间来源 generation 变化，显著提示来源已变，要求重新选择/核对当前来源并重新确认，不能悄悄取新源。
最终确认启动事务被接受时，公共设施原子校验 expected source 并固定 source identity、generation、精确媒体时间/范围、画面效果链版本及参数、字幕内容/样式/同步/选轨、音轨、confirmed-applied 音频链/顺序/算法版本/用户偏移及 preroll 策略，以及输出选项，显示固定来源文件名/创建时间和实际采样时间 t。截图“当前”指最终确认接受时的精确媒体时间，不沿用最初点击保存的旧位置；确认区与接受之间来源再变则拒绝启动并重新核对，不使用约100ms旧状态。
快照拥有可持续读取的来源租约及视频/音频处理、字幕所需不可变数据；不是只有可变路径和节点 ID。后续切媒体、调参、移除字幕、停用画面或音频处理插件，已启动任务仍使用旧输入。不能保留指向被停用插件进程的惰性回调；不支持独立复制/租赁的资源必须在启动前拒绝并说明。
任务开始后源文件被移动/替换不得静默读新文件；租约保证旧内容，或任务以 source-unavailable 明确失败。快照时间与解码实际采样时间同时可诊断；不能用当前 renderer 低分辨率 buffer 冒充原始源帧。
单次表单启动中禁用重复点击；最多一个正在处理的自有任务，另允许最多四个排队任务，超限显示等待/取消选项。排队项也在接受时固定快照，不等轮到执行才取当前来源。
任务使用 queued/running/cancelling/completed/failed/cancelled；进度已知显示帧数/总量或媒体时间，未知用活动指示。取消请求后保持取消中；仅后端终态确认已取消。超时是结果未知，显示查询，不自动重发写文件或宣称失败/已取消。
所有输出先写同目录唯一临时文件，编码完成及验证通过后以无覆盖发布操作落地；已有路径一律不覆盖。系统 Save 即使确认替换，插件仍要求换名并解释保护规则；自动建议递增后缀，但提交时再次原子检查，避免竞态覆盖。
连拍先预留唯一子目录，文件名带序号与媒体时间；每张独立验证后发布，任务详情逐张列出。已有同名子目录则另选或生成新名字。取消/失败保留已发布 PNG，删除未发布临时文件；MP4 中断不发布半成品。
完成后“打开产物”只针对确认存在的发布文件；失败保留来源、选项、阶段与具体错误，权限/空间/编码器错误可换路径后重试。重试是用户启动的新任务，明确选择保留旧快照（租约仍有效）或重新固定当前输入，不暗中换源。
任务终态后释放解码器/编码器/文件句柄；详情只保留小型元数据。旧快照只在明确的失败重试保留期内持有（本轮会话内最多5分钟），到期释放并提示必须新取快照。关闭界面不释放运行输入；停用/崩溃由公共设施取消任务、回收快照/子进程/临时文件，已发布产物保留。

## 5. 初版 usage 与能力请求

```ts
const caps = await host.capabilities();
const state = await host.playback.state(); // 只显示来源提示，不作为导出快照
await host.ui.open("capture", "capture.slint", { status: "待选择" }, ["save"]);

```

```ts
// 请求扩展：公共事务在接受时校验expectedSource并固定全部输入
const job = await proposedMediaJobs.start({
  expectedSource, time: { start, end, count, interval },
```
