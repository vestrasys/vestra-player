## 职责、入口和窗口

TS 插件用成熟 yt-dlp 解析 YouTube 单视频并执行下载，Slint 显示输入/状态/任务，公共 source 与 mpv 播放媒体。支持公开单视频网址（watch、youtu.be、Shorts；最终以 extractor 识别结果为准），不展开频道/远程播放列表，不做站内搜索、登录浏览器、DRM、会员/付费访问或直播录制。不承诺所有地区、视频及清晰度。网址带 list 参数时仍明确按单视频处理；纯列表 URL 返回本轮不支持。

| 命令 | 唯一菜单提案 | 行为 |
| --- | --- | --- |
| `youtube.open` | 文件→网络来源→YouTube… | 显示/聚焦唯一工具窗的播放区 |
| `youtube.download` | 视频→下载→YouTube视频… | 同一窗口聚焦下载区；不触发来源切换 |

通用打开网络入口、列表添加链接由各自消费者贡献；本插件仅注册公共 URL provider。不给本窗口加“直接加入列表”专用按钮，不直接执行列表私有命令。用户在列表添加/选择 YouTube 即可满足队列用法。

独立非模态窗口建议 600×500，最小 440×340，普通 Slint 布局：顶部“视频链接”输入；播放区“播放/取消解析”、状态/可重试错误；下载区“保存到…”、目标名、格式摘要、“开始下载”；下部可滚动任务行含来源标题、状态、已接收字节/总量、速度/剩余时间（有值时）、取消和完成文件路径。默认隐藏，显式入口打开，关闭仅隐藏；再次打开恢复输入/任务。小屏滚动保持取消可达。后台进度不抢焦点，菜单/工具/选择目录期间播放继续。输入框内 Space/方向键用于编辑，不触发主播放快捷键。

无媒体/暂停/播放时均可编辑网址和下载；只有显式“播放”提交新的 source 意图。解析中禁重复播放，可编辑下次输入但当前任务固定输入快照。播放接受不等于 ready；主画布/播放栏都以公开 source 为准。播放停止/重试不等于停止下载；下载失败不暂停现有媒体。菜单和按钮共享 command/action 的 busy/enabled/reason，下载任务进行中菜单可带数量。

## 播放及列表协作

provider 收原网址→匿名 yt-dlp 结构化解析→选可用且后端可解码的格式→通用媒体描述→mpv。优先可播放的完整音视频组合；分离流交成熟 mpv 外部音轨机制同步，不把仅视频 URI 冒充成功。格式/请求头、有限网络重试/重解、依赖检查由 TS 持有。过期参数、签名及底层质量 ID 不进入普通产品控件。

列表的 YouTube 行保留原网址并走相同公共 source route，ready/error/natural ended 的身份和条件语义与本地媒体一致。本站点插件不知当前队列或下一项，也不读取 playlist 文件、对象或专用消息；没有列表时仍可独立播放和下载。公共 SITE-01 缺失时显示“网络来源解析能力不可用”，不绕过成裸 mpv 网页 URL 假实现。

## 下载任务与文件安全

仅由用户明确启动；目录面板取消不创建任务。每任务冻结原网址、目标位置、格式策略及插件实例代次。默认最佳可用音视频合并为实际兼容容器，目标扩展名依据选择结果显示，不承诺强制 MP4/所有编码可用；需要 ffmpeg/ffprobe 而缺失时在启动前报具体错误。完整单文件格式可在能力具备时独立工作，不静默下载无声画面。

插件在目标文件系统创建随机私有任务目录，yt-dlp 仅写入该目录（含 `.part`、分轨与合并中间件），使用 `--no-overwrites`。标题需清理分隔符/保留名并限长，用户目录以外路径拒绝。成功须确认子进程退出成功、实际产物存在且后处理完成，最后通过文件系统原子“不替换已有目标”提交；不得以先 exists 再可覆盖 rename 规避竞态。提交时重名显示“文件已存在，请另选名称”，保留本次私有结果供改名重试；不覆盖、不把旧文件显示成本次成功。不支持原子 no-replace 的目标文件系统明确失败并可重选目录。该策略在 TS/成熟文件工具内完成，不向 core 提下载事务接口。

用 yt-dlp 机器输出/进度模板，区分解析、下载各流、合并、提交、完成；不解析普通终端进度条。未知总量显示字节和不确定进度，不虚构百分比；多流百分比仅在总量可靠时聚合，100% 传输后仍显示“正在合并/保存”。文件任务可在窗口关闭后继续；任务完成/失败非抢焦点提示。

取消：先记录 cancel-requested，停止所属 yt-dlp/ffmpeg 进程树，等待退出并清理本任务临时文件后确认 cancelled；失败如实显示清理失败及位置，不删除既有目标文件。取消与提交竞态按最终文件事实结算：若已原子提交，显示完成且说明取消前已保存，不谎报已取消。重试创建新任务/新暂存目录，不借旧 `.part` 跨网址续传。停用取消未完成任务并清理，已完成文件保留；主窗退出遵守产品既有任务确认规则，不私设后台托盘。

本轮匿名公开样本，不读用户 cookies/密钥。以后如支持显式凭据，站点插件负责作用域和私密临时文件，公共播放器只收必要受限请求上下文，列表/日志不拿到凭据。登录/地域/付费/DRM 错误直接说明限制。

## 能力与验收

当前 commands、普通窗口/dialogs、公共 source 状态可复用；站点解析依赖 SITE-01（resolver+typed media descriptor），播放中自动重解取决于 SITE-02。TS 子进程、下载文件与队列由插件承担，不申请 core YouTube 下载 API。依赖及离线分发见公共调查；EJS/runtime 不能漏报。

最小纵向切片：窗口粘贴公开链接→真实有声播放；独立下载同一允许使用的公开视频→可播放完成文件且状态真实。后续覆盖通用打开、列表加入/选择 YouTube、分离音视频、解析时切源/停用、过期/网络错误、缺依赖、任务取消与重名竞态、窗口隐藏播放连续性。实际运行版本、原生交互、音画/文件证据分别记录；当前全为待验，不用工具文档替代真实播放证明。
