# 字幕工作台设计 C2

日期：2026-10-17。阶段 C 有限方案，依照 product-interaction.md / menu-map.md B1、插件方案模板和 `vestra.experimental/0.1` 工作版。尚未批准公共扩展、发布共同基线或开始实现；本文不是已通过验收的报告。作者只拥有本文，不修改 SDK、宿主、产品代码或测试。

## 1. 职责与使用场景

用户在播放普通视频时加载外部字幕、选一条轨道或关闭字幕，调整样式和同步，并为一份原字幕运行可取消的确定性 mock 翻译，再手动切换原文与译文。TS 管理策略、解析、任务、窗口状态；成熟 libmpv/libass 后端负责字幕时间和实际渲染，宿主提供公开资源、会话、原生窗口与快照。TS 不逐帧绘制文字，不用假字幕图片替代成熟后端。

有限范围：

- 外部输入仅 `.srt`，UTF-8（允许 BOM），LF/CRLF；最大 2 MiB、10,000 cue、单 cue 4,096 Unicode 码点，时间上限24小时。严格解码，GBK/UTF-16及错误UTF-8明确拒绝并提示先转换；无自动猜测编码。SRT要求递增正整数序号、`HH:MM:SS,mmm --> HH:MM:SS,mmm`、起点小于终点；空文本、非法时间、反序起点拒绝，重叠时间允许并交成熟渲染器处理。HTML/ASS标签作为纯文本安全转义，不支持富文本、内嵌样式或可执行转义。
- 宿主可公开媒体内嵌及已注册外部轨道；单选或关闭，不叠加双字幕。内嵌图形字幕能否改样式由轨道能力说明，不能默默无效。翻译仅针对本插件成功加载且保有文本快照的外部 SRT；内嵌/他方轨道可选，翻译按钮禁用并解释“请加载外部 SRT”。不做OCR、语音识别、网络字幕搜索、在线翻译或持久字幕库。
- 样式：字体从后端已知可用的有限无衬线字体集合选一个，初始为宿主确认的默认无衬线字体（不要求枚举或管理全系统字体）；字号16–72、整数步长，默认36（1920×1080参考画布上的字幕像素，高度按视频尺寸缩放）；文字色白/黄/青三选一，默认白；黑色描边0–4、步长1、默认2；底部居中，底边距2–15%、默认5%。不承诺任意字体下载、阴影动画或ASS编辑。缺字体采用后端明确声明的默认无衬线fallback并回报实际字体，界面与呈现/导出快照均记录实际字体；无法保证替代字体可复现时拒绝冻结快照并解释。
- 同步偏移 -10,000…+10,000ms，步长100ms，默认0；数值输入可精确到1ms。正值延后出现，即播放时间 = cue时间 + 偏移。仅本实例字幕呈现层有效，不改原cue时间、不seek、不改音频延迟。
- 单实例同时仅一个翻译任务。保留当前会话的一份外部原文与至多一份完成译文；成功加载另一份原文才替换旧集合。会话切换后保留至多上一份任务摘要/完成文本快照供查看，不跨会话自动应用；再次运行覆盖历史展示，退出/停用清理，不写用户源文件。

独立运行只依赖公共宿主、成熟字幕后端和本插件包；公共测试宿主可打开媒体，无基础播放、截图、列表等其他插件亦可完成字幕用例。普通媒体不支持字幕或NES来源时，显示原因并禁用来源相关命令。

## 2. 入口与命令表

以下 `subtitle.*` 是本插件拟定命令ID，不是已存在 SDK API。菜单、右键投影与按钮统一调用同一 action，enabled/checked/busy来自同一确认状态；不注册默认全局快捷键。

| 功能 / 命令 | 唯一主菜单路径 | 其他入口 | 行为 | 启用条件 / 权威状态 |
| --- | --- | --- | --- | --- |
| `subtitle.load` | 字幕→加载外部字幕… | 工作台加载按钮 | 显示同一工作台来源区并打开非阻塞系统单选面板 | 普通字幕来源ready且未有文件面板；公开session/capabilities |
| `subtitle.track(id)` / `subtitle.off` | 字幕→轨道→各轨道 / 关闭字幕 | 来源区单选列表 | 立即提交选轨/关闭；关闭是显式选择，不销毁文本 | 当前session ready；宿主确认的effective selection及revision；关闭在已有字幕资源时可用 |
| `subtitle.style` | 字幕→样式… | 样式区控件 | 打开/聚焦同一窗口样式区 | 窗口始终可开；无媒体编辑下次默认；不支持样式的轨道禁用即时应用并解释 |
| `subtitle.sync` | 字幕→同步偏移… | 偏移滑条/数值框 | 打开/聚焦同一窗口同步区 | 同上；确认偏移为权威值 |
| `subtitle.translate` | 字幕→翻译… | 翻译区开始/取消/重试/应用译文/查看原文按钮 | 打开/聚焦同一窗口翻译区，不自动启动 | 窗口可开；开始需本实例外部SRT、ready和无运行任务；应用需有效session/revision |
| `subtitle.reset` | 字幕→复位字幕工作台 | 底部“复位字幕工作台” | 执行下述领域复位 | 有自有参数、译文或任务时可用；确认资源状态 |

轨道名称显示“内嵌/外部/原文/译文”、文件名、语言（未知写未知）；ID来自公共宿主，不用显示文本作身份。动态菜单和列表相同单选值。另有窗口内“恢复默认样式”局部按钮只调整样式，不取消任务；不能称为第二种“字幕复位”。

## 3. 界面与生命周期

一个独立非模态 Slint 原生窗口，默认隐藏，560×520、最小440×360逻辑像素；小屏按可用区布局，主内容滚动、底部状态/取消保持可达。各菜单入口显示同一实例、滚动并聚焦目标区，重复打开不重建窗口。没有独立加载窗、样式窗和翻译窗。

```text
字幕工作台                       [系统关闭]
来源：movie.mp4 / 就绪             [加载SRT…]
轨道：○关闭 ○内嵌… ○原文… ○译文…
样式：字体[可用列表] 字号[36]
      文字色[白] 描边[2] 底边距[5%]
同步：[ - / 滑条 / + ] [0] ms（正值延后）
翻译：确定性mock，非真实翻译服务
输入：example.srt · revision… · 会话…
[开始] [取消] [重试] [应用译文] [查看原文]
状态：运行中 42/100 cue / 来源已过期…
────────────────────────────────────
[复位字幕工作台]        已确认 / 局部错误
```

关闭和非编辑状态Escape只隐藏，字幕效果、当前选轨、异步任务继续；重新打开恢复参数、进度和选区。文本输入时空格/方向键属于编辑器。首开聚焦入口指定控件，后台更新不抢焦点；关闭回到仍存在的来源控件。窗口不置顶、不挤画布、不替换播放栏，显示/隐藏不暂停、seek或重载媒体。首次Slint准备遵循B1准备反馈与状态保存规则，不能把首次编译闪动当作日常show/hide已通过。

**复位具体语义**：取消本实例当前翻译任务并使其应用token立即过期；撤回本实例译文轨道；将本实例样式/偏移恢复上述默认值；保留本实例已加载的不可变原SRT和原文件。若当前有效轨道恰是被撤回的译文，条件提交切回它对应的原文；若用户已选择关闭、内嵌或他方轨道，保留该选择。取消/资源确认前显示复位中，不先伪报完成；部分失败保留最后确认值和可重试错误，不回滚别人提交。无媒体时复位只恢复下次默认并取消自有任务。复位不删除历史用户文件、不改音频/画面、不把内嵌轨移除。

**停用/崩溃**：宿主按owner generation撤销本实例窗口、订阅、字幕资源/呈现覆盖、任务临时文件；终止翻译worker。原媒体内嵌和他方资源继续存在。若撤销的是当前自有选轨，宿主条件恢复本实例首次覆盖前仍存活的基线选择（不存在则关闭），但较新的他方选择优先；清理不依赖停用后再调用RPC。快照任务已取得的共享只读字幕引用允许保留到该任务结束，停用不改变已冻结导出内容；宿主释放最后引用时回收，不让插件进程继续驻留。

## 4. 状态、连续交互与失败

权威身份是公开 `session generation + subtitle revision + track/resource id`，不得解析 `playback.backend` 的mpvDebug文本作为source/ready/error事件。0.1裸session快照不能解决结构化ready关联，属于公共缺口。

加载：打开原生系统面板之前记录expected session和加载操作序号；面板确认后先比对当前session，只有仍为expected session且ready才异步读取文件字节为不可变快照（哈希/长度/文件名），严格解析后仍以同一expected session作条件注册（读取/解析期间切源也必须拒绝）；后端确认接受资源后才替换上一份外部原文、撤旧译文并单选新原文。取消面板不改轨道；坏SRT/读取失败保持上一份有效字幕、样式和偏移，错误定位行号。面板期间切媒体则确认后返回“来源已改变，请重新加载”，不把文件自动附着新来源。并发读取以最新加载意图为准；旧读取和解析结果无应用资格。文件在读取后被外部修改不影响已冻结文本。

样式和偏移：UI显示待提交值，合并拖动至最多30次/秒，释放提交最终值；按资源revision顺序确认，过期答复不覆盖新编辑。失败恢复最近确认值并局部提示，不重开媒体。无媒体时只编辑明确标注的“下次字幕默认”，不调用空会话参数；新session ready后创建自有样式层并确认，不能误写NES。关闭字幕保留参数与选轨历史，用户重新选轨后按当前参数呈现。

翻译是实际异步worker任务而非假计时进度：逐cue处理不可变文本、检查AbortSignal、回报已完成cue/总cue。provider固定 `mock-en-zh-v1`：精确有限词典映射 `Hello.`→`你好。`、`Thank you.`→`谢谢。`、`Goodbye.`→`再见。`，其余文本输出 `〔模拟译文〕` 加原文，时间、序号不变；始终可见“确定性mock，非真实翻译服务”。不联网、不收费、不接真实模型。为展示真实取消窗口，worker每cue以可中断异步批次调度，验收样本足够长；进度来自实际完成数，不虚构百分比。测试provider可按显式故障场景首尝试抛确定错误，重试同快照成功；该故障注入只在测试配置，产品不提供伪造错误开关。

任务状态 queued→running→completed/failed，取消走cancelling→cancelled；失败可重试同一输入快照。重复开始在运行中禁用。重试生成新task ID/取消token，保留原输入，不重新读磁盘或覆盖原轨；来源过期仍可看摘要，但不能重试/应用到新来源，必须重新加载。取消点击立即撤应用资格，等待worker确认后才显示cancelled；超时显示结果未知、允许查询状态，不能把超时当成功取消。任务关闭窗口照常运行，菜单翻译入口显示运行标记，完成/失败给非抢焦点通知。

完成只产生一份未应用译文快照，不自动改当前轨道。用户点“应用译文”通过session+原文resource revision条件提交；成功后创建自有译文轨并选择它，“查看原文”回到保留原轨。开始时冻结session/原文revision，选轨或样式变化不重写输入；申请应用时还要核对最新selection revision，避免覆盖异步期间用户刚作出的关闭/选轨意图。若冲突，保留完成结果、提示当前选择变化，用户再次明确点击才对最新revision重试。原文加载替换、来源切换、复位、取消或停用使旧token过期；迟到完成仅可进历史摘要，绝不能注册/选中当前字幕。新媒体不继承旧外部字幕/偏移，样式下次默认可以继承且须明确显示。

## 5. 公共 API usage 与缺口

初版已有：`capabilities()`、`playback.state()`、`playback.state`订阅、独立 `ui.open/set/show/close/onCallback`；`sub-delay`裸全局set虽存在，但不能满足owner撤销和revision，不作绕行。初版没有轨道、外部字幕资源、字幕样式、不可变快照、CAS、任务取消、菜单、文件面板、原生列表model。以下是**请求扩展的意图伪代码，非可运行SDK或冻结签名**；拟议错误除通用invalid/backend/disabled外还需明确stale/cancelled等语义，可由maintainer统一命名。

```ts
// SUB-01：宿主将bytes/文本归一化为只读资源，不保留会变化的磁盘引用。
const source = await publicSource.read(); // generation, ready, capabilities
const input = await freezeAndParseSrt(await chooseFile()); // TS策略，取消独立结果
const original = await subtitles.register({
  owner, session: source.generation, immutableText: input.canonicalSrt,
  expectSource: source.generation,
});
await subtitles.commit({
  session: source.generation, expectRevision: confirmed.revision,
  ownedLayer, selection: original.id, style, offsetMs,
});
// TS worker只生成text；应用仍必须经过公共条件提交，不触碰私有mpv。
const result = await mockProvider.translate(input.cues, { signal, onProgress });
if (!localApplicationToken.valid) return; // 必要但不替代宿主CAS
await subtitles.registerAndSelect({
  session: task.session, expectInput: task.originalRevision,
  expectRevision: latestExplicitApplyIntent.revision,
  owner, immutableText: result.canonicalSrt,
});
```

## 6. 验收场景

样本均本轮新建：12秒含时间码/色块的合法自制视频；UTF-8 SRT含三条词典句、两行文本、重叠cue、空白边界及长字幕；另建坏序号/反序时间/损坏UTF-8/超限文件和长任务样本。不读旧测试副本。字幕在cue前后取样并对照渲染像素，字体环境和后端版本记录；只看“调用成功”不算效果通过。

| 场景 | 用户实际操作 | 可观察结果 | 证据 | 独立/组合条件 |
| --- | --- | --- | --- | --- |
