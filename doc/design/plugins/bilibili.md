## 职责与入口

独立 TS 插件采用成熟 yt-dlp Bilibili extractor 解析公开单视频（BV/av 及经验证的 b23.tv 短链），通过公共 URL provider 交 mpv 播放。不得读取 YouTube 或列表实现、对象、缓存或专用消息。多 P 网址带有效 p 时播放该 P；无 p 默认第一 P并在标题显示，不能把全部分 P 自动塞进队列。纯合集、番剧、直播、交互分支、弹幕、会员/付费、登录和地域受限资源不作本轮成功承诺。

唯一站点菜单提案“文件→网络来源→Bilibili…”（`bilibili.open`），打开/聚焦唯一普通 Slint 非模态工具窗，建议 520×320，最小 400×260。内容为链接输入、已识别标题/分 P 摘要、播放、取消解析、状态及重试。默认隐藏，关闭仅隐藏；不替换主播放栏或列表侧栏。小屏内容滚动，底部取消可达。输入框保留常规编辑键，后台状态不抢焦点。

通用“文件→打开网络内容…”亦可提交 Bilibili URL；列表“添加链接”若收到本站 URL，按同一公共 route 播放，不要求本站插件知道队列。本站不贡献下载入口，也不借 YouTube 下载窗口处理。

## 音视频与来源生命周期

解析由 TS 启动匿名 yt-dlp，读取结构化格式及必要请求头；站点 URL/分 P、短链最终域名验证、格式与备用地址选择留在插件。短链跳转出本站声明范围时明确不支持或重新交公共路由，不把任意目的地址当 Bilibili。默认选择后端可播的合理质量，不把底层 CDN 参数、格式 ID 和过期时间变成产品设置。

| 解析结果 | 交付 mpv 的方式 | 完成条件 |
| --- | --- | --- |
| 完整单个音视频 URL | 通用主 URI + 必要请求上下文 | 真正 ready，实际有声有画 |
| 分离视频/音频 URL | typed 主视频 + 外部音轨；由成熟 mpv 设施同步与 seek | 音轨确实装载并可听，不能只发视频 URI |
| 备选 CDN URL | 插件有限选择/故障切换，仍绑定同一原视频和来源条件 | 不把备选当队列下一项，不无限循环 |
| 多个顺序媒体片段 | 优先 extractor/成熟组件可表达的完整 manifest/EDL 时间线，合法转义与长度编码由插件/组件完成 | 总时长及后续段可播；不能只播第一段就宣称成功 |

mpv 官方说明外部音轨与 EDL 能力，yt-dlp 官方 extractor 包含 Bilibili Referer 处理；这是选型依据，不是对当前 SDK 多流能力的证明。当前 `source:string` 不足以传分离音轨及有作用域的 headers，因此 SITE-01 是真实接口缺口。若首个样本只需一个 URI，可先做受限切片并明确证据范围，必须继续完成分离流路径，不把这种限制定义成产品全部完成。若多段确实遇到后端不支持，记录具体 URL/结构及错误交维护者评估通用媒体描述，不手写 Rust Bilibili 解复用器。

“播放”才提交公共 source 打开，显式 startPaused=false。已暂停/播放/无媒体时输入/显示窗口均不改变来源；接受新意图后显示 loading，匹配公共 ticket/stamp 的 ready 后才显示已就绪。播放暂停/进度都由公共来源能力决定，窗口不自制另一套媒体控制。取消解析、超时后查结果、切源失效、header 清理和插件停用依公共方案；结果未知不可显示成已取消。

Referer/User-Agent 等只限当前媒体请求；换源后不得污染其他网络内容。默认匿名，不读取用户 cookie/密钥；需要登录、会员、地域访问或验证时显示当前限制，不自动提取浏览器 cookie、不绕访问控制。地址失效/403/网络失败由插件判断有限重解，恢复前比较公共来源条件；不把源端拒绝都当成签名过期，更不将其显示成自然结束触发列表下一项。

关闭工具窗保留输入并继续播放；停用撤销 resolver/解析资源，已交付普通 mpv 媒体可继续，后续需重解时明确 provider 已不可用。依赖缺失仅影响此站点能力，显示具体工具/runtime 缺口，不使本地播放或其他插件不可用。

## 实现与待验收

依赖 yt-dlp 及现有公共 mpv；不为本轮播放强制要求下载合并工具。工具平台分发/许可及版本记录沿公共调查；先审设计再在共同工作基线上实现，不等待全部站点实证。

最小切片为独立窗口→公开无需登录单视频→主画布有声有画。随后覆盖分离流、带 p 网址、完整多段（若样本可取得）、短链、通用打开与列表 URL 行、播放期间菜单/窗口连续性、解析时手动换源/停用、缺工具/坏链接/超时/受限与失效重试。仅使用公开允许使用样本；没有登录 cookie 不是验收绕限理由。当前所有条目待执行，原生未验和网站不可用分别记事实，不声称覆盖所有地区/视频。
