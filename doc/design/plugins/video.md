# 画面调节插件方案 C2

2026-10-17。作者：rebuild_video。状态：完整有限草案，已按集中交互审查R2窄修，可进入共同基线候选；不发布接口、不授权实现。依据 [B1产品交互](../product-interaction.md)、[B1菜单](../menu-map.md)、[本轮范围](../../rebuild/scope.md)、[UI可行性](../../rebuild/ui-feasibility.md) 与 `vestra.experimental/0.1`。本文只读取本轮需求、设计和新SDK，不使用旧实现或旧API副本。

## 1. 职责与使用场景

用户调节普通视频明暗、对比、饱和、伽马，应用自然/柔和预设，同时控制高斯模糊，随时复位。TS插件负责参数模型、预设、交互调度与反馈；Slint负责标准原生控件；Rust公共设施负责长期libmpv、类型化原生处理资源、会话校验、呈现与所有权清理。普通帧不得经过TS或JSONL往返。插件不向Rust注入源码、任意mpv命令或任意滤镜表达式。

范围仅此工作台，不含通用滤镜图编辑器、HDR调色、DLSS、分发包或GPU性能承诺。无其他产品插件时仍可独立加载、调参、停用；统一测试宿主提供公开来源与播放设施、合法样本和窗口，不借基础播放/列表/导出插件私有对象。普通视频能力不足或NES来源不支持时保留工作台及下次普通视频参数，禁用即时应用并说明原因。

### 参数、预设与处理顺序

| 参数 | UI范围 / 步长 | 默认 | 明确语义 |
| --- | --- | --- | --- |
| 明暗 b | -100..100 / 1 | 0 | 标准eq brightness=b/100 |
| 对比 c | -100..100 / 1 | 0 | 标准eq contrast=1+c/100 |
| 饱和 s | -100..100 / 1 | 0 | 标准eq saturation=1+s/100；-100为去色 |
| 伽马 g | -100..100 / 1 | 0 | 标准eq gamma=2^(g/100)，实际0.5..2；零为1 |
| 高斯启用 | boolean | false | 关闭旁路，仅保留强度值 |
| 高斯强度 σ | 0..10源视频像素 / 0.1 | 1.0 | 水平/垂直相同sigma；零为旁路；不按窗口缩放改变模糊尺度 |

参数均须有限；数值输入越界显示范围错误，不提交；失焦恢复最近有效值。滑条按步长量化。这里是插件的标准eq映射，不声称和初版mpv裸属性有相同视觉曲线，也不会同时写裸属性叠加一遍。

| 预设 | b / c / s / g | 高斯启用 / σ |
| --- | --- | --- |
| 自然 | 0 / 0 / 0 / 0 | false / 1.0 |
| 柔和 | 2 / -8 / -6 / 4 | true / 0.6 |

预设完整原子替换本插件六个值。复位与自然参数相同；不改其他owner、音量、字幕或来源。六值精确命中时显示对应预设，否则“自定义”；关闭高斯仍保存σ，故σ改变也可能使预设变为自定义。重启插件不承诺持久化，重新启用默认中性；同次运行关窗/换源均保留参数。

成熟算法候选：FFmpeg libavfilter `eq` 后接 `gblur`，σ两向相等、steps固定3、处理全部颜色平面。只声明必要标准参数，由宿主受校验descriptor映射到成熟库；不自写像素算法。FFmpeg公开了这些现成滤镜和参数（[官方滤镜文档](https://www.ffmpeg.org/ffmpeg-filters.html#eq)、[gblur](https://www.ffmpeg.org/ffmpeg-filters.html#gblur)）。libmpv的lavfi接入及带label的滤镜命令是原生路线候选（[mpv官方手册](https://mpv.io/manual/stable/#video-filters)、[命令接口](https://mpv.io/manual/stable/#command-interface)）；具体锁定版本/运行时可用性由maintainer核实，本文未验证构建支持。

内部顺序固定 `eq → gblur`，关闭/σ=0只旁路gblur，基础参数继续作用；全中性可旁路eq。宿主公开整个视频处理链的稳定顺序：拟按公共stage、owner稳定键、owner内节点次序排序，不能以安装/激活先后改变输出；该策略交maintainer定案。视频处理在字幕合成前，因而高斯不模糊字幕；后处理快照须记录此顺序及颜色/格式元数据。链外已有处理不得被清空。不同owner同stage的组合非交换，诊断必须展示最终顺序；本轮无拖拽重排。

无新增全局快捷键。工作台内部Tab按阅读顺序移动；滑条方向键调一格；数值框Enter提交、Escape丢弃该框未提交文本。Escape不撤销已确认效果。标准窗口关闭/工作台“关闭”只隐藏。

## 3. 界面与生命周期

独立非模态原生Slint工作台，初始480×560，最小400×420；此纵排可滚动尺寸作为B1建议尺寸的有限特例已获R2接受。系统缩放后不足时内容垂直滚动，底部状态与关闭按钮可达。不是替换底部播放栏或列表sidebar的组件。

```text
画面调节                         [系统关闭]
预设 [自然 / 柔和 / 自定义]
画面参数
  明暗  [滑条] [数值]
  对比  [滑条] [数值]
  饱和  [滑条] [数值]
  伽马  [滑条] [数值]
高斯处理 [启用]
  强度σ [滑条] [数值] 源像素
[复位画面调节]
状态：已应用 / 应用中 / 下一视频使用 / 错误
                                  [关闭]
```

激活默认隐藏，不弹窗、不抢焦点。未知Slint包先经公共准备阶段，显示“准备界面”，候选失败保留原可用UI；首次准备允许B1说明的短闪，记录耗时并恢复布局/焦点/值，backend、session与插件进程不重启。日常open仅show已准备实例，不重编、不重跑activate；隐藏不销毁对象。点击菜单请求前置并聚焦目标区；真正平台焦点恢复须实测，不能将show承诺为自动raise。关闭后主窗恢复适当焦点，编辑文字时不触发主画布播放快捷键。

关窗保留效果与参数，重开保留滚动/区段和值。插件停用/崩溃则宿主撤销本owner资源、菜单、窗口、订阅，保留兄弟资源与媒体。窗口关闭不是dispose。用户换源不复位选择；只将确认期望值应用到下一支持的视频会话。工具与基础播放栏、sidebar、音频/字幕工具可同时存在；普通show/hide不改变播放暂停/位置。

## 4. 状态、连续交互与失败

TS持有期望参数、输入预览和交互调度；宿主owner资源确认快照是已应用参数权威。Slint properties只作呈现副本。状态至少区分 `draft / applying / confirmed / staged-no-video / unsupported / failed / result-unknown`，来源由公开session/generation与能力事实判断，不解析mpv诊断字符串。

- 无媒体：可编辑六值，标“下一视频使用”；尚无真实像素应用，不显示已生效。载入中继续暂存，来源ready后按新session提交整份最新值。新来源不支持时保留期望值并解释。
- 播放中：调参不open、seek、pause或重启解码会话。暂停中：保持暂停/位置，公共原生处理须对当前已解码帧重绘预览；不能靠短暂播放或seek模拟。没有视频帧时提示“等待画面”。后端接受与屏幕可见分别记录，不能把RPC成功当像素fence。
- 拖动：即时更新本地预览数字；每个owner至多一个在途提交、一个可覆盖待发整份快照。非终值发出间隔至少约33ms（约30Hz），所有滑条共享调度，绝不每控件无限排队。释放后立即调度最终值：若有在途，终值替换待发槽并在完成后优先发；终值不因去抖遗漏。
- 带递增revision、owner generation、目标session提交；宿主原子拒绝过期session/旧revision。换源取消旧拖动与待发槽，用最新已确认期望值在新ready会话重新提交；旧ack只归档不更新新UI。通过公共来源状态与CAS应用完成隔离；新session明确显示“待应用”，接收确认后显示“已确认、等待画面生效”，实际像素更新后才作为效果生效证据。本轮不承诺每个新来源首帧前全部配置已无缝切换，不新增呈现屏障系统。
- 预设/复位/菜单开关走同一调度器，覆盖旧待发拖动，整份原子应用。重复点同值幂等；菜单不得为了执行而打开窗。应用中显示预览与等待，菜单勾选仍指最近确认状态。
- 已确定失败：宿主保留上份完整有效链，UI回最近确认快照并显示局部原因；不得只成功半个预设。没有确认过则回中性。能力缺失保留可编辑期望值，明确“未应用”，不伪造成功。
- timeout代表结果未知：暂停新提交、查询request token/owner快照，确认实际revision再恢复；不能立即回旧值却让后端迟到新值。停用取消本地计时/待发槽，宿主generation使迟到包失效。
- Escape只取消未提交输入或尚未发送的该次预览，回确认值；已接受应用不可虚称撤销。关窗不取消已提交处理。无需长任务进度、文件选择或输出文件；清理涵盖调度器/订阅/处理资源，无临时媒体产物。

## 5. 公共 API usage 与缺口

### 初版已有（仅说明真实能力，不是最终实现）

```ts
const state = await host.playback.state();
await host.playback.set("brightness", 12); // 已有裸全局mpv属性，非owner资源
const off = await host.events.subscribe("playback.state", onState);
await host.ui.show("video-workbench", false); // 已创建的Window可隐藏
```

0.1已有四个裸set、primitive Slint properties/callback、窗口show/hide与实例generation。它没有gblur、处理句柄、原子六值更新、快照、来源能力/可靠ready、可见帧确认或卸载撤销。故正式插件不以“缓存旧值再set回来”冒充所有权，也不为补功能绕到宿主私有对象或兄弟插件。

### 请求扩展：拟议usage，不能编译运行

```ts
// 下列processing/commands/windows名称是需求示意，尚非SDK/API承诺。
const resource = await publicProcessing.acquire({
  media: "video", stage: "before-subtitles", followSupportedSources: true,
}); // owner由宿主从实例确定，不接受调用者伪造owner
await resource.apply({ expectedSession: source.session, revision: ++revision,
  requestToken, nodes: [
    { standardFilter: "eq", brightness: b / 100, contrast: 1 + c / 100,
      saturation: 1 + s / 100, gamma: 2 ** (g / 100) },
    { standardFilter: "gblur", enabled, sigma: sigma, sigmaV: sigma,
      steps: 3, planes: "all-color" },
  ] }); // 返回确认revision/参数、实际顺序、目标session；错误保留旧链
const confirmed = await resource.state(); // 含未知请求token的最终结果查询
const snapshot = await publicProcessing.snapshot(source.session);
// snapshot是不可变公共资源引用；不经兄弟插件交接，不含TS大帧
```

Slint示意仅表达UI映射，非完整包：`in-out property <float> brightness; callback brightness-edited(float); callback drag-ended();`。TS接编辑事件写本地preview并入单槽调度；宿主确认后更新properties。窗口prepare/show、close可见性事件与菜单注册等遵循公共B-02/B-10，具体签名留maintainer统一，不在插件自造第二套窗口系统。

| 请求 | 所有权、输入输出 | 错误/取消/清理 | 最小观察场景 / 当前缺口 |
| --- | --- | --- | --- |
| VD-01 / B-05 类型化处理资源 | Rust按插件实例generation持有；有限标准滤镜descriptor、revision、expected session→完整确认快照；TS决定六值策略 | 校验/unsupported/过期明确；原子应用失败保留旧链；stop/crash宿主自动撤owner，不能依赖dispose发新RPC | eq+gblur同效；停用本插件仅去自身；0.1裸set不够 |
| VD-02 / B-04/B-05 确认与连续更新 | 公共来源能力/ready、CAS、request token查结果；区分validated/accepted/applied确认；applied不是visible-frame fence，真实像素另验；支持当前暂停帧重绘 | 旧session/generation/revision拒绝；timeout查实际结果；排队可丢弃，已接受不假取消 | 5秒拖动、换源迟到ack、暂停预览；不重启播放 |
| VD-03 / B-05/B-07 稳定顺序与快照 | 公共设施列实际全链顺序/滤镜版本/值/颜色格式；不可变snapshot资源由消费者任务retain/release | owner停用不破坏已retain的任务快照；实时资源清理和历史快照分开；缺snapshot禁用依赖操作 | 处理后取样与画面一致，快照后改参数不改任务；不直接调用导出插件 |
| VD-04 / B-02/B-10 菜单与窗口 | 插件拥有命令；共享enabled/checked/action，准备状态、关闭/焦点事件 | 重复ID/准备失败明确，隐藏保留资源；停用移除 | 两个菜单定位同窗，重开保值，10秒菜单音画不断 |

维护者可将VD-01..03合并为少量公共设施；不要求专名`setGaussian`。成熟libmpv/lavfi控制以常驻节点原位参数命令为候选；原位更新或局部重配置是否可行，须通过M2真实验证，不假设mpv已有atomic graph swap。不能每次拖动清空全链/重载文件。多参数以完整配置确认，但不保证物理同帧无中间值；applied不代表visible-frame fence，实际像素效果另外验收。失败必须恢复完整旧有效配置，不能遗留半链；若无法恢复，记录路线阻碍并交root，不伪报成功。Rust只提供通用媒体处理设施和资源所有权，不内置“柔和”预设或插件ID分支；所有字符串图语法若库必须使用，由受控descriptor适配内部生成，不开放任意脚本注入。

兼容影响：0.1裸set语义不在本文偷偷改变；本插件目标是后续统一发布的资源能力基线。VD请求已送maintainer与交互负责人；未批准签名前仍可审查功能和验收，不能启动实现。

## 6. 验收场景

测试媒体由本轮新建：合法自制SDR色块/灰阶/细线棋盘+移动时间码+连续正弦音轨的10秒以上视频，另一个不同颜色来源用于快切。保存生成命令、媒体hash、帧率/分辨率/色彩元数据。像素比较固定相同输入帧及色彩路径；不拿运动帧时间差当效果差。算法参考由同版成熟FFmpeg离线生成，不是插件自报成功。

| --- | --- | --- | --- | --- |

| 每个控件 | 逐一拖四滑条、输入四数值框、选择两预设、开关、σ滑条/框、复位、关闭 | 参数范围和无效输入可见；所有入口同值；无新增隐形action | 实际鼠标/键盘记录；边界错误与确认快照 | 独立 |
