# Vestra Player 0.7.3 (unsigned test build)

Internal test build, not signed or notarized. Any number of plugins can now add a sidebar tab, and only the tab you are looking at keeps its plugin running; the Plugin Store's rows are simpler; and the Options window no longer flashes. (0.7.2 was an internal build only; its changes are all here.)

## Sidebar tabs

- **No limit on sidebar tabs.** Before, the sidebar held at most 8 tabs and a ninth plugin's panel was refused. Now every plugin that adds a sidebar panel gets a tab.
- **Tabs that do not fit go into a » menu**, as in VS Code: the strip shows up to four tabs (the first three and the one you are on), and » lists every tab, with the current one marked. This works in the main window and in the detached sidebar window.
- **Only the tab you are looking at keeps its plugin running.** A plugin whose tab is in the background is put in standby after 30 seconds without use, like any other idle plugin, and its tab stays where it was. Showing the tab starts the plugin again (about 0.2 s), and its panel comes back.
- **Switching between the tabs on the strip is instant**; picking a tab from » that is not on the strip takes about a quarter of a second the first time, while the window prepares that panel.
- **A plugin whose panel fails no longer affects the others.** Its tab stays empty and the plugin is told what went wrong; other plugins' panels keep working.
- The order of the tabs is the player's own (the playlist, then the other built-in plugins), then the order in which you first saw the others; it is remembered.

## Plugin Store

- **One button per row.** Each row shows the one action that fits (Install, Update, or … for the rest), with a grey ✓ before the version of an installed plugin. Disabled plugins are dimmed. For a plugin with an update, Reload and Replace are in its detail pane.

## Fixes

- **The Options window no longer flashes or rebuilds** when a plugin that was in standby starts again and registers its settings page.

## For plugin authors

- **SDK 1.6.2.** `TestHost` no longer refuses a ninth sidebar tab, and `keepsRunning` reports "its sidebar tab is the current tab" while the plugin's tab is shown (nothing while it is in the background). A plugin with a sidebar panel should keep what the panel shows in session storage: it survives standby, and `activate` mounts the same panel again when the tab is shown. Plugins need no changes; `minPlayerVersion` is not needed for this.
- SDK 1.6.1 corrected the documentation's player versions to the published ones (0.7.1) and added pages on the player release version, Windows GPU rendering and the `lut3d` `.cube` format.

## Installing an unsigned build

- **macOS** 15 or later, Apple silicon: open the DMG and drag Vestra Player into Applications. Gatekeeper blocks the first launch: open System Settings ▸ Privacy & Security and click **Open Anyway**, or run `xattr -dr com.apple.quarantine "/Applications/Vestra Player.app"`. Files downloaded with `gh release download` are not quarantined.
- **Windows** 10/11 x64: run `VestraPlayer-0.7.3-windows-x64-setup.exe`. If SmartScreen warns, choose **More info ▸ Run anyway**. It installs to `%LOCALAPPDATA%\Programs\Vestra Player` without administrator rights. Uninstalling keeps your plugins and settings in `%APPDATA%\Vestra` unless you choose otherwise. Or unzip the portable zip and run `vestra-host.exe` (the portable build adds no Open with entries).

## Known issues

- The tab you are on keeps its plugin running even while the sidebar is hidden.
- When the set of prepared tabs changes, a detached sidebar window may redraw once.
- Check for Updates… reports "no release information was found (HTTP 404)" until a release is published (not a draft) in a public repository; internal test builds cannot find each other.
- Japanese, Korean, German, French and Spanish are machine translations, reviewed once by an AI reviewer; a human review is still to come. Corrections are welcome.
- Numbers use "." as the decimal separator in every language (1.5×, 2.0 dB).
- This build is not signed or notarized (see above).
- macOS builds are Apple silicon only. Intel Macs and macOS 14 are not supported yet.
- Picture-in-picture is macOS only. GPU rendering on Windows is experimental and off by default.
