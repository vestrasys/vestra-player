# Vestra Player 0.6.8 (unsigned test build)

Internal test build, not signed or notarized. The AI chat (Workshop) shows what the AI did as one activity row per turn, and its answers can be selected and copied. (Draft: the coordinator merges the notes of the performance batch into this file.)

## AI chat

- **One activity row per turn.** While the AI works the row reads "Working…" and the latest step; when the turn is over it reads "Worked for 12 seconds · 3 steps", and a click lists the steps. The model's thinking is no longer shown (see the Workshop's CHANGELOG).
- **Answers can be selected and copied.** Drag over a paragraph, heading, list item or quote of an answer to select it; Ctrl+C (⌘C on macOS) copies it, and a right click offers Copy and Select All. Code blocks can be selected the same way everywhere Markdown is shown. A paragraph that contains links keeps its clickable links: a right click copies it as text with each address after its link, `text (https://…)`, and offers Copy Link when it has one link. A selection stays inside one paragraph or block.

## For plugin authors

- `MarkdownBlocks` and `MarkdownView` have `selectable` (off by default; nothing changes for views that do not set it, apart from code blocks, which are now always selectable) and `MarkdownBlock` has `plain` and `links`; code blocks are always selectable. The SDK documents them once its copy of the player's Slint library is updated.

## Installing an unsigned build

- **macOS** 15 or later, Apple silicon: open the DMG and drag Vestra Player into Applications. Gatekeeper blocks the first launch: open System Settings ▸ Privacy & Security and click **Open Anyway**, or run `xattr -dr com.apple.quarantine "/Applications/Vestra Player.app"`. Files downloaded with `gh release download` are not quarantined.
- **Windows** 10/11 x64: run `VestraPlayer-0.6.8-windows-x64-setup.exe`. If SmartScreen warns, choose **More info ▸ Run anyway**. It installs to `%LOCALAPPDATA%\Programs\Vestra Player` without administrator rights. Uninstalling keeps your plugins and settings in `%APPDATA%\Vestra` unless you choose otherwise. Or unzip the portable zip and run `vestra-host.exe` (the portable build adds no Open with entries).

## Known issues

- The first start after updating starts every plugin once (each plugin's first run, to learn what it adds); later starts are lighter.
- With very many plugins installed (a hundred or more), a background check of the plugin list every 0.2 s takes several milliseconds; on a 120 or 144 Hz display this may drop a frame now and then. This check is older than this build; a fix is proposed.
- Check for Updates… reports "no release information was found (HTTP 404)" until a release is published (not a draft) in a public repository; internal test builds cannot find each other.
- Japanese, Korean, German, French and Spanish are machine translations, reviewed once by an AI reviewer; a human review is still to come. Corrections are welcome.
- Numbers use "." as the decimal separator in every language (1.5×, 2.0 dB).
- This build is not signed or notarized (see above).
- macOS builds are Apple silicon only. Intel Macs and macOS 14 are not supported yet.
- Picture-in-picture is macOS only. GPU rendering on Windows is experimental and off by default.
