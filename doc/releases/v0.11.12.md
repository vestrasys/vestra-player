# Vestra Player 0.11.12

## Install

- **macOS:** open `VestraPlayer-macos-arm64.dmg` and drag Vestra Player into Applications. The app is signed and notarized by Apple.
- **Windows:** run `VestraPlayer-windows-x64-setup.exe`. It installs for your user only, without administrator rights. The installer is not code-signed yet: if Windows SmartScreen warns, choose **More info**, then **Run anyway**. A portable zip is attached as well.

## Changes

- **Motion smoothing on Macs with Apple silicon.** Plugins can now double the frame rate with Apple's own frame interpolation (macOS 15.4 or later), as they already can with AMD and NVIDIA graphics on Windows. Install **Apple Motion Smoothing** from the Plugin Store to use it. How large a video your Mac can smooth depends on its chip: on a MacBook Air with an M2, 720p videos are smoothed in every mode and 1080p in Double Frame Rate; when the Mac cannot keep up, smoothing turns itself off for that video and says why. HDR videos are not smoothed.
- The macOS app now ships its own build of the playback library (mpv) instead of Homebrew's.
