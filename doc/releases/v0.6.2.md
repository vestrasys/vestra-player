# Vestra Player 0.6.2 (unsigned test build)

Internal test build, not signed or notarized. Long playlists stay smooth, the controls share one look, full screen and the mouse's side buttons work the way most players do, the plugin store manages your plugins, and Windows gets an experimental GPU renderer.

## Playback and the bottom bar

- **Easier seek bar.** Hovering, clicking and dragging work anywhere in the seek row, from 4 px above the bar down to the buttons; the bar looks the same.
- **Seek-bar previews.** Hovering or dragging shows a thumbnail, made in the background for local videos and kept between sessions.
- **Jump to keyframes only** (on by default, in Seek Steps…): the seek keys and the seek bar land on a nearby keyframe, so the picture appears at once on any file.
- **Bottom-bar buttons.** A Fullscreen button, and buttons for Vestra Player AI and the Plugin Store. In a narrow window they hide one by one; the time is never cut. The sidebar button is the **Toggle Sidebar** command, without a default key.
- **Volume and mute are remembered** across restarts.
- **Clicks.** A click on the video plays and pauses; a double click does nothing unless you bind it (Settings ▸ Mouse…). Submenus open as soon as you point at them, and a tooltip no longer swallows the next click.

## Full screen and mouse buttons

- **Escape toggles full screen.** It is now Toggle Fullscreen's only default key (Enter, Alt+Enter and F11 no longer are). If you had changed Toggle Fullscreen's keys, Escape is added to yours once, unless another command uses it.
- **Enter Fullscreen and Leave Fullscreen** are separate commands without default keys; bind them in Keyboard Shortcuts if you want them.
- **Side mouse buttons work anywhere in the window:** Back (X1) plays the next item, Forward (X2) the previous one.
- **In full screen the bottom bar appears only while the pointer is in its band** at the bottom edge, and hides half a second after the pointer leaves.

## Lists, menus and controls

- **Long playlists stay smooth.** The playlist draws only the rows in view, and a change sends only the rows that changed: lists of 20,000 files scroll, update and respond to clicks without stalls. Rows can show a thumbnail (toggle at the bottom of the list).
- **One set of controls.** Drop-downs, check boxes, radio buttons, tabs and sliders look and behave the same in every window; tabs switch with the arrow keys.
- **Menus** highlight the item under the pointer at once, and the open submenu's parent shows the accent bar.
- **Long file and track names.** Recently Played, Audio Track and Subtitle Track items with long Chinese, Japanese or Korean names are shortened to fit the menu. Before, such a name could stop the History plugin from starting.
- **Tool windows come back to the front.** Choosing an open but minimized window again (Vestra Player AI, Plugin Store, Options) restores it and brings it forward. When the player is in the background, a window it opens by itself asks for attention instead of taking the focus.
- **Closing the main window quits the player**, also while a tool window is open.
- **Installing or removing a plugin with a panel** no longer makes the main window flicker or move.

## Performance

- **Less memory for plugins.** The built-in plugins share one Node.js process instead of one each. Measured with the 14 built-ins of a headless start: 61 MB instead of 704 MB. Plugins from the store still get a process of their own.
- **Less idle work.** The player's background threads no longer wake every few milliseconds when there is nothing to do.

## Plugin Store

- **The store is where you manage plugins.** Tabs Installed, Available and Updates; each row has its logo, one button for its state and a ⋯ menu (Disable or Enable, Uninstall…, Reload, Open Data Folder). The Plugin Manager is gone.
- **Hide built-in plugins** (on by default, remembered): the plugins that ship with the player, which can be neither uninstalled nor disabled, are left out of the lists.
- **No rollback.** The player no longer keeps a previous version of a plugin; to go back, install the version you want.
- **Works offline:** it waits at most 5 seconds for a repository, and installed plugins show their own README and changelog.
- **The NES emulator left the player.** It is now **VestraNES** in the store.

## Vestra Player AI

- **Reads the SDK documentation** page by page with new docs and search tools, so it can look up the plugin API while it writes.
- **Thinking.** Reasoning models think again (low by default); a Thinking setting offers Off, Low and Medium, with a note on cost.
- **Tidier conversations.** Thinking and progress notes collapse into one line per turn ("Thought for 12 seconds").
- **Delete conversations** with the × on a conversation, **Delete Chat**, or Ctrl+Shift+Backspace (⌘⇧⌫ on macOS).

## Video, audio and subtitles

- **Subtitle files with the same name load automatically** when a local video opens (at most 2; Subtitle Settings… turns it off).
- **Auto deinterlacing** decides per frame and plays interlaced video at field rate (25i at 50 fps); progressive files pass untouched.
- **Snapshots** take the frame shown when you press the key and are named by its time.
- **Playback info** also shows the frame rate that reaches the screen.
- An audio file in a very large network folder no longer holds up the player while its cover art is looked for.

## Windows

- **GPU rendering (experimental).** **Video ▸ GPU Rendering (Experimental)** switches to rendering video on the GPU at the next start. It is off by default on Windows. On a laptop with two GPUs it uses the high-performance GPU unless you chose one for Vestra in Windows Settings ▸ System ▸ Display ▸ Graphics. The player keeps GPU rendering off on drivers known to misbehave and after a start that crashed; if the GPU stops responding, the player restarts where it was.
- **Smoother presentation in software rendering.** Windows are drawn with Direct3D 12 where available (OpenGL or software drawing remain the fallback), paced to the display's refresh, also after moving the window to another display. In full screen, interface updates no longer add frames between video frames.
- **Snapshots** no longer lock the playing file: it can be renamed or deleted meanwhile.
- **Shortcuts.** The Windows key is no longer offered as a modifier, and a key pressed with it is not recorded as a Ctrl shortcut.

## For plugin authors

SDK 1.5.14–1.5.50 (`@vestra-player/sdk`); `apiVersion` stays `vestra/1`. Plugins using new features declare the `minPlayerVersion` their changelog entry names; 0.6.2 satisfies all of them. Documentation: [vestrasys.github.io/vestra-player-sdk](https://vestrasys.github.io/vestra-player-sdk/).

- **Large lists** (player 0.6.0): bound arrays are sent as row patches, an update pass re-runs only the bindings that read the changed state (1.5.45), and writes larger than one message are split, so a plugin can hand the whole list (up to 100,000 rows) to the player. Draw long lists with `ListView`; `vestra-plugin check` warns about a `for` over a bound array outside one.
- **Widget library**: `Check`, `Radio`, `RadioGroup`, `Tabs`, `Choice` in `@vestra/widgets.slint`.
- **Command declarations**: TestHost now refuses what the player refuses (1.5.48). During activation, a declaration the player refuses is logged and skipped instead of failing the plugin (1.5.49); in tests `startPlugin` still fails, so fix the declaration.
- **New APIs**: `plugin.storage.session` (state that outlives a plugin restart), bar buttons on commands, `plugin.rendering`, plugin-owned video shaders and `convolution`/`lut3d` nodes, `plugin.video.upscaling` (RTX Video Super Resolution on Windows with NVIDIA, with the reason when it cannot run), and `plugin.when` conditions for command state.
- **Documentation for agents**: the docs are a tree read by path (`npx -p @vestra-player/sdk vestra-plugin docs`, `@vestra-player/sdk/docs`). `llms-full.txt` is removed (1.5.50); tools that read it must switch. New how-to: *Host your own plugin store*.

## Installing an unsigned build

- **macOS** 15 or later, Apple silicon: open the DMG and drag Vestra Player into Applications. Gatekeeper blocks the first launch: open System Settings ▸ Privacy & Security and click **Open Anyway**, or run `xattr -dr com.apple.quarantine "/Applications/Vestra Player.app"`. Files downloaded with `gh release download` are not quarantined.
- **Windows** 10/11 x64: run `VestraPlayer-0.6.2-windows-x64-setup.exe`. If SmartScreen warns, choose **More info ▸ Run anyway**. It installs to `%LOCALAPPDATA%\Programs\Vestra Player` without administrator rights. Uninstalling keeps your plugins and settings in `%APPDATA%\Vestra` unless you choose otherwise. Or unzip the portable zip and run `vestra-host.exe` (the portable build adds no Open with entries).

## Known issues

- Japanese, Korean, German, French and Spanish are machine translations, reviewed once by an AI reviewer; a human review is still to come. Corrections are welcome.
- Numbers use "." as the decimal separator in every language (1.5×, 2.0 dB).
- This build is not signed or notarized (see above).
- macOS builds are Apple silicon only. Intel Macs and macOS 14 are not supported yet.
- Picture-in-picture is macOS only. GPU rendering on Windows is experimental and off by default.
