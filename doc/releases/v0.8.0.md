# Vestra Player 0.8.0 (unsigned test build)

Internal test build, not signed or notarized. The player has a new, calmer interface: the controls that sat in menus and separate windows are now task panels beside the video, every command is one search away in the command palette, and the right-click menu is short enough to remember. The command palette can also run commands from one sentence (Ask Vestra), and pausing no longer makes playback stutter when it resumes. This release contains everything since 0.7.4: 0.7.5 was tagged but never published (its macOS build was cancelled), and 0.7.6 was an internal build only. The player program itself is 0.8.0.

## The new interface

- **Adjustments and Effects column.** Picture (Alt+1), Audio (Alt+2), Subtitles (Alt+3) and Playback (Alt+4) are tabs of one column between the video and the sidebar, and replace the Picture Adjustments, Audio Workbench, Subtitle Tuning, Adjust Sync, Jump and Speed windows. The column and the sidebar can be open at once; the column's width is remembered. In a narrow window the column lies over the video; in fullscreen, a column that is on slides in from the right edge.
  - **Picture**: Rendering (GPU Rendering, AI Upscaling), Colour, Effects as on/off chips with a strength only for those that are on, a Geometry editor (drag to pan, scroll or drag a corner to zoom, crop with ratio chips) and a collapsed Advanced row. Reset All returns colour, effects and geometry to their defaults.
  - **Audio**: volume, track, output device, channels, sync and a ten-band equalizer (was six bands; saved curves and presets carry over).
  - **Subtitles**: tracks, position, size and sync; the sync is typed in seconds (`-1.25`, `250 ms`).
  - **Playback**: a speed ruler (0.25 to 4×, 1× in the centre), seek and frame steps, Jump to time, and the **A-B Loop**, which moved here from the Chapters and Bookmarks plugin (same keys).
- **Command palette** (Ctrl+Shift+P, ⌘⇧P on macOS, or the button at the right end of the bottom bar). Every command of the player and its plugins, named "Category: Title" ("Speed: 2×", "Repeat: All"), with its key; a greyed command says why, and a command whose control lives in a panel says where.
- **Shortcut hints.** Panel controls show their key beside them or in their tooltip, and follow the keys you change in Keyboard Shortcuts.
- **Bottom button strip.** The right end of the bottom bar is the player's own: plugin buttons, a » menu for the ones that do not fit, then the command palette, Adjustments and Effects, and Sidebar buttons. As the window narrows, plugin buttons go into » before the bar drops any of its own controls; none is dropped silently.
- **« and » are Previous and Next** (from 0.7.5): they play the previous or next playlist item, the same as PgUp / PgDn, and are greyed at the ends of the list. ← and → still seek.
- **A short right-click menu**: Open ▸ (Open File… is now its first item), Close, Play/Pause, Tools ▸, Options…, Quit, plus submenus from installed plugins (such as Games ▸). **Tools ▸** holds Audio Track ▸, Subtitle Track ▸, Snapshot ▸, Chapter and Bookmark List…, Vestra Player AI…, Plugin Store…, Command Palette… and About. Everything that left the menu kept its id and key and is in the command palette; keys you bound keep working.
- **Playlist**: a Repeat button in the playlist bar cycles Off, All, One and a new **Stop After Current**; the move buttons are in the list's right-click menu. Enter or a double-click to play, and Esc, give the keyboard back to the video.
- **Settings drop-downs** in Options and the subtitle settings use the player's own style and size to their content.
- **Window state is remembered**: size, position and maximized state (not fullscreen). On Windows the window comes back on the same monitor across mixed DPI. A minimized start stays minimized.
- **Tool windows** (plugin windows, Options, the detached sidebar) belong to the main window: they stay above it and hide and restore with it. On Windows they have no taskbar button of their own.
- **Fullscreen title strip** (Windows): moving the pointer to the top edge shows the title with Minimize, Exit Fullscreen and Close.
- The sidebar header's ✕ is gone (it sat right under the window's close button); F6 and the Sidebar button hide the sidebar.

## Ask Vestra

- **Type what you want in the command palette** ("mute and go fullscreen", "rotate the picture") and press Enter on the first row, **Ask Vestra**: the model you set up in Vestra Player AI picks up to 8 commands and the player runs them; an on-screen line says what was done, with Stop while it works.
- **It only runs commands**, as if you picked them in the palette. Commands take no values, so a request such as "speed 1.37×" gets a short answer instead.
- **It asks first** (Run / Don't Run) before a command that deletes or clears something, before Close and Quit, and before every command of a plugin that is not built in. There is no undo of its own.
- **It needs a model**: a provider, model and API key in Options ▸ Plugins ▸ Vestra Player AI (pay-as-you-go or a local OpenAI-compatible service). Until then the row says "Set up a model first". The first request to a provider asks once before anything is sent; your file names and folders are never sent.

## Playback

- **No stutter after a pause** (Windows): the audio device stays open for the first 3 minutes of a pause, so resuming no longer stutters for a few frames (a 10 s pause: 261 → 24–35 ms). It is never held at the end of a file and never keeps the computer from sleeping. With GPU Rendering on, the paused frame is also kept presenting for those 3 minutes.
- **The video follows layout changes at once** when a column opens or closes or the window is resized, instead of lagging a step behind.
- **Panel tabs switch without a pause**: the first opening of the column prepares all four tabs. A video opened at start-up with the column open no longer stalls once playback has begun.
- **GPU Rendering** (Windows) is no longer marked Experimental and is in Picture ▸ Rendering with a status line; it is still off by default.
- **AI Upscaling** (Windows, NVIDIA RTX Video Super Resolution, needs GPU Rendering) is a switch in Picture ▸ Rendering and the palette. When something keeps it waiting, the status line says what to turn off.
- **Picture effects are faster**: they are processed at the size shown, a neutral effect costs nothing, and changes preview while paused (a 4K blur went from 8.6 to 60 fps).
- **Seeking after the end** works: the seek bar and seek keys jump and play on.
- On-screen messages can carry buttons (Show in Folder, Copy), and submenus open to the other side at the screen edge.
- Fixed: snapshots with subtitles always failed on Windows (the subtitle and font file paths the player hands to ffmpeg were refused instead of escaped; elsewhere a path with spaces or non-ASCII characters failed the same way); Interpolate made playback wait after it was turned off; Shader Upscale's shaders were not restored on the first restart.

## Snapshots and Clip Export

- **The built-in Snapshot plugin keeps snapshots only**: Save, Save As and Copy of the current frame, and Burst (Ctrl+G), which now starts at once from the frame shown. Its settings are in Options ▸ Video ▸ Snapshot, and your old settings are kept.
- **Clip export moved to the Plugin Store** as **Clip Export**: Fast (lossless stream copy) and Precise (re-encode) clips, a collection of parts from several files, and optional transitions. Install it from the store if you exported clips with 0.7.4.

## Plugins and reliability

- **A plugin that floods the player with requests no longer freezes input or other plugins**; the player answers requests past 320 unanswered (or 4 MiB) per plugin with an error, and SDK 1.7.10 plugins queue theirs so they never reach that limit.
- **A plugin that crashes keeps its panel** while it restarts, dimmed with a notice, and gets it back without the window being rebuilt.
- **Built-in-only capabilities**: running other plugins' commands and the palette's first row are for built-in plugins only; the Plugin Store and the player refuse a third-party plugin that asks for them. Built-in commands that cannot be undone are marked so, which is what Ask Vestra's confirmations rely on.
- A store plugin that is starting is listed as installed, not as a development load. The install confirmation ends with the permission list.
- **Diagnostics**: `host.log` gets a "ui stall" line when the interface is held for 100 ms or more (rate-limited), and what plugins print goes to `plugins.log` beside it.

## For plugin authors

- **SDK 1.7.13** (from 1.6.2). Existing plugins run unchanged. A plugin that uses anything added for this release can set `minPlayerVersion` to `0.7.6` or `0.8.0`; `@tools` needs `0.8.0`.
- **Interface**: the `adjust` panel slot and one panel per slot (1.6.11, 1.6.15); command `category` and `home` for the palette (1.6.4); `plugin.commands.keys`, `KeyHint` and `ToolTipArea.keys` (1.6.7); the player places the bar's button strip, `BarButtons` is deprecated (1.6.8); timeline ranges and OSD action buttons (1.6.9); the `@tools` menu anchor (1.7.12); `VestraFocus.release()` (1.7.0).
- **1.7.0**: `plugin.state`, `plugin.player.on` and the experimental `plugin.wire`, with a "Three ways to write a plugin" chapter; `Command.set` now re-evaluates only its own command. The documentation is in four groups since 1.7.2.
- **Media**: stream-copy and encoder options for exports, progress and the range written (1.6.10); `plugin.media.sources` and exports of several parts (1.7.8).
- **Commands**: `CommandOptions.destructive` (1.7.9); requests beyond 256 in flight wait in the plugin's own queue (1.7.10).
- **Removed in 1.7.6** (no plugin used them): `resolvers.fileTypes`, `resolvers.onFileTypesChange`, `commands.onKeysChange`, `timeline.onChange`, `appearance.onChange`; use `plugin.player.on(…)`.

## Installing an unsigned build

- **Windows** 10/11 x64: run `VestraPlayer-0.8.0-windows-x64-setup.exe`. If SmartScreen warns, choose **More info ▸ Run anyway**. It installs to `%LOCALAPPDATA%\Programs\Vestra Player` without administrator rights. Uninstalling keeps your plugins and settings in `%APPDATA%\Vestra` unless you choose otherwise. Or unzip the portable zip and run `vestra-host.exe` (the portable build adds no Open with entries).
- **macOS** 15 or later, Apple silicon: the macOS build may be added to this release later. Open the DMG and drag Vestra Player into Applications. Gatekeeper blocks the first launch: open System Settings ▸ Privacy & Security and click **Open Anyway**, or run `xattr -dr com.apple.quarantine "/Applications/Vestra Player.app"`. Files downloaded with `gh release download` are not quarantined.

## Known issues

- This build is not signed or notarized (see above).
- With GPU Rendering on, the resume-after-pause fix has been checked only on a software adapter, not yet on displays driven by an NVIDIA GPU, where a short stutter may remain.
- The first time the Adjustments and Effects column opens in a session there is a pause of about 0.9 s while all four of its tabs are prepared; switching tabs afterwards has no pause.
- There is no screen-reader support: the accessibility tree is left out because rebuilding it made the interface stall.
- The tab you are on keeps its plugin running even while the sidebar is hidden.
- When the set of prepared tabs changes, a detached sidebar window may redraw once.
- Check for Updates… reports "no release information was found (HTTP 404)" until a release is published in a public repository.
- Japanese, Korean, German, French and Spanish are machine translations, and many texts new in this release have not been reviewed yet. Corrections are welcome.
- Numbers use "." as the decimal separator in every language (1.5×, 2.0 dB).
- macOS builds are Apple silicon only. Intel Macs and macOS 14 are not supported yet.
- Picture-in-picture is macOS only. GPU rendering and AI Upscaling are Windows only, and GPU rendering is off by default.
