# Vestra Player 0.10.1

This is an internal test build. It is not signed or notarized, and it is for Windows only, like 0.10.0.

0.10.1 is a fix release. The player program itself is 0.10.1; the SDK stays 1.10.0.

## Fixes

- **A merged export no longer fails when another player starts.** Clip Export joins the parts of a merged export in a temporary folder. A player that started meanwhile (a second window, for example) removed that folder, and the export failed. A player now removes only the folders of exports that have ended; a folder left by a crash goes at a later start.
- **Plugins set aside at start-up can be uninstalled and installed again** (Store 0.2.22). Store plugins built before 0.9.0, which the player sets aside, are listed with their own names. Their row no longer offers Disable or Reload, which did nothing; it offers Uninstall…, which now removes the plugin completely (with its data, if you choose to remove it), after which you can install it again from the store.

## Breaking change

- None. Plugins built for 0.10.0 keep working unchanged.

## For plugin authors

- Nothing changes: SDK 1.10.0 as in 0.10.0. Who must change: nobody.

## Known limits

- **Unsigned:** Windows SmartScreen warns on first start.
- **No macOS build in this release.**
