# Vestra Player 0.11.10

## Install

- **macOS:** open `VestraPlayer-macos-arm64.dmg` and drag Vestra Player into Applications. The app is signed and notarized by Apple.
- **Windows:** run `VestraPlayer-windows-x64-setup.exe`. It installs for your user only, without administrator rights. The installer is not code-signed yet: if Windows SmartScreen warns, choose **More info**, then **Run anyway**. A portable zip is attached as well.

## Changes

- **Updating on Windows:** the installer can now close a running player; before, it could leave a player without its plugins (About wouldn't open).
