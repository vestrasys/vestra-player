# Vestra Player 0.11.6

The first public release of Vestra Player, for Windows (x64) and macOS (Apple silicon).

## Install

- **macOS:** open `VestraPlayer-macos-arm64.dmg` and drag Vestra Player into Applications. The app is signed and notarized by Apple.
- **Windows:** run `VestraPlayer-windows-x64-setup.exe`. It installs for your user only, without administrator rights. The installer is not code-signed yet: if Windows SmartScreen warns, choose **More info**, then **Run anyway**. A portable zip is attached as well.

## Changes

- **macOS builds again.** The macOS package is built alongside the Windows one, signed and notarized, and installs from a DMG with a branded install window.
- **macOS fixes:** pausing at the very end of a file no longer shows the wrong play state, and the hint strip wraps its text to a second line when it does not fit.
