# Vestra Player 0.8.2 (unsigned test build)

This is an internal test build. It is not signed or notarized, and it is for Windows only, like 0.8.1.

0.8.2 fixes where confirmations appear. The player program itself is 0.8.2.

## Fixes

- **Store confirmations appear in the store again.** In 0.8.1, clicking Update, Install or Uninstall in the Plugin Store could put its confirmation in the main window, hidden under the store window. The Update button then seemed to do nothing, and a second click said another dialog was open.
  - A confirmation now appears in the window you acted in: the store's own confirmation is a dialog on the store window, brought to the front.
  - The same holds for Options and any plugin's own window.
- **Ask Vestra's confirmations stay in the player.** A request typed in the command palette, and the commands Ask Vestra runs for it, confirm on the player's own sheet, even when the AI window is open.
- **A waiting confirmation comes into view.** When a second request has to wait because a confirmation is still open, the open confirmation is brought to the front instead of waiting out of sight.

## For plugin authors

- No API change. `dialogs.confirm` keeps its parameters and its answer; only where the player shows it changed. SDK 1.7.19 as in 0.8.1.

## Known limits

- **Unsigned:** Windows SmartScreen warns on first start.
- **No macOS build in this release.**
