# Vestra Player 0.11.4

This is an internal test build. It is not signed or notarized, and it is for Windows only, like 0.11.3.

## Fixes

- **The pointer no longer freezes when the player goes full screen on some laptop screens.** On a laptop panel driven by an AMD graphics chip, the visible mouse pointer could stop for a few seconds after entering full screen, although the player still followed the mouse. The player now keeps Windows composing the screen while it is full screen, which avoids the driver's stall. (`VESTRA_FULLSCREEN_COMPOSE=0` restores the previous behaviour.)
