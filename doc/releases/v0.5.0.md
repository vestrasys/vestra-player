# Vestra Player 0.5.0 (unsigned test build)

Internal test build, not signed or notarized. The player speaks seven languages, opens files from Finder and Explorer, and brings a round of Windows fixes from testing on real machines.

## Interface languages

- **Seven languages.** English, 简体中文, 日本語, 한국어, Deutsch, Français and Español. Choose one under **Settings ▸ Language** or on the Language page of the Options window (F5). **Follow System** (the default) uses the first supported language in your system's preferred languages, and English when there is none.
- **Takes effect after restart.** The language is chosen when the player starts; a new choice applies the next time you open it.
- **After updating,** the player follows the system language. Before 0.5.0 the interface was always Chinese: to keep it, choose **简体中文** under Settings ▸ Language and restart.
- **Every built-in plugin is translated**: menus, windows, panels, on-screen messages, dialogs, settings pages and the plugin store's names and descriptions. Menus from several plugins merge the same way in every language.
- **Buttons and plugin windows fit translated text.** Buttons widen with their label, and columns and rows size to the current language instead of cutting longer words off. The Chinese interface looks as before.

## Opening files from the system

- **Open With.** On macOS, Vestra Player appears in Finder's **Open With** menu for video and audio files, and you can drop files on its Dock icon. On Windows it appears in Explorer's **Open with** list.
- **One window.** Opening a file while the player runs sends it to the running window and brings it to the front, instead of starting a second player. Files opened together arrive as one open, like a drop on the video area.
- **File associations (Windows, optional).** The installer has an unchecked option **Associate common video and audio files**; with it, Vestra Player can be chosen as the default app in Settings ▸ Apps ▸ Default apps. Uninstalling removes the registrations.

## Windows

- **Hardware decoding.** The video is still rendered in software on Windows, but now decoded on the GPU (copy-back, usually `d3d11va-copy`), so playback uses much less CPU. Playback info shows the decoder in use.
- **Clicks respond on release.** A click on the video bound to Play/Pause (or with no double-click binding) acts as soon as you let go, instead of waiting for the system's double-click time. Double-click still toggles fullscreen.
- **Playlists with thousands of files.** Adding about 3000 files is instant; only the visible rows are drawn and read for durations. Before, large lists were slow and could stop updating.
- **Chinese, Japanese and Korean text without language packs.** On a system without CJK language packs, file names and interface text showed as boxes. The player now falls back to the system's CJK fonts (ordered by interface language) and to a bundled Noto Sans CJK font when there are none.
- **Menus.** Long menus that scroll show full-height rows that respond where you point (rows were squeezed together).

## Fixes

- **Hardware decoding stays on** when you turn video adjustments or filters on and off during playback. Before, switching back could leave the file on software decoding.
- **Keys of disabled commands are no longer swallowed.** When a command bound to a key is unavailable, the key goes to the next command bound to it, or to the focused control; with nothing else to run, the on-screen display says why.
- **Fullscreen commands say what they do:** **Toggle Fullscreen** and **Leave Fullscreen** (简体中文: 全屏, 仅退出全屏), in menus and the shortcut list. Your shortcuts for them stay.

## For plugin authors

SDK 1.5.9–1.5.13 (`@vestra-player/sdk`), all additive or fixes; `apiVersion` stays `vestra/1`. Plugins using the new features declare `minPlayerVersion` 0.4.3, which 0.5.0 satisfies. Documentation: [vestrasys.github.io/vestra-player-sdk](https://vestrasys.github.io/vestra-player-sdk/) (guides *Translate a plugin* and *Migrate a plugin to English source text*).

- **Translations**: English source text, `locales/<lang>.po` catalogs per plugin, `@tr` in Slint, `plugin.i18n.locale`, OSD and dialog templates with arguments; `vestra-plugin i18n extract | check` (check fails on stale catalogs since 1.5.12). The player translates declarations (commands, menus, pages, manifest fields) with the plugin's own catalog.
- **Text values**: `plugin.i18n.text`, `list`, `error` and `resolve` for words mixed with data, translated where the player shows them (menus, OSD, dialogs, window properties, timeline and subtitle titles), without composing sentences in TypeScript. `BindingInfo.key` gives a command's menu path in English keys.
- **UI value limits** are documented and higher (16384 values, 4096 rows per array); a value over them fails with code `limit` naming the property, and failures the player finds later reach `onError`.
- **TestHost** enforces the same limits, renders text values as the player does (`display`, `host.osd`, dialog texts) and takes a `locale`; `press` now resolves `"ran"`, `"reason"` or `"passed"`, since keys of disabled commands pass on (1.5.12). 1.5.13 keeps translators' comments and writes the right number of plural forms.

## Installing an unsigned build

- **macOS** 15 or later, Apple silicon: open the DMG and drag Vestra Player into Applications. Gatekeeper blocks the first launch: open System Settings ▸ Privacy & Security and click **Open Anyway**, or run `xattr -dr com.apple.quarantine "/Applications/Vestra Player.app"`. Files downloaded with `gh release download` are not quarantined.
- **Windows** 10/11 x64: run `VestraPlayer-0.5.0-windows-x64-setup.exe`. If SmartScreen warns, choose **More info ▸ Run anyway**. It installs to `%LOCALAPPDATA%\Programs\Vestra Player` without administrator rights. Uninstalling keeps your plugins and settings in `%APPDATA%\Vestra` unless you choose otherwise. Or unzip the portable zip and run `vestra-host.exe` (the portable build adds no Open with entries).

## Known issues

- Japanese, Korean, German, French and Spanish are machine translations, reviewed once by an AI reviewer; a human review is still to come. Corrections are welcome.
- Numbers use "." as the decimal separator in every language (1.5×, 2.0 dB).
- This build is not signed or notarized (see above).
- macOS builds are Apple silicon only. Intel Macs and macOS 14 are not supported yet.
- Picture-in-picture and GPU rendering are macOS only; on Windows the video is rendered in software (decoded in hardware).
