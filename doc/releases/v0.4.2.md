# Vestra Player 0.4.2 (unsigned test build)

Internal test build, not signed or notarized. The first build published as a release: it covers 0.4.0 (new look), 0.4.1 and 0.4.2, and brings the packaging work of 0.3.x (installers, bundled Node and FFmpeg) to testers for the first time.

## New look

- **Aurora palette and V-Line icons.** Vestra has its own visual identity: a dark Aurora palette (magenta accent, amber-to-cyan progress gradient) and a new rounded line icon set across the player and every built-in plugin. Sliders have ringed thumbs, menus use icon check marks, radio dots and submenu arrows with an accent bar on the highlighted row, and the on-screen display and info overlays sit on translucent rounded plates.
- **Aurora Light.** A light theme is back: **Settings ▶ Appearance ▶ Vestra Light** (设置 ▶ 外观 ▶ Vestra 浅色), with previews on the Appearance page. The video area stays dark. The standard controls (scroll bars, text fields, combo boxes, check boxes) turn light with it.
- **Title bars follow the theme** on macOS and Windows: dark with Vestra Dark, light with Vestra Light, whatever the system setting.
- Context menus cast a softer shadow in the light theme.
- On macOS, menus write shortcuts the Mac way: ⌘O, ⇧⌘S, ⌥→ (Windows keeps Ctrl+O). The shortcut settings page uses the same style.

## New in 0.4.1 and 0.4.2

- **Vestra Player AI** (was the plugin workshop): chat with an AI that writes Vestra plugins for you. Bring your own API key (stored in the system keychain); pay-as-you-go providers from the list, or a custom OpenAI- or Anthropic-format endpoint. Replies render as Markdown, tool calls show as one live status line. The agent works in a per-chat folder in a restricted process without shell access, checks its plugin (type check, tests, package check) and you install it with one click; **Undo install** removes it again. Export as `.vxp` or as a source zip ready for your own repository.
- **Sidebar tabs.** Several plugins can show a sidebar panel; they share the sidebar as tabs. With one panel the sidebar looks as before. F6 brings the playlist forward or hides the sidebar.
- **Open NES ROMs like any file.** ⌘O / Ctrl+O, drag and drop, the playlist and next/previous all start the emulator for `.nes` files. A bad ROM shows a clear message.
- **Plugins.** Only the plugins built into the player are official (`vestra.` ids are reserved for them); plugins from the plugin repository are third-party plugins reviewed there. The plugin store marks the official repository as such.
- **Fixes.** Windows reopen at their saved position (no title-bar drift); context submenus no longer cover their parent in narrow windows, and a click is not lost when a menu updates; the playlist follows generated streams; the visualizer no longer shows the previous file's card after a failed open.
- For plugin authors: SDK 1.5.8 (`@vestra-player/sdk`): file resolvers, sidebar tab API, Markdown in list rows, `llms.txt` for AI agents, `resolvers.fileTypes`. The experimental package trial API was removed.

## Changes in 0.4.0

- **The classic palette is gone.** If you were using it, the player switches to Vestra Dark the first time it starts; nothing to do. Plugins built for an older SDK that still ask for the old palette get Vestra Dark too, without an error.
- **Menus keep their order when plugins add to them.** The built-in top-level menus (Open, Playback, Subtitles, Video, Audio, Screen, Settings) now have fixed places. Before, a plugin adding an item to one of them without an explicit order could move the whole menu to the top. Items a plugin adds without an order go at the end of the menu.
- The NES plugin no longer prints `ExperimentalWarning: localStorage is not available` when it starts: the player starts plugin processes without Node's Web Storage API.
- Built-in plugins updated for the new look (playback, playlist, marks, hotkeys, store, audio, video, info, preferences).  In the playlist, the move, detach and close buttons respond to clicks again (their click area had no size).

## Packaging

- **Installers.** macOS: a DMG and a zipped `.app` (Apple silicon). Windows: a per-user setup program and a portable zip (x64). `SHA256SUMS` lists every file.
- **Nothing else to install.** The player bundles Node 26 for its plugins, libmpv, and FFmpeg/ffprobe (snapshot export, embedded subtitles, durations, thumbnails). Third-party licences are included.
- The Windows build ships the Vulkan loader (`vulkan-1.dll`) that libmpv needs, so the player starts on machines without a Vulkan driver. On Windows the player has its icon and version information and starts no console windows.
- For plugin authors: SDK 1.5.0 (`@vestra-player/sdk`) has the icon library (`@vestra/icons.slint`) and the light palette.

## Installing an unsigned build

- **macOS** 15 or later, Apple silicon: open the DMG and drag Vestra Player into Applications. Gatekeeper blocks the first launch: open System Settings ▶ Privacy & Security and click **Open Anyway**, or run `xattr -dr com.apple.quarantine "/Applications/Vestra Player.app"`. Files downloaded with `gh release download` are not quarantined.
- **Windows** 10/11 x64: run `VestraPlayer-0.4.2-windows-x64-setup.exe`. If SmartScreen warns, choose **More info ▶ Run anyway**. It installs to `%LOCALAPPDATA%\Programs\Vestra Player` without administrator rights. Uninstalling keeps your plugins and settings in `%APPDATA%\Vestra` unless you choose otherwise. Or unzip the portable zip and run `vestra-host.exe`.

## Known issues

- Windows has been built and tested on CI only, not yet on a real machine.
- macOS builds are Apple silicon only. Intel Macs and macOS 14 are not supported yet.
- Files cannot be opened from Finder or Explorer yet (no file associations).
- Picture-in-picture and GPU rendering are macOS only; on Windows the video is rendered in software.
