# Vestra Player 0.6.3 (unsigned test build)

Internal test build, not signed or notarized. Every reset now sits in one Reset menu, the player can tell you about a new version and fetch it, and windows open without a white flash.

## Reset menu

- **One place for every reset.** A new **Reset** submenu, right below Settings, gathers the reset commands of all plugins: Subtitle Position, Subtitle Sync, Picture, Framing, Crop Position, Audio Sync, Audio Processing and Idle Logo. The reset items in the other menus are gone; their keys (Q, Alt+Home, /, ?, Numpad5, Alt+Backspace) and any keys you bound to them are unchanged.
- **Reset ▸ Picture (Q) also turns image processing off:** sharpen, edge sharpen, denoise, deblock, deband, frame doubling and motion interpolation. Their strengths are kept, so turning one back on restores it as it was.
- **Reset ▸ Audio Processing** now resets only the equalizer, Normalize and Crystalizer; it no longer clears audio sync (use Reset ▸ Audio Sync, ?) or sets the channels back to Stereo. The Reset button in the audio window still resets everything.

## Updates

- **Check for Updates…** (right after About Vestra Player…) opens About and checks at once; About has a new Updates row with the latest version, a Release Notes link and one button. The player also checks on its own, 30 seconds after it starts and then once a day, and shows one notice per new version; turn this off in Options ▸ General ▸ Updates.
- **Download and run the installer from the player.** The installer goes to your Downloads folder; the player checks its size and checksum before it offers **Run Installer**. A file already there is never overwritten.

## Windows

- **A maximized window stays maximized** when the next file starts: "Window size when playback starts" leaves it alone, as MPC-HC and mpv do. Screen ▸ 0.5×–2× still resize it; on Windows the window is restored first.
- **No white flash when a window opens** (Windows): the player and its tool windows appear only once their first frame is drawn.

## Plugin Store

- **Buttons keep their place.** On a plugin's page, Disable and Enable share one position and Uninstall… stays where it was, so disabling a plugin no longer moves the buttons; the ⋯ menu keeps one order too.
- **A plugin you disabled stays disabled after an update or reinstall**: the store turns it off again right after installing the new version and says "(still disabled)". A version the store disabled because its repository revoked it is enabled again by updating to the fixed version.

## Playback and stability

- **The next video no longer freezes on the previous picture with AI Upscaling on.** Starting a video (for example from VestraTube) after another one could play the new sound under the old, frozen picture until another video was opened. The same freeze happened with a crop or pad from a plugin left on; such a picture now appears after about 2 seconds.
- **Plugin shaders after a crash.** If the player ends abnormally while a plugin's shaders are drawing (including a GPU device loss), the next start runs without plugin shaders and says so once when a plugin turns them on; after two such ends within a day, plugin shaders stay off until the graphics card, its driver or the player changes, or for 7 days. A normal quit does not count.
- **A log file.** The player keeps a small log in the `logs` folder next to its settings (`%APPDATA%\Vestra\logs\host.log` on Windows, `~/Library/Application Support/Vestra/logs/host.log` on macOS): start and exit, the renderer, errors by code and plugin shader changes; on Windows also the graphics card and, once a minute, memory use. `host.log` records no file names, links or titles; attach it to a bug report if you like (not `restart.log` in the same folder, which can name the file that was playing when the GPU device was lost).

## For plugin authors

SDK 1.5.51–1.5.53 (`@vestra-player/sdk`); `apiVersion` stays `vestra/1`. Documentation: [vestrasys.github.io/vestra-player-sdk](https://vestrasys.github.io/vestra-player-sdk/).

- **Reset menu**: `@reset` puts a command in the player's Reset menu (below Settings).
- **`plugin.window.state.maximized`**: whether the main window is maximized (false in full screen).
- **Vestra Player AI** reads the SDK 1.5.53 documentation (Reset menu, `maximized`, Check for Updates…).

## Installing an unsigned build

- **macOS** 15 or later, Apple silicon: open the DMG and drag Vestra Player into Applications. Gatekeeper blocks the first launch: open System Settings ▸ Privacy & Security and click **Open Anyway**, or run `xattr -dr com.apple.quarantine "/Applications/Vestra Player.app"`. Files downloaded with `gh release download` are not quarantined.
- **Windows** 10/11 x64: run `VestraPlayer-0.6.3-windows-x64-setup.exe`. If SmartScreen warns, choose **More info ▸ Run anyway**. It installs to `%LOCALAPPDATA%\Programs\Vestra Player` without administrator rights. Uninstalling keeps your plugins and settings in `%APPDATA%\Vestra` unless you choose otherwise. Or unzip the portable zip and run `vestra-host.exe` (the portable build adds no Open with entries).

## Known issues

- Check for Updates… reports "no release information was found (HTTP 404)" until a release is published (not a draft) in a public repository; internal test builds cannot find each other.
- The new texts of 0.6.3 (Reset menu, updates, the window setting) are machine translations not yet reviewed.
- Japanese, Korean, German, French and Spanish are machine translations, reviewed once by an AI reviewer; a human review is still to come. Corrections are welcome.
- Numbers use "." as the decimal separator in every language (1.5×, 2.0 dB).
- This build is not signed or notarized (see above).
- macOS builds are Apple silicon only. Intel Macs and macOS 14 are not supported yet.
- Picture-in-picture is macOS only. GPU rendering on Windows is experimental and off by default.
