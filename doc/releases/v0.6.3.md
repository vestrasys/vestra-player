# Vestra Player 0.6.3 (unsigned test build)

Internal test build, not signed or notarized. Every reset now sits in one Reset menu, the player can tell you about a new version and fetch it, and windows open without a white flash.

## Reset menu

- **One place for every reset.** A new **Reset** submenu, right below Settings, gathers the reset commands of all plugins: Subtitle Position, Subtitle Sync, Picture, Framing, Crop Position, Audio Sync, Audio Processing and Idle Logo. The reset items in the other menus are gone; their keys (Q, Alt+Home, /, ?, Numpad5) are unchanged.
- **Reset ▸ Picture (Q) also turns image processing off:** denoise, sharpen, edge enhancement, deblock, deband, frame doubling and motion compensation. Their strengths are kept, so turning one back on restores it as it was.
- **Reset ▸ Audio Processing** resets the equalizer, Normalize and Crystalizer only; audio sync and channels have their own entry. The Reset button in the audio window still resets everything.

## Updates

- **Check for Updates…** (next to About) asks whether a newer version is out. The player also checks on its own, 30 seconds after it starts and then once a day, and shows one notice per new version; turn this off in Options ▸ General ▸ Updates.
- **Download and run the installer from the player.** The installer goes to your Downloads folder; the player checks its size and checksum before it offers **Run Installer**. A file already there is never overwritten.

## Windows

- **No white flash when a window opens.** The player and its tool windows appear only once their first frame is drawn.
- **A maximized window stays maximized** when the next file starts, also with "Window size when playback starts" on (as in MPC-HC and mpv). A size you choose yourself, such as Screen ▸ 1×, restores the window first.

## Plugins and the SDK

- **Plugin SDK 1.5.53.** Plugins can put commands in the Reset menu (`@reset`) and read whether the main window is maximized.
- **Vestra Player AI** reads the SDK 1.5.53 documentation.
