# Vestra Player 0.10.3

This is an internal test build. It is not signed or notarized, and it is for Windows only, like 0.10.2.

0.10.3 adds temporary windows: play files in a separate window that keeps nothing. The player program itself is 0.10.3; the SDK goes to 1.10.1.

## New

- **Play in New Window.** Right-click files in the playlist and choose Play in New Window: they play in a separate temporary window, like a browser's guest window. Its title ends with "(Temporary Window)". It starts with your settings (theme, language, keys, rendering, window layout) and your installed plugins, but with empty plugin data: no history, no remembered playlist, and plugin options at their defaults. Nothing it changes is kept, and it changes nothing in the main window: it cannot install, update or remove plugins or save sign-in details, and its temporary folder is deleted when it closes. You can close the main window while a temporary window plays; opening a file afterwards starts a new main window. Windows only for now (Playlist 0.2.10).
- **No background checks in a temporary window.** The store's automatic repository check (Store 0.3.2) and the automatic update check (Info 0.1.16) do not run there; Refresh and Check for Updates… still work.

## Improvements

- **Store cards name a plugin's sidebar tab first**: store plugins with a sidebar tab now say so first on their card ("→ Sidebar: … tab"), then another way to open them if there is room.

## Breaking change

- None. Plugins built for 0.10.0 keep working unchanged.

## For plugin authors

- **SDK 1.10.1** (see its changelog). Who must change: nobody.
  - `plugin.app.temporary` is `true` in a temporary window (absent in a main window), so a plugin can skip its own background work there.
  - In a temporary window the player refuses installing, updating, uninstalling, enabling or disabling plugins and saving or deleting sign-in details with the error `unavailable`. Reading them still works.
  - `App.openWindow` (open files in a temporary window) is for built-in plugins only.
  - `TestHost` gains `openedWindows` and an `app.temporary` option.
- The "how to open" line at the end of a plugin's description now puts the sidebar first: a plugin with a sidebar tab writes `Sidebar: <tab> tab`, and adds its next way in after `; ` while the line stays within 48 characters, for example `Sidebar: VestraTube tab; Menu: Open ▸ VestraTube`.
- The Plugin Workshop is 2.2.46 and vendors SDK 1.10.1.

## Known limits

- **Unsigned:** Windows SmartScreen warns on first start: click "More info", then "Run anyway". The installer needs no administrator rights; you can also unzip the portable zip and run `vestra-host.exe`.
- **No macOS build in this release.** Temporary windows are not available on macOS yet.
