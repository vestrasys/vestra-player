# Vestra Player 0.8.4

This is an internal test build. It is not signed or notarized, and it is for Windows only, like 0.8.3.

0.8.4 ships SDK 1.8.0: plugins can now drive mpv directly, the store shows what a plugin can do from a scan of its code, and Ask Vestra reports its progress more clearly. The player program itself is 0.8.4.

## New

- **mpv pass-through for plugins.** A plugin that declares the risky capability `mpv` can run mpv commands, read and set properties, and observe them (`plugin.mpv`). The player refuses what would start programs, load code, open a control channel, write files, quit, or touch the player's own filters and the properties it manages; a plugin's filters carry its own label and are removed when it stops.
- **The store discloses what a plugin can do from a scan of its code.** The install dialog and update prompt list the categories the plugins index found by scanning the package (for example "Read and write the clipboard" or "Store sign-in details in the system keychain"), plus one sentence for every plugin that it runs with your access to files and the network. Without a scan nothing is listed from the plugin's own declarations (Store 0.2.18).
- **Ask Vestra shows clearer progress** (Workshop 2.2.41). Stop ends as "Stopped" (dimmed), the row reads "Vestra is working · Planning…" while the model plans, and a result can use two lines (up to 160 characters).

## Fixes

- **Ask Vestra follow-ups:**
  - a parked holder no longer keeps the strip sweeping;
  - the strip stays still when Windows animations are off;
  - a waiting confirmation restores or flashes the minimized window;
  - the approval sheet fits and scrolls in the smallest window;
  - its checkbox follows the plugins that remain;
  - the scrollbar never covers text.
- **Playlist 0.2.7:** the list command reads "Show in Folder" on every system (it said "Show in Finder" on Windows too).

## For plugin authors

- **SDK 1.8.0** (additions only; nothing that exists changes behaviour):
  - `plugin.mpv` (command, get, set, observe) with its capability `mpv`;
  - the palette lead status `stopped`, end texts up to 160 characters, and the working-only `strip`;
  - the capability scan (`vestra-plugin scan`, `capability-scan.json`);
  - the widget library's Button key-cap slot.
- The Plugin Workshop is 2.2.41 and vendors SDK 1.8.0, including `capability-scan.json`.

## Known limits

- **Unsigned:** Windows SmartScreen warns on first start.
- **No macOS build in this release.**
