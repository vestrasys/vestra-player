# Vestra Player 0.8.3

This is an internal test build. It is not signed or notarized, and it is for Windows only, like 0.8.2.

0.8.3 fixes subtitle position and style, and motion smoothing with AI Upscaling. The player program itself is 0.8.3.

## Fixes

- **Every subtitle position works.** Only the 85%, 90% and 95% positions took effect before; the player now applies every position in the subtitle style.
- **Subtitles 0.4.12: Reset stays reset.** Reset no longer brings the previous style back a moment later.
  - A style the player could not apply is no longer reported as "The player cannot load this subtitle."
- **Motion smoothing hands over to AI Upscaling at once.** When both are on, motion smoothing now gives way to AI Upscaling on the first request too, instead of showing a reason about copying frames back.

## For plugin authors

- No API change. SDK 1.7.20 (docs only: `MotionState.sourceFps` is the converter's input rate as the player measures it). The Plugin Workshop is 2.2.40 and vendors SDK 1.7.20.

## Known limits

- **Unsigned:** Windows SmartScreen warns on first start.
- **No macOS build in this release.**
