# Vestra Player 0.11.5

This is an internal test build. It is not signed or notarized, and it is for Windows only, like 0.11.4.

## Changes

- **The full-screen workaround from 0.11.4 now applies only to built-in laptop screens driven by an AMD graphics chip.** On every other screen, full screen is shown directly again, as before 0.11.4, without the extra composition work. (`VESTRA_FULLSCREEN_COMPOSE=1` applies the workaround on every screen, `=0` on none.)
